二、知识点详解

知识点 K14-1：Axios 安装与基本使用

定义

Axios 是基于 Promise 的 HTTP 库，支持请求/响应拦截器、取消请求、自动 JSON 转换等，是前端最流行的网络请求库。

安装

npm install axios

基本使用

import axios from 'axios'

// GET 请求
axios.get('/api/projects').then(res => {
  console.log(res.data)        // 响应数据
})

// POST 请求
axios.post('/api/login', { username: 'admin', password: '123' })
  .then(res => console.log(res.data))

// async/await
const res = await axios.get('/api/projects')
console.log(res.data)

响应结构

{
  data: {},          // 服务器返回的数据
  status: 200,       // HTTP 状态码
  statusText: 'OK',
  headers: {},       // 响应头
  config: {}         // 请求配置
}

易错点

  • 直接用 res 而非 res.data：响应数据在 res.data。
  • 不处理错误：网络请求应 try/catch 或 catch 处理失败。

小结

Axios 基于 Promise，axios.get/post 发请求，响应数据在 res.data。

知识点 K14-2：请求封装

定义

创建 Axios 实例统一配置 baseURL/timeout/headers，便于管理与切换环境。

用法

// src/utils/request.js
import axios from 'axios'

const request = axios.create({
  baseURL: '/api',           // 基础路径，所有请求自动拼接
  timeout: 10000,            // 超时 10 秒
  headers: { 'Content-Type': 'application/json' }
})

export default request

接口模块化

// src/api/user.js
import request from '../utils/request'

export const login = (data) => request.post('/login', data)
export const getUserInfo = () => request.get('/user/info')

// src/api/project.js
import request from '../utils/request'
export const getProjects = (params) => request.get('/projects', { params })
export const getProjectById = (id) => request.get(`/projects/${id}`)

组件中调用

import { login } from '../api/user'
const res = await login({ username: 'admin', password: '123' })

易错点

  • baseURL 末尾斜杠：/api/ 与 /login 拼接可能产生双斜杠，注意统一。
  • 直接用 axios 而非封装实例：应用封装的 request 实例，统一配置。

小结

创建 axios 实例统一配置 baseURL/timeout；接口按模块组织在 src/api/，组件调用 api 函数。

知识点 K14-3：请求拦截器

定义

请求拦截器 在请求发送前统一处理，常用于自动添加 Token、显示 loading。

用法

// src/utils/request.js
import axios from 'axios'
import { useUserStore } from '../stores/user'

const request = axios.create({ baseURL: '/api', timeout: 10000 })

// 请求拦截器
request.interceptors.request.use(
  (config) => {
    const userStore = useUserStore()
    if (userStore.token) {
      config.headers.Authorization = `Bearer ${userStore.token}`   // 自动加 Token
    }
    return config
  },
  (error) => Promise.reject(error)
)

export default request

易错点

  • 拦截器中用 useUserStore：需在 Pinia 已挂载后调用，确保 store 可用。
  • 忘 return config：拦截器必须 return config，否则请求被拦截不发。

小结

请求拦截器 interceptors.request.use，自动加 Token 到请求头。

知识点 K14-4：响应拦截器

定义

响应拦截器 在响应到达后统一处理，常用于解包数据、统一错误处理、登录过期跳转。

用法

// 响应拦截器
request.interceptors.response.use(
  (response) => {
    const res = response.data
    if (res.code === 200) {
      return res.data          // 成功，返回业务数据
    } else {
      ElMessage.error(res.message || '请求失败')
      return Promise.reject(new Error(res.message))
    }
  },
  (error) => {
    // HTTP 错误（如 401/404/500）
    if (error.response?.status === 401) {
      // 登录过期，清空状态跳登录
      const userStore = useUserStore()
      userStore.logout()
      router.push('/login')
    } else {
      ElMessage.error(error.message || '网络错误')
    }
    return Promise.reject(error)
  }
)

统一响应格式（与后端约定）

后端返回统一格式：

{ "code": 200, "message": "success", "data": {} }

响应拦截器根据 code 判断成功/失败，成功返回 data，失败提示。

易错点

  • return Promise.reject：错误必须 reject，否则组件 catch 不到。
  • 401 处理：登录过期应清状态跳登录，避免死循环。

小结

响应拦截器 interceptors.response.use，解包数据（成功返回 data）、统一错误处理（401 跳登录）。

知识点 K14-5：接口联调与 Vite 代理

定义

前端开发服务器（5173）调后端（8080）会产生跨域，用 Vite 代理把 /api 转发到后端，解决开发环境跨域。

Vite 代理配置

// vite.config.js
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8080',   // 后端地址
        changeOrigin: true,                 // 改变 Origin
        rewrite: (path) => path.replace(/^\/api/, '')   // 可选：去掉 /api 前缀
      }
    }
  }
})

Mock 兜底（后端未就绪）

后端未就绪时，用 Mock 数据：

// 简单 Mock：在 api 函数中判断
export const getProjects = async () => {
  // 后端就绪：return request.get('/projects')
  // Mock 兜底：
  return [
    { id: 1, title: '项目一：JavaWeb', status: '进行中' },
    { id: 2, title: '项目二：Vue3', status: '进行中' }
  ]
}

也可用 mockjs 等库。

易错点

  • 代理不生效：改 vite.config.js 后需重启 dev server。
  • rewrite 去前缀：若后端无 /api 前缀，用 rewrite 去掉；若有则不去。
  • 生产环境跨域：Vite 代理只对开发有效，生产用 Nginx 反代或后端 CORS。

小结

开发环境跨域用 Vite proxy 转发；后端未就绪用 Mock 兜底；生产用 Nginx/CORS。

三、综合示例：CTTS-Frontend Axios 封装与联调

src/utils/request.js：

import axios from 'axios'
import { useUserStore } from '../stores/user'
import { useRouter } from 'vue-router'
import { ElMessage } from 'element-plus'

const request = axios.create({
  baseURL: '/api',
  timeout: 10000
})

// 请求拦截器：自动加 Token
request.interceptors.request.use(config => {
  const userStore = useUserStore()
  if (userStore.token) {
    config.headers.Authorization = `Bearer ${userStore.token}`
  }
  return config
})

// 响应拦截器：统一处理
request.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code === 200) return res.data
    ElMessage.error(res.message || '请求失败')
    return Promise.reject(new Error(res.message))
  },
  error => {
    if (error.response?.status === 401) {
      const userStore = useUserStore()
      userStore.logout()
      ElMessage.warning('登录已过期，请重新登录')
    } else {
      ElMessage.error(error.message || '网络错误')
    }
    return Promise.reject(error)
  }
)

export default request

src/api/user.js：

import request from '../utils/request'
export const login = (data) => request.post('/login', data)
export const getUserInfo = () => request.get('/user/info')

src/api/project.js：

import request from '../utils/request'
export const getProjects = (params) => request.get('/projects', { params })
export const getProjectById = (id) => request.get(`/projects/${id}`)

vite.config.js（代理）：

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
export default defineConfig({
  plugins: [vue()],
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      }
    }
  }
})

userStore 中调用 login：

// stores/user.js
import { defineStore } from 'pinia'
import { login as loginApi } from '../api/user'

export const useUserStore = defineStore('user', {
  state: () => ({
    token: localStorage.getItem('token') || '',
    userInfo: JSON.parse(localStorage.getItem('userInfo') || 'null')
  }),
  getters: { isLogin: (s) => !!s.token },
  actions: {
    async login(credentials) {
      const data = await loginApi(credentials)    // 调接口
      this.token = data.token
      this.userInfo = data.userInfo
      localStorage.setItem('token', this.token)
      localStorage.setItem('userInfo', JSON.stringify(this.userInfo))
    },
    logout() {
      this.token = ''
      this.userInfo = null
      localStorage.removeItem('token')
      localStorage.removeItem('userInfo')
    }
  }
})

运行方式：配置 request、api、vite proxy；启动 CTTS 后端（8080）与前端（5173），登录调用后端接口，请求头自动带 Token，响应统一处理。

若后端未就绪，api 函数返回 Mock 数据兜底，第 15~16 次课再真实联调。
