二、知识点详解

知识点 K7-1：组件基础与注册

定义

组件是可复用的 Vue 实例，把页面拆成独立可维护的单元。组件化就是把复杂页面拆成多个组件组合。

注册方式

局部注册（推荐，<script setup> 下）：

<!-- 父组件 App.vue -->
<template>
  <div>
    <HelloWorld msg="Hi" />      <!-- 直接使用 -->
  </div>
</template>
<script setup>
import HelloWorld from './components/HelloWorld.vue'   <!-- 导入即用，无需注册 -->
</script>

全局注册（main.js，少用）：

import { createApp } from 'vue'
import App from './App.vue'
import MyComp from './MyComp.vue'
const app = createApp(App)
app.component('MyComp', MyComp)   // 全局注册，任意地方可用
app.mount('#app')

组件命名

  • PascalCase（推荐）：HelloWorld，模板用 <HelloWorld /> 或 <hello-world />。
  • kebab-case：hello-world。
  • <script setup> 中 import 的组件名即使用名。

易错点

  • 全局注册过多组件：全局注册的组件无法 Tree-shaking，增大体积，优先局部注册。
  • 组件名与 HTML 原生标签冲突：避免用 header/footer 等原生标签名作组件名（用 PascalCase 区分）。

小结

组件化拆分页面；<script setup> 下 import 即用（局部注册，推荐）；全局注册用 app.component。

知识点 K7-2：props

定义

props 是父组件传给子组件的数据，子组件用 defineProps 声明接收。props 是单向数据流，子组件不应直接修改。

用法

<!-- 子组件 UserInfo.vue -->
<template>
  <div>
    <p>姓名：{{ name }}</p>
    <p>年龄：{{ age }}</p>
  </div>
</template>
<script setup>
// 字符串数组声明（仅声明）
defineProps(['name', 'age'])

// 对象声明（带类型/默认值/必填/校验）
defineProps({
  name: { type: String, required: true },
  age: { type: Number, default: 18 },
  status: { type: String, validator: (v) => ['active', 'inactive'].includes(v) }
})
</script>
<!-- 父组件 App.vue -->
<template>
  <UserInfo name="张三" :age="20" status="active" />
</template>
<script setup>
import UserInfo from './UserInfo.vue'
</script>

props 校验

选项 说明
type 类型：String/Number/Boolean/Array/Object/Function 等
required: true 必填
default 默认值（对象/数组需用工厂函数 () => []）
validator 自定义校验函数

单向数据流

props 从父流向子，子组件不能直接修改 props。若需基于 props 派生数据，用 computed 或本地 ref 拷贝。

易错点

  • 子组件直接改 props：Vue 警告，应 emit 通知父改。
  • 对象/数组默认值直接写：default: [] 报错，应 default: () => []。
  • 解构 props 丢失响应式：const { name } = props 后 name 不响应式，需用 toRefs。

小结

props 父传子，单向数据流，子不能直接改；用 defineProps 声明类型/默认/必填/校验。

知识点 K7-3：emits

定义

emits 是子组件向父组件传递数据的方式，子组件用 defineEmits 声明，用 $emit（或返回的函数）触发事件，父组件用 @事件名 监听。

用法

<!-- 子组件 Counter.vue -->
<template>
  <button @click="increment">+1 ({{ count }})</button>
</template>
<script setup>
import { ref } from 'vue'
const props = defineProps({ init: { type: Number, default: 0 } })
const emit = defineEmits(['change'])          // 声明事件
const count = ref(props.init)
const increment = () => {
  count.value++
  emit('change', count.value)                  // 触发事件，传数据
}
</script>
<!-- 父组件 App.vue -->
<template>
  <Counter :init="0" @change="onChange" />
</template>
<script setup>
import Counter from './Counter.vue'
import { ref } from 'vue'
const result = ref(0)
const onChange = (val) => { result.value = val }   // 接收子组件数据
</script>

易错点

  • 忘声明 emits：<script setup> 中不声明也能用，但声明后更清晰且能校验，推荐声明。
  • 事件名用驼峰：推荐用 kebab-case（'change'/'update:value'），模板监听用 @change。

小结

emits 子传父：子用 defineEmits 声明 + emit 触发；父用 @事件名 监听接收数据。

知识点 K7-4：父子组件通信综合

定义

父子通信是组件化开发的核心：父传子用 props，子传父用 emits，形成数据流动闭环。

通信方案

方向 方式 说明
父 → 子 props 父传数据给子
子 → 父 emits 子触发事件，父监听
跨层 provide / inject 祖先传后代（后续课程）
全局 状态管理（Pinia） 第 12 次课

综合示例

见 K7-2、K7-3 组合：父传 init 给子（props），子变化时 emit change 给父，父更新数据。

易错点

  • 用 props 反向传数据：props 只能父传子，子传父必须 emit。
  • 跨多层用 props 逐层透传：层数多时改用 provide/inject 或状态管理。

小结

父传子 props，子传父 emits；跨层用 provide/inject，全局用状态管理。

知识点 K7-5：组件 v-model

定义

组件 v-model 是父子组件双向绑定的语法糖，让组件像表单元素一样支持 v-model。

原理

<Child v-model="x" /> 等价于：

<Child :modelValue="x" @update:modelValue="x = $event" />

即：父传 modelValue（props），子 emit update:modelValue 通知父更新。

用法（Vue 3.4+ 推荐 defineModel）

<!-- 子组件 MyInput.vue -->
<template>
  <input :value="model" @input="model = $event.target.value" />
</template>
<script setup>
import { defineModel } from 'vue'      // Vue 3.4+
const model = defineModel()              // 自动声明 modelValue + update:modelValue
</script>
<!-- 父组件 -->
<template>
  <MyInput v-model="text" />            <!-- 双向绑定 -->
  <p>{{ text }}</p>
</template>
<script setup>
import { ref } from 'vue'
import MyInput from './MyInput.vue'
const text = ref('')
</script>

多个 v-model

<Child v-model:title="t" v-model:author="a" />
<!-- 子组件用 defineModel('title')、defineModel('author') -->

易错点

  • Vue 3.4 以下无 defineModel：需手动 props: modelValue + emit('update:modelValue', val)。
  • 事件名必须 update:modelValue：v-model 默认绑定 modelValue，更新事件名固定。

小结

组件 v-model = :modelValue + @update:modelValue；Vue 3.4+ 用 defineModel 简化；支持多 v-model。

三、综合示例：CTTS-Frontend LoginForm 组件

子组件 LoginForm.vue：

<template>
  <form @submit.prevent="onSubmit">
    <input v-model.trim="form.username" placeholder="用户名" />
    <input v-model.trim="form.password" type="password" placeholder="密码" />
    <button type="submit">登录</button>
  </form>
</template>
<script setup>
import { reactive } from 'vue'
defineProps({ initName: { type: String, default: '' } })   // 父传初始用户名
const emit = defineEmits(['submit'])                        // 声明事件
const form = reactive({ username: '', password: '' })
const onSubmit = () => {
  emit('submit', { username: form.username, password: form.password })  // 子传父
}
</script>

父组件 App.vue：

<template>
  <div class="app">
    <LoginForm :init-name="defaultName" @submit="onLogin" />
    <p v-if="msg">{{ msg }}</p>
  </div>
</template>
<script setup>
import { ref } from 'vue'
import LoginForm from './components/LoginForm.vue'
const defaultName = ref('admin')
const msg = ref('')
const onLogin = (data) => {                                  // 接收子组件数据
  msg.value = `登录：${data.username} / ${data.password}`
}
</script>

运行方式：在 src/components/LoginForm.vue 与 src/App.vue 分别创建，npm run dev 提交表单，父组件显示登录信息。注意 props 用 kebab-case 传递（init-name）。
