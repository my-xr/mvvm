二、知识点详解

知识点 K4-1：ref

定义

ref 创建响应式数据，可包装基本类型或对象。返回 Ref 对象 { value }，JS 中用 .value 访问，模板中自动解包。

原理

ref 内部用 RefImpl 类包装值，通过 get/set 拦截实现对 .value 读写追踪。基本类型用 Object.defineProperty 或直接拦截；对象类型会再用 reactive 转换。

用法

<template>
  <p>{{ count }}</p>              <!-- 模板自动解包 -->
  <button @click="count.value++">+1</button>
</template>
<script setup>
import { ref } from 'vue'
const count = ref(0)              // 基本类型
const user = ref({ name: '张三' }) // 对象（也可用 reactive）
// JS 访问：
console.log(count.value)          // 0
console.log(user.value.name)      // 张三
</script>

易错点

  • JS 中忘 .value：count++ 报错，须 count.value++。
  • 模板中多写 .value：{{ count.value }} 显示 undefined。
  • 重新赋值覆盖：count = 1 丢失响应式，应 count.value = 1。

小结

ref 适合基本类型（也支持对象），JS 用 .value，模板自动解包。

知识点 K4-2：reactive

定义

reactive 创建对象类型的响应式数据，返回 Proxy 代理对象，直接访问属性无需 .value。

原理

reactive 用 ES6 Proxy 包裹对象，拦截属性的读/写/增/删，实现深度响应式。

用法

<template>
  <p>{{ state.name }} - {{ state.age }}</p>
  <button @click="state.age++">长大</button>
</template>
<script setup>
import { reactive } from 'vue'
const state = reactive({ name: '张三', age: 18 })
// 直接访问属性，无需 .value
state.age++                      // ✅ 正确
</script>

ref vs reactive

特性 ref reactive
适合类型 基本类型（也支持对象） 对象/数组
访问方式 JS 用 .value 直接访问属性
模板解包 自动解包 无需解包
重新赋值 x.value = newVal（保留响应式） 不能整体替换（会丢失响应式），应改属性

易错点

  • 解构丢失响应式：let { name } = state 后 name 不再响应式。需用 toRefs： 
    import { toRefs } from 'vue'
const state = reactive({ name: '张三', age: 18 })
const { name, age } = toRefs(state)   // 解构后仍是响应式
  • 整体替换丢失响应式：state = { new: 1 } 会覆盖变量丢失响应式；应逐属性改或用 Object.assign。
  • 基本类型用 reactive：reactive(0) 无效，基本类型必须用 ref。

小结

reactive 适合对象，直接访问属性；解构需 toRefs；不能整体替换。

知识点 K4-3：computed

定义

computed 创建计算属性，基于其他响应式数据派生新值，具有缓存特性——只有依赖变化时才重新计算。

原理

computed 返回一个只读 Ref。首次访问时计算并缓存；当依赖的响应式数据变化时，标记为脏，下次访问才重算。无依赖变化时直接返回缓存值。

用法

<template>
  <p>单价：{{ price }}</p>
  <p>数量：{{ count }}</p>
  <p>总价：{{ total }}</p>           <!-- 缓存，依赖不变不重算 -->
</template>
<script setup>
import { ref, computed } from 'vue'
const price = ref(50)
const count = ref(2)
const total = computed(() => price.value * count.value)
// total 是只读 Ref，访问 total.value
</script>

可写 computed（少见，需提供 get/set）：

const fullName = computed({
  get: () => firstName.value + ' ' + lastName.value,
  set: (val) => {
    [firstName.value, lastName.value] = val.split(' ')
  }
})

computed vs methods

特性 computed methods
缓存 有（依赖不变不重算） 无（每次调用都执行）
调用 像属性（不加括号） 像方法（加括号）
适用 派生数据 事件处理、动作

易错点

  • 在 computed 中做副作用（如发请求、改数据）：computed 应为纯计算，副作用用 watch。
  • computed 解构丢失缓存：computed 返回 Ref，解构 .value 后失去缓存。
  • 循环依赖：computed A 依赖 B，B 又依赖 A，会死循环。

小结

computed 派生数据且带缓存，依赖不变不重算；应保持纯函数，副作用用 watch。

知识点 K4-4：watch

定义

watch 侦听一个或多个响应式数据，当其变化时执行回调，可获取新旧值。

原理与用法

<script setup>
import { ref, watch } from 'vue'
const count = ref(0)

// 侦听 ref
watch(count, (newVal, oldVal) => {
  console.log(`${oldVal} → ${newVal}`)
})

// 侦听 reactive 属性（需用函数返回）
const state = reactive({ name: '张三' })
watch(() => state.name, (newVal) => {
  console.log('name 变为', newVal)
})

// 侦听多个源
watch([count, () => state.name], ([newCount, newName]) => {
  console.log(newCount, newName)
})

// 选项：deep 深度侦听，immediate 立即执行
watch(state, (newVal) => { ... }, { deep: true, immediate: true })
</script>

关键选项

选项 作用
deep: true 深度侦听对象内部变化
immediate: true 立即执行一次回调
flush: 'post' 在组件更新后执行

易错点

  • 侦听 reactive 属性直接写 state.name：无效，必须用函数 () => state.name 返回该属性。
  • 侦听 reactive 对象默认是深度：但侦听 ref 对象（包对象）默认非深度，需 deep: true。
  • 忘加 immediate 导致初始不执行：若需初始化时执行一次，加 immediate: true。

小结

watch 显式侦听数据源，可获新旧值，适合在数据变化时执行副作用（如请求、日志）。

知识点 K4-5：watchEffect

定义

watchEffect 立即执行一次回调，并自动收集回调中用到的响应式依赖，当依赖变化时重新执行。

用法

<script setup>
import { ref, watchEffect } from 'vue'
const count = ref(0)

watchEffect(() => {
  console.log('count 是', count.value)   // 自动追踪 count
})
// 立即输出 "count 是 0"
// count 变化时再次执行
</script>

watch vs watchEffect

特性 watch watchEffect
触发时机 依赖变化时 立即执行 + 依赖变化时
依赖指定 显式指定侦听源 自动收集
获取旧值 能 不能
适用 需要旧值/明确侦听源 仅需响应变化执行副作用

易错点

  • 期望获取旧值：watchEffect 无法获取旧值，需要旧值用 watch。
  • 依赖追踪不稳定：回调中用条件分支访问不同响应式数据，依赖会动态变化。

小结

watchEffect 立即执行并自动收集依赖，适合不需旧值的副作用；需旧值或明确源用 watch。

知识点 K4-6：响应式原理（Proxy）

定义

Vue 3 响应式基于 ES6 Proxy：用 reactive() 包裹对象后，对该对象属性的读写会被 Proxy 拦截，从而实现"依赖收集"与"触发更新"。

原理（简化）

图示 1：结构与流程重绘
读取属性（get） ──▶ 收集依赖（谁用了这个属性） 修改属性（set） ──▶ 触发更新（通知依赖重新执行/渲染）

简化示意：

// 简化版响应式原理（仅示意，非 Vue 源码）
function reactive(obj) {
  return new Proxy(obj, {
    get(target, key) {
      track(target, key)        // 收集依赖
      return target[key]
    },
    set(target, key, value) {
      target[key] = value
      trigger(target, key)      // 触发更新
      return true
    }
  })
}

Vue 2 vs Vue 3

Vue 2 Vue 3
技术 Object.defineProperty Proxy
新增属性 需 Vue.set 自动响应
删除属性 需 Vue.delete 自动响应
数组索引修改 需特殊方法 自动响应

小结

Vue 3 用 Proxy 实现响应式，能监测属性增删与数组索引修改，比 Vue 2 更全面。

三、综合示例：CTTS-Frontend 任务列表过滤与状态监听

<template>
  <div class="tasks">
    <h2>任务列表</h2>
    <input v-model="keyword" placeholder="搜索任务" />
    <ul>
      <li v-for="t in filteredTasks" :key="t.id">
        {{ t.title }} - {{ t.status }}
      </li>
    </ul>
    <p>已完成：{{ doneCount }} 个</p>
    <button @click="finishFirst">完成第一个</button>
    <p v-if="log">日志：{{ log }}</p>
  </div>
</template>

<script setup>
import { ref, reactive, computed, watch } from 'vue'

const keyword = ref('')
const tasks = reactive([
  { id: 1, title: '任务一：搭建项目', status: '进行中' },
  { id: 2, title: '任务二：实现登录', status: '未开始' },
  { id: 3, title: '任务三：接口联调', status: '进行中' }
])

// computed：搜索过滤
const filteredTasks = computed(() =>
  tasks.filter(t => t.title.includes(keyword.value))
)

// computed：统计已完成数量
const doneCount = computed(() => tasks.filter(t => t.status === '已完成').length)

const log = ref('')
// watch：监听任务数组变化（深度）
watch(tasks, () => {
  log.value = `任务状态变化，当前已完成 ${doneCount.value} 个`
}, { deep: true })

const finishFirst = () => {
  const t = tasks.find(x => x.status !== '已完成')
  if (t) t.status = '已完成'
}
</script>

<style scoped>
.tasks { max-width: 600px; margin: 20px auto; font-family: system-ui; }
ul { list-style: none; padding: 0; }
li { padding: 10px 0; border-bottom: 1px solid #eee; }
input { padding: 6px; margin-bottom: 10px; }
</style>

运行方式：替换 src/App.vue，输入搜索关键词列表实时过滤；点击"完成第一个"按钮，任务状态变化，watch 触发记录日志，doneCount 自动更新。

四、拓展阅读（选学）

  1. toRef / toRefs：把 reactive 属性转为 ref，便于解构保持响应式。
  2. shallowRef / shallowReactive：只对第一层响应式，性能优化。
  3. 依赖收集与触发更新细节：track/trigger/effect，见 Vue 源码 @vue/reactivity。
