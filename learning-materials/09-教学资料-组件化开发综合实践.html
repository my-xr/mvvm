二、组件库规划与拆分原则（K9-1）

拆分原则

  1. 单一职责：一个组件只做一件事（如 ProjectList 只管列表展示）。
  2. 可复用：通用组件（Card/Pagination/Dialog）不绑定具体业务。
  3. 命名规范：PascalCase，业务组件前缀业务名（AppHeader），通用组件无业务前缀（Card）。
  4. 层次清晰：布局组件 > 业务组件 > 通用组件。

组件清单

类别 组件 职责
布局 AppHeader / AppSidebar / AppContent 顶部栏/侧边栏/内容区
列表 ProjectList / TaskList 项目列表/任务列表（props 数据）
表单 LoginForm / SubmitForm 登录/提交（emits）
通用 Pagination / Card / Dialog 分页/卡片插槽/对话框 v-model

3.2 列表组件

ProjectList.vue（props 传数据、:class 状态）：

<template>
  <ul class="project-list">
    <li v-for="p in projects" :key="p.id" :class="statusClass(p.status)">
      {{ p.title }} <span class="status">{{ p.status }}</span>
    </li>
  </ul>
</template>
<script setup>
defineProps({ projects: { type: Array, default: () => [] } })
const statusClass = (s) => ({ 's-doing': s === '进行中', 's-done': s === '已完成' })
</script>
<style scoped>
.project-list { list-style: none; padding: 0; }
li { padding: 10px; border-bottom: 1px solid #eee; display: flex; justify-content: space-between; }
.s-doing { color: #e6a23c; }
.s-done { color: #42b883; }
</style>

3.3 表单组件

LoginForm.vue（v-model + emits）：

<template>
  <form @submit.prevent="onSubmit">
    <input v-model.trim="form.username" placeholder="用户名" />
    <input v-model.trim="form.password" type="password" placeholder="密码" />
    <button type="submit">登录</button>
  </form>
</template>
<script setup>
import { reactive } from 'vue'
const emit = defineEmits(['submit'])
const form = reactive({ username: '', password: '' })
const onSubmit = () => emit('submit', { ...form })
</script>

3.4 通用组件

Pagination.vue（props + emits）：

<template>
  <div class="pager">
    <button @click="$emit('change', page - 1)" :disabled="page <= 1">上一页</button>
    <span>{{ page }} / {{ total }}</span>
    <button @click="$emit('change', page + 1)" :disabled="page >= total">下一页</button>
  </div>
</template>
<script setup>
defineProps({ page: { type: Number, required: true }, total: { type: Number, required: true } })
</script>
<style scoped>
.pager { margin-top: 16px; }
button { padding: 4px 12px; margin: 0 6px; }
</style>

Card.vue（具名插槽）：

<template>
  <div class="card">
    <div class="card-header"><slot name="header"></slot></div>
    <div class="card-body"><slot></slot></div>
    <div class="card-footer"><slot name="footer"></slot></div>
  </div>
</template>
<style scoped>
.card { border: 1px solid #ddd; border-radius: 8px; max-width: 400px; margin: 10px; }
.card-header { padding: 10px; border-bottom: 1px solid #eee; font-weight: bold; }
.card-body { padding: 12px; }
.card-footer { padding: 10px; border-top: 1px solid #eee; }
</style>

Dialog.vue（组件 v-model 控制显隐）：

<template>
  <div v-if="model" class="dialog-mask" @click="model = false">
    <div class="dialog" @click.stop>
      <slot></slot>
      <button @click="model = false">关闭</button>
    </div>
  </div>
</template>
<script setup>
import { defineModel } from 'vue'
const model = defineModel()
</script>
<style scoped>
.dialog-mask { position: fixed; inset: 0; background: rgba(0,0,0,0.5); display: flex; align-items: center; justify-content: center; }
.dialog { background: #fff; padding: 20px; border-radius: 8px; }
</style>

四、综合示例：组合应用

App.vue（组合所有组件）：

<template>
  <div class="app">
    <AppHeader :user="currentUser" />
    <div class="app-body">
      <AppSidebar />
      <main class="app-content">
        <Card>
          <template #header>项目列表</template>
          <ProjectList :projects="projects" />
          <template #footer>
            <Pagination :page="page" :total="totalPages" @change="onPageChange" />
          </template>
        </Card>
        <button @click="showDialog = true">打开对话框</button>
        <Dialog v-model="showDialog">
          <p>这是一个对话框</p>
        </Dialog>
      </main>
    </div>
  </div>
</template>
<script setup>
import { ref, computed } from 'vue'
import AppHeader from './components/AppHeader.vue'
import AppSidebar from './components/AppSidebar.vue'
import ProjectList from './components/ProjectList.vue'
import Card from './components/Card.vue'
import Pagination from './components/Pagination.vue'
import Dialog from './components/Dialog.vue'

const currentUser = ref('admin')
const pageSize = 2
const page = ref(1)
const allProjects = ref([
  { id: 1, title: '项目一', status: '进行中' },
  { id: 2, title: '项目二', status: '已完成' },
  { id: 3, title: '项目三', status: '未开始' },
  { id: 4, title: '项目四', status: '进行中' }
])
const totalPages = computed(() => Math.max(1, Math.ceil(allProjects.value.length / pageSize)))
const projects = computed(() => {
  const start = (page.value - 1) * pageSize
  return allProjects.value.slice(start, start + pageSize)
})
const onPageChange = (p) => { if (p >= 1 && p <= totalPages.value) page.value = p }
const showDialog = ref(false)
</script>
<style scoped>
.app-body { display: flex; }
.app-content { flex: 1; padding: 16px; }
</style>

运行方式：在 src/components/ 下创建上述组件，src/App.vue 组合，npm run dev 即可看到完整应用骨架。

五、实践复盘要点

常见问题 解决
props 忘传/类型不符 父组件正确传值，子组件声明 type
emit 事件名与监听不一致 子 emit 名与父 @ 名一致
插槽忘写 <slot> 通用组件必须留插槽
组件 v-model 报错 Vue 3.4+ 用 defineModel，否则手动 modelValue+update
组件拆太碎/太大 单一职责，适度拆分
