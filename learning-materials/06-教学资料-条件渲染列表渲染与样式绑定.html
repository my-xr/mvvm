二、知识点详解

知识点 K6-1：条件渲染

定义

  • v-if/v-else-if/v-else：条件为真渲染，为假删除 DOM。
  • v-show：始终渲染，通过 display: none 切换显隐。
  • <template v-if>：对多元素分组条件渲染（不产生额外 DOM）。

用法

<template>
  <p v-if="score >= 90">优秀</p>
  <p v-else-if="score >= 60">及格</p>
  <p v-else>不及格</p>

  <div v-show="visible">v-show 始终在 DOM</div>

  <template v-if="loading">
    <p>加载中...</p>
    <p>请稍候</p>
  </template>
</template>

v-if vs v-show

特性 v-if v-show
实现 删除/重建 DOM 切 display
初始 假则不渲染 始终渲染
切换开销 高 低
初始开销 低 高
场景 一次性/少切换 频繁切换

易错点

  • v-if/v-else 不紧邻：中间插入元素会使 v-else 失效。
  • v-show 用于 <template>：v-show 不支持 template，v-if 支持。
  • v-show 不支持 v-else。

小结

频繁切换用 v-show，一次性用 v-if；多元素分组用 <template v-if>。

知识点 K6-2：列表渲染 v-for 与 :key

定义

v-for 遍历数组/对象/数字渲染列表，:key 提供唯一稳定标识。

用法

<template>
  <!-- 数组 -->
  <li v-for="(item, index) in list" :key="item.id">
    {{ index }} - {{ item.title }}
  </li>
  <!-- 对象 -->
  <li v-for="(value, key, index) in obj" :key="key">{{ key }}: {{ value }}</li>
  <!-- 数字 -->
  <span v-for="n in 5" :key="n">{{ n }} </span>
</template>
<script setup>
import { ref } from 'vue'
const list = ref([{ id: 1, title: 'A' }, { id: 2, title: 'B' }])
const obj = ref({ name: 'Vue', version: 3 })
</script>

:key 规则

  • ✅ 唯一且稳定：用数据 id（:key="item.id"）。
  • ❌ 用 index：增删时错位、性能差。
  • ❌ 用随机数：每次变，失去复用。

易错点

  • 忘加 :key：Vue 警告，影响更新。
  • v-for 与 v-if 同级：Vue 3 中 v-if 优先级高会出错，用 computed 过滤。

小结

v-for 遍历数组/对象/数字，必须提供唯一稳定 :key，避免与 v-if 同级。

知识点 K6-3：列表更新检测

定义

Vue 通过响应式系统检测数组变化触发更新。方法分两类：

  • 变异方法（修改原数组，触发更新）：push/pop/shift/unshift/splice/sort/reverse。
  • 非变异方法（返回新数组，需替换）：filter/map/concat/slice。

用法

import { ref } from 'vue'
const list = ref([1, 2, 3])

list.value.push(4)              // 变异，触发更新
list.value.splice(0, 1)         // 变异，触发更新
list.value = list.value.filter(x => x > 1)  // 非变异，替换触发更新

// Vue 3 Proxy 能直接监测索引与 length
list.value[0] = 99              // Vue 3 触发更新（Vue 2 不能）

Vue 2 vs Vue 3

操作 Vue 2 Vue 3
list[0] = x 不触发更新（需 Vue.set） 触发更新（Proxy）
list.length = 0 不触发 触发

易错点

  • 非变异方法直接调用不替换：list.value.filter(...) 不赋值回 list，原数组不变，视图不更新。
  • Vue 2 思维用 Vue.set：Vue 3 不需要，直接索引赋值即可。

小结

变异方法直接触发更新；非变异方法需替换原数组；Vue 3 Proxy 能监测索引与 length 修改。

知识点 K6-4：class 绑定

定义

:class 动态绑定 class，支持对象、数组、字符串语法，可与普通 class 共存。

用法

<template>
  <!-- 对象语法 -->
  <div :class="{ active: isActive, 'text-danger': hasError }"></div>
  <!-- 数组语法 -->
  <div :class="[baseClass, isActive ? 'active' : '']"></div>
  <!-- 数组+对象混合 -->
  <div :class="[baseClass, { active: isActive }]"></div>
  <!-- 与普通 class 共存 -->
  <div class="box" :class="{ active: isActive }"></div>
</template>
<script setup>
import { ref } from 'vue'
const isActive = ref(true)
const hasError = ref(false)
const baseClass = ref('base')
</script>

易错点

  • 对象语法键名含短横线需引号：{ 'text-danger': bool }。
  • 数组语法用布尔而非类名：[isActive] 会把 true/false 当类名，应 [isActive ? 'active' : ''] 或对象语法。

小结

:class 支持对象（{类名: 布尔}）、数组（[类名]）、混合语法，与普通 class 合并。

知识点 K6-5：style 绑定

定义

:style 动态绑定内联样式，支持对象、数组语法。

用法

<template>
  <!-- 对象语法（驼峰） -->
  <div :style="{ color: textColor, fontSize: size + 'px' }"></div>
  <!-- 短横线（需引号） -->
  <div :style="{ 'background-color': bg }"></div>
  <!-- 数组语法（合并多个样式对象） -->
  <div :style="[baseStyle, activeStyle]"></div>
</template>
<script setup>
import { ref } from 'vue'
const textColor = ref('red')
const size = ref(16)
const bg = ref('#eee')
const baseStyle = ref({ margin: '10px' })
const activeStyle = ref({ color: 'green' })
</script>

易错点

  • 属性名驼峰 vs 短横线：fontSize（驼峰）或 'font-size'（短横线引号），不能写 font-size 不加引号。
  • 值需带单位：fontSize: 16 不生效，应 16 + 'px' 或 '16px'。

小结

:style 对象语法用驼峰或引号短横线；值需带单位；数组语法合并多样式。

三、综合示例：CTTS-Frontend 任务列表条件展示与分页

<template>
  <div class="tasks">
    <h2>任务列表</h2>
    <select v-model="statusFilter">
      <option value="">全部</option>
      <option value="进行中">进行中</option>
      <option value="已完成">已完成</option>
      <option value="未开始">未开始</option>
    </select>

    <ul v-if="pagedTasks.length">
      <li v-for="t in pagedTasks" :key="t.id" :class="statusClass(t.status)">
        {{ t.title }} <span class="status">{{ t.status }}</span>
      </li>
    </ul>
    <p v-else>暂无数据</p>

    <div class="pager">
      <button @click="prev" :disabled="page === 1">上一页</button>
      <span>第 {{ page }} / {{ totalPages }} 页</span>
      <button @click="next" :disabled="page === totalPages">下一页</button>
    </div>
  </div>
</template>

<script setup>
import { ref, computed } from 'vue'
const pageSize = 2
const page = ref(1)
const statusFilter = ref('')
const tasks = ref([
  { id: 1, title: '任务一', status: '进行中' },
  { id: 2, title: '任务二', status: '已完成' },
  { id: 3, title: '任务三', status: '未开始' },
  { id: 4, title: '任务四', status: '进行中' }
])

const filtered = computed(() =>
  tasks.value.filter(t => statusFilter.value === '' || t.status === statusFilter.value)
)
const totalPages = computed(() => Math.max(1, Math.ceil(filtered.value.length / pageSize)))
const pagedTasks = computed(() => {
  const start = (page.value - 1) * pageSize
  return filtered.value.slice(start, start + pageSize)
})
const statusClass = (status) => ({ 's-doing': status === '进行中', 's-done': status === '已完成' })

const prev = () => { if (page.value > 1) page.value-- }
const next = () => { if (page.value < totalPages.value) page.value++ }
</script>

<style scoped>
.tasks { max-width: 600px; margin: 20px auto; font-family: system-ui; }
ul { list-style: none; padding: 0; }
li { padding: 10px; border-bottom: 1px solid #eee; display: flex; justify-content: space-between; }
.s-doing { color: #e6a23c; }
.s-done { color: #42b883; }
.status { font-size: 13px; }
.pager { margin-top: 16px; }
button { padding: 6px 14px; margin: 0 6px; }
</style>

运行方式：替换 src/App.vue，筛选状态、翻页均可工作，状态不同颜色不同。
