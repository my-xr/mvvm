二、知识点详解

知识点 K5-1：事件处理基础

定义

v-on（简写 @）绑定 DOM 事件，触发时执行方法或内联语句。

用法

<template>
  <button @click="count.value++">+1</button>          <!-- 内联语句 -->
  <button @click="handleClick">点击</button>          <!-- 方法引用 -->
  <button @click="say('hi')">传参</button>            <!-- 内联传参 -->
  <button @click="say('hi', $event)">传参+事件对象</button>
</template>
<script setup>
import { ref } from 'vue'
const count = ref(0)
const handleClick = (e) => { console.log(e.target) }  // 方法引用：自动接收事件对象
const say = (msg, e) => { console.log(msg, e) }       // 内联：手动传 $event
</script>

方法引用 vs 内联语句

写法 行为 事件对象
@click="fn" 方法引用，触发时调用 自动作为第一参数
@click="fn()" 内联，立即执行 需手动传 $event

易错点

  • @click="fn()" 忘传 $event：拿不到事件对象。
  • 方法名拼错：模板方法名须与 script 一致。

小结

@event 绑定事件；方法引用自动接收事件对象，内联语句用 $event。

知识点 K5-2：事件修饰符

定义

事件修饰符以 . 后缀简化常见事件操作，可链式使用。

常用修饰符

修饰符 作用 等价
.stop 阻止冒泡 e.stopPropagation()
.prevent 阻止默认行为 e.preventDefault()
.once 只触发一次 —
.capture 捕获模式 addEventListener capture
.self 仅事件源为自身才触发 e.target === currentTarget
.passive 不调用 preventDefault（性能） passive:true 
<template>
  <form @submit.prevent="onSubmit">          <!-- 阻止默认提交 -->
    <div @click.stop="outer">                <!-- 阻止冒泡 -->
      <button @click.once="onceFn">只点一次</button>
    </div>
  </form>
</template>

链式顺序

@click.prevent.stop：先 prevent 再 stop；@click.stop.prevent：先 stop 再 prevent。顺序影响执行先后。

易错点

  • .passive 与 .prevent 不能同用：passive 表示不阻止默认行为，与 prevent 矛盾。
  • 修饰符顺序：影响行为，注意书写顺序。

小结

事件修饰符 .stop/.prevent/.once/.capture/.self 简化常见操作，可链式。

知识点 K5-3：按键与系统修饰符

定义

按键修饰符限定特定按键触发；系统修饰符限定组合键。

按键修饰符

<input @keyup.enter="submit" />      <!-- 回车 -->
<input @keyup.esc="cancel" />        <!-- Esc -->
<input @keyup.tab="next" />          <!-- Tab -->
<input @keyup.delete="remove" />     <!-- Delete/Backspace -->
<input @keyup.space="doSomething" />  <!-- 空格 -->

也支持按键码（已废弃，不推荐）与自定义按键名。

系统修饰符

<div @click.ctrl="onCtrlClick">Ctrl+点击</div>
<div @click.shift="onShiftClick">Shift+点击</div>
<!-- .exact 精确匹配组合键 -->
<button @click.ctrl.exact="fn">仅 Ctrl（不按其他）</button>
修饰符 含义
.ctrl 按下 Ctrl
.shift 按下 Shift
.alt 按下 Alt
.meta 按下 Meta（Mac: Command，Win: Win 键）
.exact 精确匹配组合键

易错点

  • 按键修饰符用错事件：@click.enter 无效，按键修饰符用于 keyup/keydown。
  • .meta 跨平台差异：Mac 是 Command，Windows 是 Win 键。

小结

按键修饰符（.enter/.esc 等）限定按键；系统修饰符（.ctrl/.shift）限定组合键；.exact 精确匹配。

知识点 K5-4：表单输入绑定

定义

v-model 实现各类表单元素的双向绑定。

用法

文本输入：

<input v-model="text" />
<textarea v-model="desc"></textarea>

单选 radio（绑定字符串值）：

<input type="radio" v-model="gender" value="male" />男
<input type="radio" v-model="gender" value="female" />女
<!-- gender 为 'male' 或 'female' -->

多选 checkbox： 单个（布尔）：<input type="checkbox" v-model="agree" />（agree 为 true/false） 多个（数组）：

<input type="checkbox" v-model="hobbies" value="read" />阅读
<input type="checkbox" v-model="hobbies" value="music" />音乐
<!-- hobbies 为 ['read','music'] 子集 -->

下拉 select：

<select v-model="selected">
  <option value="a">A</option>
  <option value="b">B</option>
</select>
<!-- 多选 -->
<select v-model="selectedList" multiple>
  ...
</select>

易错点

  • checkbox 多选忘绑定数组：多个 checkbox 必须绑定数组，否则只存布尔。
  • radio/checkbox 忘写 value：v-model 靠 value 区分选项，缺 value 无法正确同步。
  • textarea 用 {{ }} 插值：textarea 应用 v-model，不能在标签内用 {{ }}。

小结

v-model 支持文本、radio（字符串）、checkbox（单布尔/多数组）、select（单值/多选数组）。

知识点 K5-5：v-model 修饰符

定义

v-model 修饰符控制同步时机与数据转换。

修饰符 作用
.lazy 失焦（change）时同步，非实时（input）
.number 转为数字类型
.trim 去除首尾空格 
<input v-model.lazy="text" />      <!-- 失焦同步 -->
<input v-model.number="age" />     <!-- 转数字 -->
<input v-model.trim="name" />      <!-- 去空格 -->
<input v-model.lazy.number="n" />  <!-- 链式 -->

易错点

  • .number 对非数字字符串：无法转数字时保留原字符串。
  • .lazy 体验：输入时数据不变，失焦才变，注意与实时校验冲突。

小结

.lazy 失焦同步、.number 转数字、.trim 去空格，可链式。

知识点 K5-6：表单验证基础

定义

表单验证在提交前校验数据合法性（非空、格式、长度等），避免无效请求。

用法

<template>
  <form @submit.prevent="onSubmit">
    <input v-model.trim="form.username" placeholder="用户名" />
    <p v-if="errors.username" class="err">{{ errors.username }}</p>

    <input v-model.trim="form.password" type="password" placeholder="密码" />
    <p v-if="errors.password" class="err">{{ errors.password }}</p>

    <button type="submit">登录</button>
  </form>
</template>
<script setup>
import { reactive } from 'vue'
const form = reactive({ username: '', password: '' })
const errors = reactive({ username: '', password: '' })

const validate = () => {
  errors.username = form.username ? '' : '用户名不能为空'
  errors.password = form.password.length >= 6 ? '' : '密码至少 6 位'
  return !errors.username && !errors.password
}
const onSubmit = () => {
  if (!validate()) return
  alert('登录成功：' + form.username)
}
</script>
<style scoped>
.err { color: red; font-size: 12px; }
</style>

小结

表单验证：提交前校验非空/格式/长度；用响应式 errors 显示错误信息；校验通过才提交。

三、综合示例：CTTS-Frontend 登录表单

<template>
  <div class="login">
    <h2>登录</h2>
    <form @submit.prevent="onSubmit">
      <div>
        <input v-model.trim="form.username" placeholder="用户名" @keyup.enter="onSubmit" />
        <p v-if="errors.username" class="err">{{ errors.username }}</p>
      </div>
      <div>
        <input v-model.trim="form.password" type="password" placeholder="密码" @keyup.enter="onSubmit" />
        <p v-if="errors.password" class="err">{{ errors.password }}</p>
      </div>
      <label>
        <input type="checkbox" v-model="form.remember" /> 记住我
      </label>
      <button type="submit">登录</button>
    </form>
    <p v-if="msg">{{ msg }}</p>
  </div>
</template>

<script setup>
import { reactive } from 'vue'
const form = reactive({ username: '', password: '', remember: false })
const errors = reactive({ username: '', password: '' })
const msg = ref('')   // 注：需 import ref（见下）
import { ref } from 'vue'

const validate = () => {
  errors.username = form.username ? '' : '用户名不能为空'
  errors.password = form.password.length >= 6 ? '' : '密码至少 6 位'
  return !errors.username && !errors.password
}
const onSubmit = () => {
  if (!validate()) return
  msg.value = `登录成功：${form.username}，记住我：${form.remember}`
}
</script>

<style scoped>
.login { max-width: 360px; margin: 40px auto; font-family: system-ui; }
input { display: block; width: 100%; padding: 8px; margin: 6px 0; box-sizing: border-box; }
.err { color: #e24b4a; font-size: 12px; margin: 0 0 6px; }
button { padding: 8px 20px; background: #42b883; color: #fff; border: none; border-radius: 4px; cursor: pointer; }
</style>

运行方式：替换 src/App.vue，输入用户名密码，回车或点登录提交；空用户名或密码<6 位会提示错误。
