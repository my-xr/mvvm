二、知识点详解

知识点 K10-1：路由概念与安装

定义

前端路由是 SPA（单页应用）中不刷新页面、通过 JS 切换页面内容的机制。Vue Router 是 Vue 官方路由库，当前版本 Vue Router 4。

hash 与 history 模式

模式 URL 形式 特点
hash http://x.com/#/projects 带 #，兼容好，无需服务器配置
history http://x.com/projects 干净，需服务器配置回退到 index.html

安装

npm install vue-router

创建路由

// src/router/index.js
import { createRouter, createWebHistory } from 'vue-router'
import Home from '../views/Home.vue'

const routes = [
  { path: '/', component: Home },
  { path: '/about', component: () => import('../views/About.vue') }   // 懒加载
]

const router = createRouter({
  history: createWebHistory(),   // history 模式；hash 用 createWebHashHistory()
  routes
})

export default router

挂载到应用

// src/main.js
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
createApp(App).use(router).mount('#app')

易错点

  • history 模式部署 404：服务器需配置所有路径回退到 index.html。
  • 忘在 main.js 挂载 router：.use(router) 不能少。

小结

Vue Router 4 用 createRouter 创建，createWebHistory 选模式；在 main.js .use(router) 挂载。

知识点 K10-2：路由配置与组件

定义

路由配置用 routes 数组，每项含 path（路径）与 component（组件）。<router-view> 是路由出口，<router-link> 是导航链接。

用法

<!-- App.vue -->
<template>
  <div>
    <nav>
      <router-link to="/">首页</router-link>
      <router-link to="/about">关于</router-link>
    </nav>
    <router-view />        <!-- 路由匹配的组件在此渲染 -->
  </div>
</template>

router-link 属性

属性 说明
to 目标路径（字符串或对象）
active-class 激活时的 class
replace 替换历史记录（不留下返回记录） 
<router-link to="/projects">项目</router-link>
<router-link :to="{ path: '/user', query: { id: 1 } }">用户</router-link>

路由懒加载

component: () => import('./X.vue') 按需加载，减小首屏体积。

易错点

  • 忘写 <router-view>：路由匹配的组件无处渲染。
  • path 不以 / 开头：除相对嵌套外，path 应以 / 开头。

小结

routes 配置 path+component；<router-view> 是出口；<router-link to> 导航；大组件懒加载。

知识点 K10-3：useRouter 与 useRoute

定义

  • useRouter：获取路由实例，用于编程式导航（push/replace/go）。
  • useRoute：获取当前路由信息（params/query/path 等）。

用法

<script setup>
import { useRouter, useRoute } from 'vue-router'
const router = useRouter()
const route = useRoute()

const goProjects = () => {
  router.push('/projects')                       // 字符串
  router.push({ path: '/user', query: { id: 1 } })  // 对象
}

const showInfo = () => {
  console.log(route.path)          // 当前路径
  console.log(route.params.id)     // 动态参数
  console.log(route.query.keyword) // 查询参数
}
</script>

push vs replace

  • push：压入历史，可返回。
  • replace：替换历史，不可返回。

易错点

  • 混淆 useRouter 与 useRoute：useRouter 用于导航（动作），useRoute 用于获取信息（数据）。
  • 在 setup 外使用：useRouter/useRoute 必须在 setup 或组件内调用。

小结

useRouter 做编程式导航（push/replace）；useRoute 获取当前路由信息（params/query）。

知识点 K10-4：动态路由与参数

定义

动态路由用 :参数名 匹配 URL 片段，如 /tasks/:id 匹配 /tasks/5，参数通过 route.params.id 获取。

用法

const routes = [
  { path: '/tasks/:id', component: TaskDetail, props: true }   // props:true 把 params 作为 props
]
<!-- TaskDetail.vue -->
<template>
  <p>任务 ID：{{ $route.params.id }}</p>
</template>
<script setup>
import { useRoute } from 'vue-router'
const route = useRoute()
console.log(route.params.id)
</script>

props 传参（推荐）

props: true 让路由参数作为组件 props 传入，组件与路由解耦：

<script setup>
defineProps(['id'])   // 直接接收，不依赖 $route
</script>
<template>
  <p>任务 ID：{{ id }}</p>
</template>

易错点

  • 参数名不一致：路由定义 :id，获取应用 route.params.id。
  • 多个动态段：/users/:userId/posts/:postId，分别取 params.userId、params.postId。

小结

动态路由 :参数名 匹配 URL；route.params 获取；props: true 解耦传参。

知识点 K10-5：嵌套路由

定义

嵌套路由用 children 配置子路由，在父组件内用子 <router-view> 渲染，适合主从结构（如用户中心下有资料/密码子页）。

用法

const routes = [
  {
    path: '/user',
    component: UserLayout,
    children: [
      { path: '', component: UserProfile },                 // /user
      { path: 'profile', component: UserProfile },           // /user/profile
      { path: 'password', component: ChangePassword }        // /user/password
    ]
  }
]
<!-- UserLayout.vue -->
<template>
  <div class="user-layout">
    <nav>
      <router-link to="/user/profile">资料</router-link>
      <router-link to="/user/password">密码</router-link>
    </nav>
    <router-view />          <!-- 子路由渲染处 -->
  </div>
</template>

路径拼接规则

  • 子路由 path 以 / 开头：绝对路径，不与父拼接。
  • 子路由 path 不以 / 开头：相对，拼接父 path（如父 /user + 子 profile = /user/profile）。

易错点

  • 忘在父组件写子 <router-view>：子路由无处渲染。
  • 子 path 加了 / 但想拼接：以 / 开头是绝对路径，不拼接。

小结

嵌套路由用 children，父组件内放子 <router-view>；子 path 不以 / 开头则与父拼接。

三、综合示例：CTTS-Frontend 路由配置

src/router/index.js：

import { createRouter, createWebHistory } from 'vue-router'
import Layout from '../views/Layout.vue'

const routes = [
  { path: '/', redirect: '/projects' },
  { path: '/login', component: () => import('../views/Login.vue') },
  {
    path: '/',
    component: Layout,
    children: [
      { path: 'projects', component: () => import('../views/Projects.vue') },
      { path: 'tasks/:id', component: () => import('../views/TaskDetail.vue'), props: true },
      {
        path: 'user',
        component: () => import('../views/User.vue'),
        children: [
          { path: 'profile', component: () => import('../views/UserProfile.vue') },
          { path: 'password', component: () => import('../views/ChangePassword.vue') }
        ]
      }
    ]
  }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

export default router

Layout.vue（含导航与子 router-view）：

<template>
  <div class="layout">
    <nav>
      <router-link to="/projects">项目</router-link>
      <router-link to="/user/profile">个人中心</router-link>
    </nav>
    <router-view />      <!-- 子页面渲染 -->
  </div>
</template>

TaskDetail.vue（动态路由 + props）：

<template>
  <p>任务详情，ID = {{ id }}</p>
</template>
<script setup>
defineProps(['id'])   // 通过 props:true 接收动态参数
</script>

main.js：

import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
createApp(App).use(router).mount('#app')

App.vue：

<template>
  <router-view />
</template>

运行方式：创建对应 views 组件，npm run dev，访问 /projects、/tasks/5、/user/profile 等路径，页面切换不刷新。
