二、知识点详解

知识点 K10-1：路由概念与安装

定义

前端路由是 SPA（单页应用）中不刷新页面、通过 JS 切换页面内容的机制。Vue Router 是 Vue 官方路由库，当前版本 Vue Router 4。

hash 与 history 模式

模式 URL 形式 特点
hash http://x.com/#/projects 带 #，兼容好，无需服务器配置
history http://x.com/projects 干净，需服务器配置回退到 index.html

安装

请在 Vue 3 + Vite 项目根目录执行；从空目录创建项目的完整命令见 3.1。Vue Router 4 与 Vue 3 配套使用。

npm install vue-router@4

创建路由

// src/router/index.js
import { createRouter, createWebHistory } from 'vue-router'
import Home from '../views/Home.vue'

const routes = [
  { path: '/', component: Home },
  { path: '/about', component: () => import('../views/About.vue') }   // 懒加载
]

const router = createRouter({
  history: createWebHistory(),   // history 模式；hash 用 createWebHashHistory()
  routes
})

export default router

切换为 hash 模式：把导入改为 import { createRouter, createWebHashHistory } from 'vue-router'，并把 history 改成 createWebHashHistory()。两处必须同时修改，否则会出现未定义函数。

挂载到应用

// src/main.js
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'
createApp(App).use(router).mount('#app')

最小页面文件：上面的路由引用了 src/views/Home.vue 和 src/views/About.vue，两个文件都必须存在：

<!-- src/views/Home.vue -->
<template><h2>首页</h2></template>
<!-- src/views/About.vue -->
<template><h2>关于页面</h2></template>

易错点

  • history 模式部署 404：服务器需配置所有路径回退到 index.html。
  • 忘在 main.js 挂载 router：.use(router) 不能少。

小结

Vue Router 4 用 createRouter 创建，createWebHistory 选模式；在 main.js .use(router) 挂载。

知识点 K10-2：路由配置与组件

定义

路由配置用 routes 数组，每项含 path（路径）与 component（组件）。<router-view> 是路由出口，<router-link> 是导航链接。

用法

<!-- App.vue -->
<template>
  <div>
    <nav>
      <router-link to="/">首页</router-link>
      <router-link to="/about">关于</router-link>
    </nav>
    <router-view />        <!-- 路由匹配的组件在此渲染 -->
  </div>
</template>

router-link 属性

属性 说明
to 目标路径（字符串或对象）
active-class 激活时的 class
replace 替换当前历史记录，不新增本次导航记录 
<router-link to="/">首页</router-link>
<router-link :to="{ path: '/about', query: { id: 1 } }">关于（带查询参数）</router-link>

路由懒加载

component: () => import('./X.vue') 按需加载，减小首屏体积。

易错点

  • 忘写 <router-view>：路由匹配的组件无处渲染。
  • path 不以 / 开头：除相对嵌套外，path 应以 / 开头。

小结

routes 配置 path+component；<router-view> 是出口；<router-link to> 导航；大组件懒加载。

知识点 K10-3：useRouter 与 useRoute

定义

  • useRouter：获取路由实例，用于编程式导航（push/replace/go）。
  • useRoute：获取当前路由信息（params/query/path 等）。

用法

下面的组件应放在已经接入 Router 的页面中（例如路由页面 Projects.vue），这样 useRouter 和 useRoute 才能取得当前应用的路由上下文。

<!-- RouteActions.vue -->
<template>
  <section>
    <button type="button" @click="goProjects">打开项目列表</button>
    <button type="button" @click="goTask">打开任务 5</button>
    <p>当前路径：{{ route.path }}</p>
    <p>任务 ID：{{ route.params.id || '无' }}</p>
    <p>关键词：{{ route.query.keyword || '无' }}</p>
  </section>
</template>
<script setup>
import { useRouter, useRoute } from 'vue-router'

const router = useRouter()
const route = useRoute()

const goProjects = () => {
  router.push('/projects')                         // 字符串路径
}
const goTask = () => {
  router.push({ path: '/tasks/5', query: { keyword: 'vue' } }) // 对象
}
</script>

route 是响应式路由对象，地址变化后模板会自动更新；路径参数来自 route.params，查询参数来自 route.query。如果只需要查看当前 URL，也可以在函数中读取 route.path。

运行这个组件前，路由表至少要存在 /projects 和 /tasks/:id 两条路由；没有匹配的路由时， router.push 虽然会改变地址，但不会渲染预期页面。

push vs replace

  • push：压入历史，可返回。
  • replace：替换历史，不可返回。

易错点

  • 混淆 useRouter 与 useRoute：useRouter 用于导航（动作），useRoute 用于获取信息（数据）。
  • 在 setup 外使用：useRouter/useRoute 必须在 setup 或组件内调用。

小结

useRouter 做编程式导航（push/replace）；useRoute 获取当前路由信息（params/query）。

知识点 K10-4：动态路由与参数

定义

动态路由用 :参数名 匹配 URL 片段，如 /tasks/:id 匹配 /tasks/5，参数通过 route.params.id 获取。

用法

// src/router/index.js
const routes = [
  {
    path: '/tasks/:id',
    component: () => import('../views/TaskDetail.vue'),
    props: true // 把 params.id 作为 id prop 传入
  }
]
<!-- TaskDetail.vue -->
<template>
  <p>任务 ID：{{ props.id }}</p>
</template>
<script setup>
const props = defineProps({
  id: { type: String, required: true }
})
</script>

props 传参（推荐）

props: true 让路由参数作为组件 props 传入，组件与路由解耦。上面的 TaskDetail.vue 就是完整写法。

直接读取路由参数（可选）

如果不使用 props: true，也可以在组件中直接读取当前路由：

<script setup>
import { useRoute } from 'vue-router'
const route = useRoute()
</script>
<template>
  <p>任务 ID：{{ route.params.id }}</p>
</template>

两种方式不要在同一个示例里混用。URL 参数默认是字符串，如需数值请在业务代码中显式转换。

易错点

  • 参数名不一致：路由定义 :id，获取应用 route.params.id。
  • 多个动态段：/users/:userId/posts/:postId，分别取 params.userId、params.postId。

小结

动态路由 :参数名 匹配 URL；route.params 获取；props: true 解耦传参。

知识点 K10-5：嵌套路由

定义

嵌套路由用 children 配置子路由，在父组件内用子 <router-view> 渲染，适合主从结构（如用户中心下有资料/密码子页）。

用法

const routes = [
  {
    path: '/user',
    component: () => import('../views/UserLayout.vue'),
    children: [
      { path: '', redirect: '/user/profile' }, // /user 自动进入 /user/profile
      { path: 'profile', component: () => import('../views/UserProfile.vue') },
      { path: 'password', component: () => import('../views/ChangePassword.vue') }
    ]
  }
]
<!-- UserLayout.vue -->
<template>
  <div class="user-layout">
    <nav>
      <router-link to="/user/profile">资料</router-link>
      <router-link to="/user/password">密码</router-link>
    </nav>
    <router-view />          <!-- 子路由渲染处 -->
  </div>
</template>

路径拼接规则

  • 子路由 path 以 / 开头：绝对路径，不与父拼接。
  • 子路由 path 不以 / 开头：相对，拼接父 path（如父 /user + 子 profile = /user/profile）。

空字符串 path: '' 表示父路径本身的默认子路由；示例用绝对目标 redirect: '/user/profile' 把 /user 导向已有的资料页，避免为同一页面重复配置两个路由。

易错点

  • 忘在父组件写子 <router-view>：子路由无处渲染。
  • 子 path 加了 / 但想拼接：以 / 开头是绝对路径，不拼接。

小结

嵌套路由用 children，父组件内放子 <router-view>；子 path 不以 / 开头则与父拼接。

三、综合示例：CTTS-Frontend 路由配置

3.1 从零运行

下面的案例从空目录创建一个完整的 Vue Router 项目，涵盖重定向、声明式导航、编程式导航、动态参数、查询参数、嵌套路由、404 和路由懒加载。

  1. 执行 Vite 创建命令并安装依赖。
  2. 用 3.2 的文件内容覆盖 src/App.vue、src/main.js，并创建 src/router、src/views 中的文件。
  3. 执行 npm run dev，打开终端显示的本地地址。
  4. 依次验证根路径重定向、项目链接、任务动态参数、用户中心子路由、登录页和不存在路径。
npm create vite@latest ctts-router -- --template vue
cd ctts-router
npm install
npm install vue-router@4
npm run dev

示例使用 createWebHistory()，Vite 开发服务器可直接运行；部署到生产服务器时，必须把未知路径回退到 index.html，否则直接刷新 /projects 等地址可能返回 404。

3.2 文件结构与完整代码

src/
├─ App.vue
├─ main.js
├─ router/
│  └─ index.js
└─ views/
   ├─ Layout.vue
   ├─ Login.vue
   ├─ Projects.vue
   ├─ TaskDetail.vue
   ├─ User.vue
   ├─ UserProfile.vue
   ├─ ChangePassword.vue
   └─ NotFound.vue

src/router/index.js：布局和页面组件都采用懒加载，根路径通过 redirect 重定向到项目列表。

import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  { path: '/', redirect: '/projects' },
  { path: '/login', component: () => import('../views/Login.vue') },
  {
    path: '/',
    component: () => import('../views/Layout.vue'),
    children: [
      { path: 'projects', component: () => import('../views/Projects.vue') },
      { path: 'tasks/:id', component: () => import('../views/TaskDetail.vue'), props: true },
      {
        path: 'user',
        component: () => import('../views/User.vue'),
        children: [
          { path: '', redirect: '/user/profile' },
          { path: 'profile', component: () => import('../views/UserProfile.vue') },
          { path: 'password', component: () => import('../views/ChangePassword.vue') }
        ]
      }
    ]
  },
  { path: '/:pathMatch(.*)*', component: () => import('../views/NotFound.vue') }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

export default router
