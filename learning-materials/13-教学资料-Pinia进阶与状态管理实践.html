二、知识点详解

知识点 K13-1：多 store 管理

定义

按职责把全局状态拆分到多个 store，每个 store 单一职责，便于维护。

CTTS-Frontend store 规划

store 职责 主要状态
userStore 用户登录与信息 token、userInfo
projectStore 项目数据缓存 projects、total
appStore 全局 UI 状态 sidebarCollapsed、theme

知识点 K13-2：store 间相互引用

定义

在 action 中调用其他 store：const other = useXxxStore()。

用法

// stores/project.js
import { defineStore } from 'pinia'
import { useUserStore } from './user'

export const useProjectStore = defineStore('project', {
  state: () => ({ projects: [] }),
  actions: {
    async fetchProjects() {
      const userStore = useUserStore()      // 引用其他 store
      if (!userStore.isLogin) return        // 未登录不请求
      // 实际调接口（第 14 次课）
      this.projects = [{ id: 1, title: '项目一' }]
    }
  }
})

易错点

  • 循环引用：A 引用 B，B 引用 A，应在 action 内部调用（不在顶层），避免初始化死循环。
  • 顶层调用：useXxxStore() 必须在 setup 或 action 内调用，不能在 store 顶层。

小结

store 间在 action 内用 useXxxStore() 互相调用；避免循环引用与顶层调用。

知识点 K13-3：状态持久化

定义

把状态存到 localStorage，刷新页面后从 localStorage 恢复，保持状态不丢失。

用法（手动持久化）

// stores/user.js
export const useUserStore = defineStore('user', {
  state: () => ({
    token: localStorage.getItem('token') || '',           // 初始化恢复
    userInfo: JSON.parse(localStorage.getItem('userInfo') || 'null')
  }),
  actions: {
    login(token, userInfo) {
      this.token = token
      this.userInfo = userInfo
      localStorage.setItem('token', token)                // 持久化
      localStorage.setItem('userInfo', JSON.stringify(userInfo))
    },
    logout() {
      this.token = ''
      this.userInfo = null
      localStorage.removeItem('token')
      localStorage.removeItem('userInfo')
    }
  }
})

用 $subscribe 自动持久化

// 在组件或 store 中监听变化自动存储
userStore.$subscribe((mutation, state) => {
  localStorage.setItem('token', state.token)
  localStorage.setItem('userInfo', JSON.stringify(state.userInfo))
})

插件方式（pinia-plugin-persistedstate）

npm install pinia-plugin-persistedstate
// main.js
import { createPinia } from 'pinia'
import piniaPluginPersistedstate from 'pinia-plugin-persistedstate'
const pinia = createPinia()
pinia.use(piniaPluginPersistedstate)
app.use(pinia)
// store 中开启
export const useUserStore = defineStore('user', {
  state: () => ({ token: '', userInfo: null }),
  persist: true          // 自动持久化
})

易错点

  • 持久化敏感数据：token 存 localStorage 有 XSS 风险，生产环境可考虑 httpOnly cookie。
  • 持久化大对象：避免存过大数据，影响性能。

小结

持久化用 localStorage 存取或 $subscribe 自动存；插件 pinia-plugin-persistedstate 可自动持久化。

知识点 K13-4：$reset / $patch / $subscribe

$reset

重置 state 到初始值：

userStore.$reset()       // state 恢复到 state() 返回的初始值

$patch

批量修改 state：

userStore.$patch({ token: 'a', userInfo: { name: 'x' } })
userStore.$patch(state => { state.token = 'a' })

$subscribe

监听 state 变化：

userStore.$subscribe((mutation, state) => {
  console.log('state 变了', state)
})

易错点

  • 组合式 store 无 $reset：Setup Store（组合式写法）默认无 $reset，需自行实现。
  • $subscribe 不自动解绑：组件内用需手动解绑或在 onUnmounted 清理。

小结

$reset 重置、$patch 批量改、$subscribe 监听变化；组合式 store 无默认 $reset。

三、综合示例：CTTS-Frontend 三个 store

src/stores/user.js（见第 12 次课综合示例，含 localStorage 持久化）。

src/stores/project.js：

import { defineStore } from 'pinia'
import { useUserStore } from './user'

export const useProjectStore = defineStore('project', {
  state: () => ({
    projects: [],
    total: 0
  }),
  getters: {
    projectCount: (state) => state.projects.length
  },
  actions: {
    async fetchProjects() {
      const userStore = useUserStore()
      if (!userStore.isLogin) return
      // 简化：实际调接口
      this.projects = [
        { id: 1, title: '项目一：JavaWeb', status: '进行中' },
        { id: 2, title: '项目二：Vue3', status: '进行中' }
      ]
      this.total = this.projects.length
    },
    reset() {
      this.$reset()
    }
  }
})

src/stores/app.js：

import { defineStore } from 'pinia'

export const useAppStore = defineStore('app', {
  state: () => ({
    sidebarCollapsed: localStorage.getItem('sidebar') === 'true'
  }),
  actions: {
    toggleSidebar() {
      this.sidebarCollapsed = !this.sidebarCollapsed
      localStorage.setItem('sidebar', this.sidebarCollapsed)
    }
  }
})

组件中使用：

<template>
  <div :class="{ collapsed: appStore.sidebarCollapsed }">
    <button @click="appStore.toggleSidebar">切换侧边栏</button>
    <p>项目数：{{ projectStore.projectCount }}</p>
    <button @click="projectStore.fetchProjects">加载项目</button>
  </div>
</template>
<script setup>
import { useAppStore } from '../stores/app'
import { useProjectStore } from '../stores/project'
const appStore = useAppStore()
const projectStore = useProjectStore()
</script>

运行方式：配置三个 store，组件中调用；切换侧边栏后刷新页面状态保留（持久化）。

四、实践复盘要点

常见问题 解决
解构 store 丢失响应式 用 storeToRefs
store 间循环引用 在 action 内调用，不在顶层
刷新后状态丢失 用 localStorage 持久化
组合式 store 无 $reset 自行实现 reset action
持久化大对象性能差 只持久化必要状态
