二、知识点详解

知识点 K8-1：默认插槽

定义

插槽（slot） 让父组件向子组件传递模板内容，子组件用 <slot> 作为占位。默认插槽是无 name 的插槽。

用法

<!-- 子组件 Card.vue -->
<template>
  <div class="card">
    <slot>默认内容（无传入时显示）</slot>   <!-- 占位 + 后备内容 -->
  </div>
</template>
<!-- 父组件 -->
<template>
  <Card>
    <p>这是父组件传给 Card 的内容</p>
  </Card>
</template>
<script setup>
import Card from './Card.vue'
</script>

后备内容

<slot>默认值</slot> 中的内容在父组件不传时显示。

易错点

  • 把内容写在子组件模板里而非 slot：子组件模板里写死的内容无法被父组件替换；要用 <slot> 占位。
  • 忘写 <slot>：父组件传入的内容无处渲染。

小结

默认插槽用 <slot> 占位，父组件传入内容替换；可设后备内容。

知识点 K8-2：具名插槽

定义

具名插槽 用 name 属性区分多个插槽，父组件用 v-slot:name（简写 #name）指定内容放入哪个插槽。

用法

<!-- 子组件 Layout.vue -->
<template>
  <div class="layout">
    <header><slot name="header"></slot></header>
    <main><slot></slot></main>              <!-- 默认插槽（name 隐式 default） -->
    <footer><slot name="footer"></slot></footer>
  </div>
</template>
<!-- 父组件 -->
<template>
  <Layout>
    <template #header>
      <h1>标题</h1>
    </template>
    <p>主体内容（放默认插槽）</p>
    <template #footer>
      <p>底部</p>
    </template>
  </Layout>
</template>
<script setup>
import Layout from './Layout.vue'
</script>

简写

v-slot:header 简写为 #header。默认插槽用 v-slot:default 或 #default，或直接写内容（不包 template）。

易错点

  • #name 用在普通元素上：v-slot 只能用在 <template> 或组件上，不能用在普通 <div>。
  • 默认插槽与具名混用：未指定 name 的内容放默认插槽。

小结

具名插槽用 name 区分，父用 #name 指定；适合多区域布局（header/main/footer）。

知识点 K8-3：作用域插槽

定义

作用域插槽 让子组件把数据传给插槽内容，父组件根据子组件数据自定义渲染。

用法

<!-- 子组件 List.vue -->
<template>
  <ul>
    <li v-for="(item, i) in items" :key="item.id">
      <slot :item="item" :index="i"></slot>   <!-- 把 item 传给父 -->
    </li>
  </ul>
</template>
<script setup>
import { ref } from 'vue'
const items = ref([{ id: 1, name: 'A' }, { id: 2, name: 'B' }])
</script>
<!-- 父组件 -->
<template>
  <List>
    <template #default="{ item, index }">       <!-- 接收子组件传的 item/index -->
      <span>{{ index + 1 }}. 自定义：{{ item.name }}</span>
    </template>
  </List>
</template>
<script setup>
import List from './List.vue'
</script>

解构

v-slot="slotProps" 接收所有插槽 props；v-slot="{ item }" 解构取需要的。

易错点

  • 父组件拿不到子组件数据：忘了在 <slot> 上绑定 :item，或父没解构。
  • 解构名与绑定名不一致：子绑 :item，父应用 { item } 解构。

小结

作用域插槽：子用 <slot :data="x"> 传数据，父用 v-slot="{ data }" 接收，实现父自定义渲染。

知识点 K8-4：动态组件与 keep-alive

定义

动态组件 用 <component :is="组件名"> 动态切换渲染的组件，适合标签页等场景。keep-alive 缓存切换走的组件状态，避免重建。

用法

<template>
  <div>
    <button type="button" @click="current = 'A'">A</button>
    <button type="button" @click="current = 'B'">B</button>
    <keep-alive>
      <component :is="currentComp" />
    </keep-alive>
  </div>
</template>
<script setup>
import { ref, computed } from 'vue'
import CompA from './CompA.vue'
import CompB from './CompB.vue'
const current = ref('A')
const currentComp = computed(() => current.value === 'A' ? CompA : CompB)
</script>

为了让示例可以直接运行，再创建两个带本地状态的组件：

<!-- CompA.vue -->
<template>
  <section>
    <h3>组件 A</h3>
    <label>A 的草稿：<input v-model="draft" /></label>
  </section>
</template>
<script setup>
import { ref } from 'vue'
const draft = ref('切换后仍保留')
</script>

<!-- CompB.vue -->
<template>
  <section>
    <h3>组件 B</h3>
    <p>B 组件已挂载，切回 A 可观察 keep-alive 的缓存效果。</p>
  </section>
</template>

验证步骤：把父组件、CompA.vue、CompB.vue 放在同一目录并运行项目；在 A 的输入框输入文字，切换到 B 再切回 A，文字仍在即表示缓存生效。暂时删除 <keep-alive> 的包裹再试一次，可对比状态被重置的结果。

keep-alive

  • 不加 keep-alive：切换时组件销毁重建，状态丢失。
  • 加 keep-alive：组件缓存，切换回来状态保留。
  • include/exclude/max 控制缓存。

易错点

  • :is 用字符串但未全局注册：局部注册的组件需用组件引用（变量），不能用字符串名。
  • markRaw/shallowRef：组件赋给响应式数据建议用 shallowRef 避免不必要的深层响应式开销。

小结

<component :is> 动态切换组件；keep-alive 缓存组件状态，适合频繁切换。

知识点 K8-5：异步组件

定义

异步组件 用 defineAsyncComponent 按需加载组件，只在需要时才请求加载，优化首屏性能。

用法

<script setup>
import { defineAsyncComponent } from 'vue'
// 按需加载（动态 import）
const HeavyComp = defineAsyncComponent(() => import('./HeavyComp.vue'))
</script>
<template>
  <HeavyComp />
</template>

注意：下面的高级配置是对上面基础写法的替换，请二选一，不要把两段代码同时放进同一个 <script setup>，否则会重复声明 HeavyComp。

高级配置必须传入真实的加载中和失败组件，不能直接写未定义的变量：

<script setup>
import { defineAsyncComponent } from 'vue'
import LoadingState from './LoadingState.vue'
import ErrorState from './ErrorState.vue'

const HeavyComp = defineAsyncComponent({
  loader: () => import('./HeavyComp.vue'),
  loadingComponent: LoadingState,
  errorComponent: ErrorState,
  delay: 200,
  timeout: 3000
})
</script>
<template>
  <HeavyComp />
</template>

配套文件：将下面三个文件放在同一目录。正常加载会看到成功状态；加载失败时才会显示错误状态。

<!-- LoadingState.vue -->
<template><p>正在加载高级面板……</p></template>

<!-- ErrorState.vue -->
<template><p class="error">高级面板加载失败，请稍后重试。</p></template>
<style scoped>.error { color: #b91c1c; }</style>

<!-- HeavyComp.vue -->
<template>
  <section>
    <h3>异步加载完成</h3>
    <p>这个组件在首次渲染时才被请求。</p>
  </section>
</template>

验证状态：首次加载很快时可能看不到 loading，这是正常的；可在浏览器开发者工具中开启网络限速后刷新。要验证错误状态，可暂时把 loader 改成 import('./NotFound.vue') 并刷新，确认看到 ErrorState，再改回 ./HeavyComp.vue。

易错点

  • 滥用异步组件：小组件无需异步，反而增加请求开销；大组件/路由级才用。
  • 路由懒加载更常用：路由组件懒加载（第 11 次课）比异步组件更常用。

小结

defineAsyncComponent 按需加载组件，优化首屏；适合大组件，小组件不必。

三、综合示例：通用 Card 组件与动态标签页

3.1 从零运行

这个综合案例同时验证具名插槽、默认插槽、动态组件和 keep-alive。请按下面步骤创建项目，所有文件代码均在本节给出。

  1. 执行 npm create vite@latest ctts-slots -- --template vue，进入目录后执行 npm install。
  2. 创建 src/components 文件夹，并按 3.2 的文件结构创建四个文件。
  3. 执行 npm run dev，打开终端显示的本地地址。
  4. 依次点击“卡片”“任务”“用户”；在任务或用户页面输入内容，再切换页面回来，确认状态仍然保留。
npm create vite@latest ctts-slots -- --template vue
cd ctts-slots
npm install
npm run dev

3.2 文件结构与完整代码

src/
├─ App.vue
└─ components/
   ├─ Card.vue
   ├─ TaskList.vue
   └─ UserInfo.vue

通用 Card.vue（具名插槽）：

<template>
  <div class="card">
    <div class="card-header" v-if="$slots.header">
      <slot name="header"></slot>
    </div>
    <div class="card-body">
      <slot></slot>
    </div>
    <div class="card-footer" v-if="$slots.footer">
      <slot name="footer"></slot>
    </div>
  </div>
</template>
<style scoped>
.card { border: 1px solid #ddd; border-radius: 8px; max-width: 400px; margin: 10px; }
.card-header { padding: 10px; border-bottom: 1px solid #eee; font-weight: bold; }
.card-body { padding: 12px; }
.card-footer { padding: 10px; border-top: 1px solid #eee; }
</style>

动态标签页 App.vue：

<template>
  <div class="tabs">
    <button v-for="tab in tabs" :key="tab.name" type="button" @click="selectTab(tab)">
      {{ tab.label }}
    </button>
    <keep-alive>
      <Card v-if="activeName === 'card'">
        <template #header>
          <h2>通用卡片标题</h2>
        </template>
        <p>这段文字来自 App.vue 的默认插槽。</p>
        <template #footer>
          <small>这段文字来自 footer 插槽。</small>
        </template>
      </Card>
      <component v-else :is="current" />
    </keep-alive>
  </div>
</template>
<script setup>
import { ref, shallowRef } from 'vue'
import Card from './components/Card.vue'
import TaskList from './components/TaskList.vue'
import UserInfo from './components/UserInfo.vue'
const tabs = [
  { label: '卡片', name: 'card', comp: Card },
  { label: '任务', name: 'task', comp: TaskList },
  { label: '用户', name: 'user', comp: UserInfo }
]
const activeName = ref('card')
const current = shallowRef(Card)
const selectTab = (tab) => {
  activeName.value = tab.name
  current.value = tab.comp
}
</script>

TaskList.vue：

<template>
  <section class="panel">
    <h2>任务列表</h2>
    <form @submit.prevent="addTask">
      <input v-model.trim="draft" placeholder="输入任务" />
      <button type="submit">添加</button>
    </form>
    <ul>
      <li v-for="task in tasks" :key="task.id">{{ task.title }}</li>
    </ul>
  </section>
</template>
<script setup>
import { ref } from 'vue'

const draft = ref('')
const nextId = ref(3)
const tasks = ref([
  { id: 1, title: '阅读插槽文档' },
  { id: 2, title: '完成动态组件练习' }
])

const addTask = () => {
  if (!draft.value) return
  tasks.value.push({ id: nextId.value++, title: draft.value })
  draft.value = ''
}
</script>
<style scoped>
.panel { padding: 16px; border: 1px solid #d1d5db; }
input { margin-right: 8px; padding: 6px; }
</style>

UserInfo.vue：

<template>
  <section class="panel">
    <h2>用户信息</h2>
    <label>昵称：<input v-model="name" /></label>
    <p>当前昵称：{{ name || '未填写' }}</p>
  </section>
</template>
<script setup>
import { ref } from 'vue'
const name = ref('小林')
</script>
<style scoped>
.panel { padding: 16px; border: 1px solid #d1d5db; }
input { padding: 6px; }
</style>

运行结果检查：Card 页显示 header/body/footer 三个区域；TaskList 页可以添加任务；UserInfo 页可以编辑昵称。切换标签后，任务和昵称仍保留，说明 keep-alive 正在缓存组件实例。
