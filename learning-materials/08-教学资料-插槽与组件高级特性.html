二、知识点详解

知识点 K8-1：默认插槽

定义

插槽（slot） 让父组件向子组件传递模板内容，子组件用 <slot> 作为占位。默认插槽是无 name 的插槽。

用法

<!-- 子组件 Card.vue -->
<template>
  <div class="card">
    <slot>默认内容（无传入时显示）</slot>   <!-- 占位 + 后备内容 -->
  </div>
</template>
<!-- 父组件 -->
<template>
  <Card>
    <p>这是父组件传给 Card 的内容</p>
  </Card>
</template>
<script setup>
import Card from './Card.vue'
</script>

后备内容

<slot>默认值</slot> 中的内容在父组件不传时显示。

易错点

  • 把内容写在子组件模板里而非 slot：子组件模板里写死的内容无法被父组件替换；要用 <slot> 占位。
  • 忘写 <slot>：父组件传入的内容无处渲染。

小结

默认插槽用 <slot> 占位，父组件传入内容替换；可设后备内容。

知识点 K8-2：具名插槽

定义

具名插槽 用 name 属性区分多个插槽，父组件用 v-slot:name（简写 #name）指定内容放入哪个插槽。

用法

<!-- 子组件 Layout.vue -->
<template>
  <div class="layout">
    <header><slot name="header"></slot></header>
    <main><slot></slot></main>              <!-- 默认插槽（name 隐式 default） -->
    <footer><slot name="footer"></slot></footer>
  </div>
</template>
<!-- 父组件 -->
<template>
  <Layout>
    <template #header>
      <h1>标题</h1>
    </template>
    <p>主体内容（放默认插槽）</p>
    <template #footer>
      <p>底部</p>
    </template>
  </Layout>
</template>

简写

v-slot:header 简写为 #header。默认插槽用 v-slot:default 或 #default，或直接写内容（不包 template）。

易错点

  • #name 用在普通元素上：v-slot 只能用在 <template> 或组件上，不能用在普通 <div>。
  • 默认插槽与具名混用：未指定 name 的内容放默认插槽。

小结

具名插槽用 name 区分，父用 #name 指定；适合多区域布局（header/main/footer）。

知识点 K8-3：作用域插槽

定义

作用域插槽 让子组件把数据传给插槽内容，父组件根据子组件数据自定义渲染。

用法

<!-- 子组件 List.vue -->
<template>
  <ul>
    <li v-for="item in items" :key="item.id">
      <slot :item="item" :index="i"></slot>   <!-- 把 item 传给父 -->
    </li>
  </ul>
</template>
<script setup>
import { ref } from 'vue'
const items = ref([{ id: 1, name: 'A' }, { id: 2, name: 'B' }])
</script>
<!-- 父组件 -->
<template>
  <List>
    <template #default="{ item }">       <!-- 接收子组件传的 item -->
      <span>自定义：{{ item.name }}</span>
    </template>
  </List>
</template>
<script setup>
import List from './List.vue'
</script>

解构

v-slot="slotProps" 接收所有插槽 props；v-slot="{ item }" 解构取需要的。

易错点

  • 父组件拿不到子组件数据：忘了在 <slot> 上绑定 :item，或父没解构。
  • 解构名与绑定名不一致：子绑 :item，父应用 { item } 解构。

小结

作用域插槽：子用 <slot :data="x"> 传数据，父用 v-slot="{ data }" 接收，实现父自定义渲染。

知识点 K8-4：动态组件与 keep-alive

定义

动态组件 用 <component :is="组件名"> 动态切换渲染的组件，适合标签页等场景。keep-alive 缓存切换走的组件状态，避免重建。

用法

<template>
  <div>
    <button @click="current = 'CompA'">A</button>
    <button @click="current = 'CompB'">B</button>
    <keep-alive>
      <component :is="currentComp" />
    </keep-alive>
  </div>
</template>
<script setup>
import { ref, computed, shallowRef } from 'vue'
import CompA from './CompA.vue'
import CompB from './CompB.vue'
const current = ref('A')
const currentComp = computed(() => current.value === 'A' ? CompA : CompB)
// 或用 shallowRef 直接存组件
</script>

keep-alive

  • 不加 keep-alive：切换时组件销毁重建，状态丢失。
  • 加 keep-alive：组件缓存，切换回来状态保留。
  • include/exclude/max 控制缓存。

易错点

  • :is 用字符串但未全局注册：局部注册的组件需用组件引用（变量），不能用字符串名。
  • markRaw/shallowRef：组件赋给响应式数据建议用 shallowRef 避免不必要的深层响应式开销。

小结

<component :is> 动态切换组件；keep-alive 缓存组件状态，适合频繁切换。

知识点 K8-5：异步组件

定义

异步组件 用 defineAsyncComponent 按需加载组件，只在需要时才请求加载，优化首屏性能。

用法

<script setup>
import { defineAsyncComponent } from 'vue'
// 按需加载（动态 import）
const HeavyComp = defineAsyncComponent(() => import('./HeavyComp.vue'))
</script>
<template>
  <HeavyComp />
</template>

高级配置（加载状态/错误处理）：

const HeavyComp = defineAsyncComponent({
  loader: () => import('./HeavyComp.vue'),
  loadingComponent: Loading,       // 加载中显示
  errorComponent: Error,           // 加载失败显示
  delay: 200,                      // 延迟显示 loading
  timeout: 3000                    // 超时
})

易错点

  • 滥用异步组件：小组件无需异步，反而增加请求开销；大组件/路由级才用。
  • 路由懒加载更常用：路由组件懒加载（第 11 次课）比异步组件更常用。

小结

defineAsyncComponent 按需加载组件，优化首屏；适合大组件，小组件不必。

三、综合示例：通用 Card 组件与动态标签页

通用 Card.vue（具名插槽）：

<template>
  <div class="card">
    <div class="card-header" v-if="$slots.header">
      <slot name="header"></slot>
    </div>
    <div class="card-body">
      <slot></slot>
    </div>
    <div class="card-footer" v-if="$slots.footer">
      <slot name="footer"></slot>
    </div>
  </div>
</template>
<style scoped>
.card { border: 1px solid #ddd; border-radius: 8px; max-width: 400px; margin: 10px; }
.card-header { padding: 10px; border-bottom: 1px solid #eee; font-weight: bold; }
.card-body { padding: 12px; }
.card-footer { padding: 10px; border-top: 1px solid #eee; }
</style>

动态标签页 App.vue：

<template>
  <div class="tabs">
    <button v-for="tab in tabs" :key="tab.name" @click="current = tab.comp">
      {{ tab.label }}
    </button>
    <keep-alive>
      <component :is="current" />
    </keep-alive>
  </div>
</template>
<script setup>
import { shallowRef } from 'vue'
import Card from './components/Card.vue'
import TaskList from './components/TaskList.vue'
import UserInfo from './components/UserInfo.vue'
const tabs = [
  { label: '卡片', name: 'card', comp: Card },
  { label: '任务', name: 'task', comp: TaskList },
  { label: '用户', name: 'user', comp: UserInfo }
]
const current = shallowRef(Card)
</script>

运行方式：创建 Card.vue 与简单 TaskList.vue、UserInfo.vue，点击按钮切换组件；keep-alive 缓存状态。
