二、知识点详解

知识点 K3-1：文本插值（Mustache）

定义

文本插值用双花括号 {{ }}（Mustache 语法）把响应式数据渲染到模板文本中，数据变化时文本自动更新。

原理

{{ 表达式 }} 中的表达式会被求值并转成字符串显示。可放变量、运算、三元、方法调用等。

<template>
  <p>{{ message }}</p>              <!-- 变量 -->
  <p>{{ count + 1 }}</p>            <!-- 运算 -->
  <p>{{ ok ? '是' : '否' }}</p>     <!-- 三元 -->
  <p>{{ sayHi() }}</p>              <!-- 方法调用 -->
</template>
<script setup>
import { ref } from 'vue'
const message = ref('Hello')
const count = ref(10)
const ok = ref(true)
const sayHi = () => 'Hi'
</script>

易错点

  • {{ }} 不能用于 HTML 属性：<img src="{{ url }}"> 是错的，应用 v-bind：<img :src="url">。
  • {{ }} 输出纯文本：不会解析 HTML 标签。要渲染 HTML 用 v-html（注意 XSS 风险）。

小结

{{ }} 用于文本内容渲染，响应式更新；不能用于属性。

知识点 K3-2：属性绑定 v-bind

定义

v-bind 用于将数据绑定到 HTML 属性上，可简写为 :。

原理与用法

<template>
  <img v-bind:src="imgUrl" />     <!-- 完整写法 -->
  <img :src="imgUrl" />            <!-- 简写（推荐） -->
  <a :href="link" :title="tip">链接</a>
  <button :disabled="isDisabled">按钮</button>
</template>
<script setup>
import { ref } from 'vue'
const imgUrl = ref('/logo.png')
const link = ref('https://vuejs.org')
const tip = ref('Vue 官网')
const isDisabled = ref(true)
</script>

绑定 class（对象语法、数组语法）：

<template>
  <!-- 对象语法：键为类名，值为布尔决定是否生效 -->
  <div :class="{ active: isActive, 'text-danger': hasError }"></div>
  <!-- 数组语法 -->
  <div :class="[baseClass, isActive ? 'active' : '']"></div>
</template>

绑定 style（对象语法）：

<template>
  <div :style="{ color: textColor, fontSize: size + 'px' }"></div>
</template>

易错点

  • 属性名大小写：HTML 属性不区分大小写，绑定自定义属性注意用短横线（kebab-case）。
  • class 对象语法与字符串混用：<div class="base" :class="{active: isActive}"> 可共存，普通 class 与 :class 会合并。

小结

v-bind（简写 :）绑定 HTML 属性，支持 class/style 对象与数组语法。

知识点 K3-3：事件绑定 v-on

定义

v-on 用于绑定 DOM 事件，可简写为 @。

原理与用法

<template>
  <button v-on:click="handleClick">点击</button>   <!-- 完整 -->
  <button @click="handleClick">点击</button>        <!-- 简写（推荐） -->
  <button @click="count++">+1</button>              <!-- 内联语句 -->
  <button @click="say('hi', $event)">传参+事件对象</button>
</template>
<script setup>
import { ref } from 'vue'
const count = ref(0)
const handleClick = (e) => { console.log('事件对象', e) }
const say = (msg, e) => { console.log(msg, e) }
</script>

事件对象 $event：内联语句中要访问原生事件对象，用 $event；方法直接作为事件处理时（@click="handleClick"），第一个参数即事件对象。

易错点

  • @click="handleClick()" vs @click="handleClick"：前者立即调用（需手动传 $event）；后者把方法引用交给事件，事件触发时调用（自动接收事件对象）。
  • 方法名拼错：模板里方法名必须与 script 中一致，否则报错。

小结

v-on（简写 @）绑定事件；内联语句用 $event 访问事件对象。

知识点 K3-4：双向绑定 v-model

定义

v-model 在表单元素上实现双向绑定：数据→视图（更新 value），视图→数据（输入同步回数据）。

原理

v-model 本质是 :value + @input 的语法糖：

<input v-model="text" />
<!-- 等价于 -->
<input :value="text" @input="text = $event.target.value" />

用法

<template>
  <input v-model="text" placeholder="输入" />
  <p>你输入了：{{ text }}</p>

  <textarea v-model="desc"></textarea>

  <select v-model="selected">
    <option value="a">A</option>
    <option value="b">B</option>
  </select>
  <p>选择了：{{ selected }}</p>
</template>
<script setup>
import { ref } from 'vue'
const text = ref('')
const desc = ref('')
const selected = ref('a')
</script>

易错点

  • v-model 只能用于表单元素（input/textarea/select 等），不能用于普通 div。
  • 单选/多选用 v-model 需配合 value 属性（第 5 次课详讲）。

小结

v-model 实现表单双向绑定，是 :value + @input 语法糖。

知识点 K3-5：条件渲染 v-if / v-show

定义

  • v-if：条件为真时渲染元素，为假时删除元素（不占 DOM）。
  • v-show：通过切换 display: none 控制显隐，元素始终存在于 DOM。

原理与对比

<template>
  <p v-if="score >= 60">及格</p>
  <p v-else-if="score >= 50">补考</p>
  <p v-else>不及格</p>

  <div v-show="isVisible">始终在 DOM，仅切 display</div>
</template>
特性 v-if v-show
实现方式 删除/重建 DOM 切换 display
初始渲染 假则不渲染 始终渲染
切换开销 高（重建） 低（仅样式）
初始开销 低（惰性） 高（始终渲染）
适用场景 一次性/少切换 频繁切换

易错点

  • v-if 与 v-else 之间不能有其他元素，否则 v-else 失效。
  • v-if 与 v-for 不要同级使用（详见 K3-6）。
  • v-show 不支持 <template> 与 v-else。

小结

频繁切换用 v-show，一次性/少切换用 v-if。

知识点 K3-6：列表渲染 v-for 与 :key

定义

v-for 根据数据遍历渲染一组元素，需为每项提供唯一稳定的 :key。

原理与用法

<template>
  <!-- 遍历数组 -->
  <li v-for="(item, index) in list" :key="item.id">
    {{ index }} - {{ item.title }}
  </li>

  <!-- 遍历对象 -->
  <li v-for="(value, key) in obj" :key="key">{{ key }}: {{ value }}</li>

  <!-- 遍历数字 -->
  <span v-for="n in 5" :key="n">{{ n }}</span>
</template>
<script setup>
import { ref } from 'vue'
const list = ref([
  { id: 1, title: '项目一' },
  { id: 2, title: '项目二' }
])
const obj = ref({ name: 'Vue', version: 3 })
</script>

:key 的重要性

:key 帮助 Vue 识别每个节点，高效复用与更新。key 必须唯一且稳定：

  • ✅ 用数据的唯一 id：:key="item.id"
  • ❌ 用 index：:key="index"（列表增删时会错位、性能差）
  • ❌ 用随机数（每次变，失去复用意义）

v-if 与 v-for 混用的坑

<!-- ❌ 错误：Vue3 中 v-if 优先级高于 v-for，会取不到 item -->
<li v-for="item in list" v-if="item.active" :key="item.id"></li>

<!-- ✅ 正确：用 computed 过滤 -->
<li v-for="item in activeList" :key="item.id"></li>

易错点

  • 忘加 :key：Vue 会警告，影响更新。
  • 用 index 作 key：列表插入/删除时状态错乱。
  • v-if 与 v-for 同级：Vue 3 报错或行为异常。

小结

v-for 遍历数组/对象/数字，必须提供唯一稳定的 :key，避免与 v-if 同级。

知识点 K3-7：指令修饰符

定义

修饰符是以 . 指明的特殊后缀，简化常见操作。

常用修饰符

修饰符 用于 作用
.stop v-on 阻止事件冒泡（event.stopPropagation()）
.prevent v-on 阻止默认行为（event.preventDefault()）
.once v-on 事件只触发一次
.capture v-on 使用捕获模式
.self v-on 仅事件源是元素自身才触发
.enter/.esc 等 v-on 按键修饰符（第 5 次课详讲）
.lazy v-model 失焦时才同步（非实时）
.number v-model 转为数字
.trim v-model 去首尾空格 
<template>
  <form @submit.prevent="onSubmit">       <!-- 阻止默认提交 -->
    <button @click.stop="doSomething">    <!-- 阻止冒泡 -->
    <button @click.once="onceFn">         <!-- 只触发一次 -->
    <input v-model.lazy="text">           <!-- 失焦同步 -->
    <input v-model.number="num">          <!-- 转数字 -->
    <input v-model.trim="text">           <!-- 去空格 -->
  </form>
</template>

易错点

  • 修饰符顺序：@click.prevent.stop 先 prevent 再 stop，顺序影响行为。
  • 修饰符只对对应指令有效：.lazy 只用于 v-model，不能用于 v-on。

小结

修饰符以 . 后缀简化常见操作，事件用 .stop/.prevent/.once，表单用 .lazy/.number/.trim。

三、综合示例：CTTS-Frontend 项目列表与搜索筛选

<template>
  <div class="projects">
    <h2>实训项目列表</h2>
    <input v-model="keyword" placeholder="搜索项目" />
    <select v-model="statusFilter">
      <option value="">全部状态</option>
      <option value="进行中">进行中</option>
      <option value="未开始">未开始</option>
    </select>

    <ul v-if="filteredProjects.length">
      <li v-for="p in filteredProjects" :key="p.id" :class="{ done: p.status === '进行中' }">
        <span>{{ p.title }}</span>
        <span class="status">{{ p.status }}</span>
      </li>
    </ul>
    <p v-else>暂无匹配项目</p>

    <button @click="reset">重置筛选</button>
  </div>
</template>

<script setup>
import { ref, computed } from 'vue'

const keyword = ref('')
const statusFilter = ref('')
const projects = ref([
  { id: 1, title: '项目一：JavaWeb', status: '进行中' },
  { id: 2, title: '项目二：Vue3', status: '进行中' },
  { id: 3, title: '项目三：全栈联调', status: '未开始' }
])

const filteredProjects = computed(() =>
  projects.value.filter(p =>
    p.title.includes(keyword.value) &&
    (statusFilter.value === '' || p.status === statusFilter.value)
  )
)

const reset = () => {
  keyword.value = ''
  statusFilter.value = ''
}
</script>

<style scoped>
.projects { max-width: 600px; margin: 20px auto; font-family: system-ui; }
ul { list-style: none; padding: 0; }
li { display: flex; justify-content: space-between; padding: 10px 0; border-bottom: 1px solid #eee; }
li.done { color: #42b883; }
.status { color: #999; font-size: 14px; }
input, select { padding: 6px; margin: 0 8px 10px 0; }
button { padding: 6px 16px; cursor: pointer; }
</style>

运行方式：替换 src/App.vue，npm run dev 访问。输入关键词或选择状态，列表实时过滤；无匹配显示"暂无匹配项目"。
