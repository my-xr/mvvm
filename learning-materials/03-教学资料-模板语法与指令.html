二、知识点详解

知识点 K3-1：文本插值（Mustache）

定义

文本插值用双花括号 {{ }}（Mustache 语法）把响应式数据渲染到模板文本中，数据变化时文本自动更新。

原理

{{ 表达式 }} 中的表达式会被求值并转成字符串显示。可放变量、运算、三元、方法调用等。

<template>
  <p>{{ message }}</p>              <!-- 变量 -->
  <p>{{ count + 1 }}</p>            <!-- 运算 -->
  <p>{{ ok ? '是' : '否' }}</p>     <!-- 三元 -->
  <p>{{ sayHi() }}</p>              <!-- 方法调用 -->
</template>
<script setup>
import { ref } from 'vue'
const message = ref('Hello')
const count = ref(10)
const ok = ref(true)
const sayHi = () => 'Hi'
</script>
<style scoped>
p { margin: 6px 0; }
</style>

易错点

  • {{ }} 不能用于 HTML 属性：<img src="{{ url }}"> 是错的，应用 v-bind：<img :src="url">。
  • {{ }} 输出纯文本：不会解析 HTML 标签。要渲染 HTML 用 v-html（注意 XSS 风险）。

v-html 与安全边界

v-html 会把字符串当作 HTML 插入 DOM，只能用于可信内容。用户评论、昵称、富文本等外部输入不能未经清洗就交给 v-html，否则可能产生 XSS。

<template>
  <h3>公告</h3>
  <p v-html="trustedNotice"></p>
  <p>普通插值会转义标签：{{ userText }}</p>
</template>
<script setup>
import { ref } from 'vue'

// 仅放入经过后端白名单清洗的内容；不要直接使用用户输入
const trustedNotice = ref('<strong>报名已开始</strong>：请按时提交。')
const userText = ref('<img src=x onerror=alert(1)>')
</script>
<style scoped>
h3 { color: #1e3a8a; }
</style>

小结

{{ }} 用于文本内容渲染，响应式更新；不能用于属性。

知识点 K3-2：属性绑定 v-bind

定义

v-bind 用于将数据绑定到 HTML 属性上，可简写为 :。

原理与用法

<template>
  <img v-bind:src="imgUrl" alt="Vue logo" />     <!-- 完整写法 -->
  <img :src="imgUrl" alt="Vue logo" />            <!-- 简写（推荐） -->
  <a :href="link" :title="tip">链接</a>
  <button :disabled="isDisabled">按钮</button>
</template>
<script setup>
import { ref } from 'vue'
// Vite 默认项目 public 目录中有 vite.svg；自己的图片也可放在 public 中
const imgUrl = ref('/vite.svg')
const link = ref('https://vuejs.org')
const tip = ref('Vue 官网')
const isDisabled = ref(true)
</script>
<style scoped>
img { width: 56px; vertical-align: middle; }
a { color: #2563eb; }
</style>
展开 class/style 进阶预览（第 06 课系统讲解）

本段只用于建立语法印象；完整的状态样式、列表状态和分页案例请学习第 06 课。

绑定 class（对象语法、数组语法）：

<template>
  <!-- 对象语法：键为类名，值为布尔决定是否生效 -->
  <p class="card" :class="{ active: isActive, 'text-danger': hasError }">对象语法</p>
  <!-- 数组语法 -->
  <p :class="[baseClass, isActive ? 'active' : '']">数组语法</p>
  <button @click="isActive = !isActive">切换 active</button>
  <button @click="hasError = !hasError">切换错误色</button>
</template>
<script setup>
import { ref } from 'vue'
const isActive = ref(true)
const hasError = ref(false)
const baseClass = ref('card')
</script>
<style scoped>
.card { padding: 10px; border: 1px solid #cbd5e1; }
.active { border-color: #2563eb; background: #eff6ff; }
.text-danger { color: #dc2626; }
button { margin: 8px 8px 0 0; }
</style>

绑定 style（对象语法）：

<template>
  <p :style="{ color: textColor, fontSize: size + 'px' }">动态样式文本</p>
  <button @click="size += 2">放大</button>
  <button @click="textColor = textColor === '#0f766e' ? '#7c3aed' : '#0f766e'">换色</button>
</template>
<script setup>
import { ref } from 'vue'
const textColor = ref('#0f766e')
const size = ref(18)
</script>
<style scoped>
button { margin-right: 8px; }
</style>

易错点

  • 属性名大小写：原生 HTML 属性名不区分大小写，但 Vue 组件 props 在脚本中通常用 camelCase、模板中用 kebab-case；自定义 DOM 属性也建议使用标准短横线写法。
  • class 对象语法与字符串混用：<div class="base" :class="{active: isActive}"> 可共存，普通 class 与 :class 会合并。

小结

v-bind（简写 :）绑定 HTML 属性，支持 class/style 对象与数组语法。

展开后续专题预览：事件、表单、条件、列表与修饰符（第 04~06 课深入）

知识点 K3-3：事件绑定 v-on

定义

v-on 用于绑定 DOM 事件，可简写为 @。

原理与用法

<template>
  <button v-on:click="handleClick">点击</button>   <!-- 完整 -->
  <button @click="handleClick">点击</button>        <!-- 简写（推荐） -->
  <button @click="count++">+1</button>              <!-- 内联语句 -->
  <button @click="say('hi', $event)">传参+事件对象</button>
  <p>点击次数：{{ count }}</p>
  <p>最近一次操作：{{ lastAction || '尚未点击' }}</p>
</template>
<script setup>
import { ref } from 'vue'
const count = ref(0)
const lastAction = ref('')
const handleClick = (e) => {
  count.value++
  lastAction.value = 'handleClick 收到 ' + e.type
  console.log('事件对象', e)
}
const say = (msg, e) => {
  lastAction.value = msg + ' / ' + e.type
  console.log(msg, e)
}
</script>
<style scoped>
button { margin: 4px; }
</style>

事件对象 $event：内联语句中要访问原生事件对象，用 $event；方法直接作为事件处理时（@click="handleClick"），第一个参数即事件对象。

易错点

  • @click="handleClick()" vs @click="handleClick"：两者都在点击发生时执行，前者是“事件发生后执行表达式并主动调用方法”，后者是直接传入方法引用；handleClick() 不会在模板渲染时立即执行。若要传参使用 @click="handleClick(id, $event)"。
  • 模板中的 ref 会自动解包：@click="count++" 在模板中是正确的；只有在 <script setup> 的 JavaScript 代码里才需要写 count.value++。
  • 方法名拼错：模板里方法名必须与 script 中一致，否则报错。

小结

v-on（简写 @）绑定事件；内联语句用 $event 访问事件对象。

知识点 K3-4：事件修饰符预览

事件修饰符紧跟事件绑定学习：用一个点号后缀表达阻止冒泡、阻止默认行为或限制触发次数。第 05 课会用完整交互案例深入验证这些行为。

写法作用原生等价思路
@click.stop阻止事件冒泡event.stopPropagation()
@submit.prevent阻止表单默认提交event.preventDefault()
@click.once只响应一次只保留第一次监听
@click.self只在点击元素自身时触发target === currentTarget
 
<template>
  <div class="panel" @click="parentClick">
    <button type="button" @click.stop="childClick">不冒泡</button>
    <button type="button" @click.once="onceClick">只触发一次</button>
  </div>
</template>
<script setup>
const parentClick = () => console.log('父级')
const childClick = () => console.log('子级')
const onceClick = () => console.log('第一次点击')
</script>

学习提示：按键修饰符（.enter、.esc）以及 v-model 的 .lazy/.number/.trim 会在第 05 课系统展开；本课只需记住修饰符的位置和作用。

小结

K3-3 负责“监听什么事件”，K3-4 负责“事件发生时附加什么规则”，两者应一起理解。

知识点 K3-5：双向绑定 v-model

定义

v-model 在表单元素上实现双向绑定：数据→视图（更新 value），视图→数据（输入同步回数据）。

原理

v-model 的具体等价关系取决于表单控件。下面先以文本输入框为例；这段是完整 SFC，两个输入框分别展示简写和展开写法。

<template>
  <label>简写：<input v-model="text" /></label>
  <label>展开：<input :value="text" @input="text = $event.target.value" /></label>
  <p>当前值：{{ text }}</p>
</template>
<script setup>
import { ref } from 'vue'
const text = ref('')
</script>
<style scoped>
label { display: block; margin: 8px 0; }
input { padding: 5px 8px; }
</style>
控件v-model 关注的属性同步事件注意点
文本 input / textareavalueinput输入时实时同步
checkboxchecked（多选时通常是数组）change多个复选框要设置不同 value
radiocheckedchange同一组使用相同 name，通过不同 value 区分
select选中值changeoption 的 value 决定写入的值

用法

<template>
  <input v-model="text" placeholder="输入" />
  <p>你输入了：{{ text }}</p>

  <textarea v-model="desc"></textarea>

  <select v-model="selected">
    <option value="a">A</option>
    <option value="b">B</option>
  </select>
  <p>选择了：{{ selected }}</p>

  <label><input type="checkbox" v-model="agreed" /> 同意条款</label>
  <p>是否同意：{{ agreed ? '是' : '否' }}</p>

  <label><input type="radio" name="role" value="student" v-model="role" /> 学生</label>
  <label><input type="radio" name="role" value="teacher" v-model="role" /> 教师</label>
  <p>角色：{{ role }}</p>
</template>
<script setup>
import { ref } from 'vue'
const text = ref('')
const desc = ref('')
const selected = ref('a')
const agreed = ref(false)
const role = ref('student')
</script>
<style scoped>
label { display: inline-block; margin: 6px 10px 6px 0; }
textarea { display: block; min-height: 60px; margin: 8px 0; }
</style>

易错点

  • 原生 v-model 主要用于表单元素（input/textarea/select 等），普通 div 没有可绑定的 value/checked 语义；组件上的 v-model 会在第 7 次课学习。
  • checkbox/radio/select 的同步规则不同：不要机械套用文本框的 :value + @input，复选框和单选框应设置合适的 value。

小结

v-model 实现表单双向绑定；对文本 input 可理解为 :value + @input，checkbox/radio/select 会根据控件类型使用相应的 checked/value 与 change 逻辑。

知识点 K3-6：条件渲染 v-if / v-show

定义

  • v-if：条件为真时渲染元素，为假时删除元素（不占 DOM）。
  • v-show：通过切换 display: none 控制显隐，元素始终存在于 DOM。

原理与对比

<template>
  <label>分数：<input v-model.number="score" type="number" /></label>
  <p v-if="score >= 60">及格</p>
  <p v-else-if="score >= 50">补考</p>
  <p v-else>不及格</p>

  <div v-show="isVisible">始终在 DOM，仅切 display</div>
  <button @click="isVisible = !isVisible">切换 v-show</button>
</template>
<script setup>
import { ref } from 'vue'
const score = ref(72)
const isVisible = ref(true)
</script>
<style scoped>
label { display: block; margin-bottom: 8px; }
button { margin-top: 8px; }
</style>
特性 v-if v-show
实现方式 删除/重建 DOM 切换 display
初始渲染 假则不渲染 始终渲染
切换开销 高（重建） 低（仅样式）
初始开销 低（惰性） 高（始终渲染）
适用场景 一次性/少切换 频繁切换

易错点

  • v-if 与 v-else 之间不能有其他元素，否则 v-else 失效。
  • v-if 与 v-for 不要同级使用（详见 K3-7）。
  • v-show 不支持 <template> 与 v-else。

小结

频繁切换用 v-show，一次性/少切换用 v-if。

知识点 K3-7：列表渲染 v-for 与 :key

定义

v-for 根据数据遍历渲染一组元素。为了让 Vue 在列表增删、排序时准确复用节点，通常要为每项提供唯一且稳定的 :key；列表中包含输入框、组件状态或会改变顺序时，应将它视为必需。

原理与用法

<template>
  <!-- 遍历数组 -->
  <ul>
    <li v-for="(item, index) in list" :key="item.id">
      {{ index }} - {{ item.title }}
    </li>
  </ul>

  <!-- 遍历对象 -->
  <ul>
    <li v-for="(value, key) in obj" :key="key">{{ key }}: {{ value }}</li>
  </ul>

  <!-- 遍历数字 -->
  <div>
    <span v-for="n in 5" :key="n">{{ n }} </span>
  </div>
</template>
<script setup>
import { ref } from 'vue'
const list = ref([
  { id: 1, title: '项目一' },
  { id: 2, title: '项目二' }
])
const obj = ref({ name: 'Vue', version: 3 })
</script>
<style scoped>
ul { padding-left: 20px; }
span { display: inline-block; margin-right: 8px; }
</style>

:key 的重要性

:key 帮助 Vue 识别每个节点，高效复用与更新。key 必须唯一且稳定：

  • ✅ 用数据的唯一 id：:key="item.id"
  • ⚠️ 用 index：:key="index"（插入、删除、排序时可能复用错误，导致输入框或子组件状态错位；静态列表才可谨慎使用）
  • ❌ 用随机数（每次变，失去复用意义）

v-if 与 v-for 混用的坑

错误写法（只用于识别，不要复制运行）：<li v-for="item in list" v-if="item.active" :key="item.id">。Vue 3 中 v-if 的优先级高于 v-for，此时 item 尚未可用。

可运行的修复方式：先用 computed 得到过滤结果，再只负责遍历。

<template>
  <ul>
    <li v-for="item in activeList" :key="item.id">
      {{ item.title }}
    </li>
  </ul>
</template>
<script setup>
import { computed, ref } from 'vue'

const list = ref([
  { id: 1, title: '进行中的项目', active: true },
  { id: 2, title: '已归档的项目', active: false }
])
const activeList = computed(() => list.value.filter(item => item.active))
</script>
<style scoped>
li { margin: 6px 0; }
</style>

易错点

  • 完全不写 :key：简单列表仍可能显示，但 Vue 无法按业务身份稳定复用节点；包含输入框或组件状态时容易错位，应补上唯一 id。
  • 用 index 作 key：列表插入/删除时状态错乱；只有静态且不会排序、增删的列表才可谨慎使用。
  • v-if 与 v-for 同级：Vue 3 报错或行为异常。

小结

v-for 遍历数组/对象/数字，列表项通常带唯一稳定的 :key（优先使用数据 id），并避免与 v-if 同级。

修饰符补充：v-model 修饰符与完整示例

定义

修饰符是以 . 指明的特殊后缀，简化常见操作。

常用修饰符

修饰符 用于 作用
.lazy v-model 改用 change 事件同步；文本输入通常在失焦时同步
.number v-model 能转换时转为数字，空值可能是空字符串；type="number" 的 input 在 Vue 中也会自动尝试数字转换
.trim v-model 去首尾空格

下面只展示表单修饰符；事件修饰符的可运行示例已放在上方 K3-4，避免学生在两个位置重复学习同一段代码。

<template>
  <label>失焦同步：<input v-model.lazy="text" /></label>
  <label>数字：<input v-model.number="num" type="number" /></label>
  <label>去空格：<input v-model.trim="name" /></label>
  <p>{{ text }} / {{ num }} / {{ name }}</p>
</template>
<script setup>
import { ref } from 'vue'
const text = ref('')
const num = ref(null)
const name = ref('')
</script>

易错点

  • 修饰符顺序：@click.prevent.stop 会按书写顺序 prevent 再 stop；组合多个修饰符时要先确认每一步的语义。
  • 修饰符只对对应指令有效：.lazy 只用于 v-model，不能用于 v-on。
  • 表单按钮的默认类型：<form> 中普通 <button> 默认是 submit。只想测试点击事件时要写 type="button"，否则可能意外触发表单提交。

小结

修饰符以 . 后缀简化常见操作；事件修饰符已在前面的 K3-4 预览，表单修饰符将在第 05 课完整练习。

<template>

<template>
  <div class="projects">
    <h2>实训项目列表</h2>
    <input v-model.trim="keyword" placeholder="搜索项目" />
    <select v-model="statusFilter">
      <option value="">全部状态</option>
      <option value="进行中">进行中</option>
      <option value="未开始">未开始</option>
    </select>

    <ul v-if="filteredProjects.length">
      <li v-for="p in filteredProjects" :key="p.id" :class="{ 'is-running': p.status === '进行中' }">
        <span>{{ p.title }}</span>
        <span class="status">{{ p.status }}</span>
      </li>
    </ul>
    <p v-else>暂无匹配项目</p>

    <button @click="reset">重置筛选</button>
  </div>
</template>

<script setup>
import { ref, computed } from 'vue'

const keyword = ref('')
const statusFilter = ref('')
const projects = ref([
  { id: 1, title: '项目一：JavaWeb', status: '进行中' },
  { id: 2, title: '项目二：Vue3', status: '进行中' },
  { id: 3, title: '项目三：全栈联调', status: '未开始' }
])

const filteredProjects = computed(() =>
  projects.value.filter(p =>
    p.title.includes(keyword.value) &&
    (statusFilter.value === '' || p.status === statusFilter.value)
  )
)

const reset = () => {
  keyword.value = ''
  statusFilter.value = ''
}
</script>

常见问题排查

  • 页面白屏：检查 computed 是否和 ref 一起从 vue 导入，并查看终端编译错误。
  • 筛选不更新：模板中直接使用 ref 是正确的；如果在 script 中读取或修改响应式值，要写 keyword.value、statusFilter.value。
  • 列表控制台警告：确认 v-for 写在 v-if 过滤后的 filteredProjects 上，并保留 :key="p.id"。
  • 命令找不到：先确认 Node.js 和 npm 已安装，执行 node -v、npm -v 检查版本。

图示 1：模板语法与指令知识地图
K3-1

文本插值

{{ }} 用于响应式文本展示，不能直接放在属性位置。

K3-2

属性绑定

v-bind / : 绑定属性，支持 class/style 对象与数组。

K3-3

事件绑定

v-on / @ 绑定交互事件，必要时接收 $event。

K3-4

事件修饰符

.stop、.prevent、.once 等为事件附加规则。

K3-5

双向绑定

v-model 根据控件类型组合值/选中状态与同步事件，适合表单状态。

K3-6

条件渲染

v-if 控制创建销毁，v-show 适合频繁切换。

K3-7

列表渲染

v-for 配合稳定唯一 :key，让更新更可靠。

要点 一句话
文本 {{ }} 渲染响应式文本
属性 :attr 绑定属性
事件 @event 绑定事件
事件规则 @event.stop / .prevent 等修饰事件行为
表单 v-model 双向绑定
条件 频繁切 v-show，一次性 v-if
列表 v-for 通常带稳定 :key；动态列表优先用 id，不用 index
修饰符 . 后缀简化操作
