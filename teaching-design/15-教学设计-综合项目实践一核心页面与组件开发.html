二、教学目标

知识目标

  1. 综合运用组件化、路由、状态管理、接口联调开发完整页面。
  2. 复习 props/emits、插槽、Pinia、Axios 的实战整合。

能力目标

  1. 完成 CTTS-Frontend 全部核心页面：登录页、布局组件、项目列表页、任务列表页、任务详情页、成果提交页、评审页、用户管理页。
  2. 所有页面对接后端 API（或 Mock）。

素质目标（课程思政）

  1. 培养团队协作意识——前后端各司其职，接口联调是关键。
  2. 建立工程交付意识——能运行、能演示才是合格成果。

三、主要知识点纲要（实践复盘型）

编号 知识点 要点
K15-1 核心页面规划 页面清单；组件复用；数据流
K15-2 登录页与布局对接 API 登录调接口存 Token；布局读 store 显示用户
K15-3 列表页与详情页 项目列表/任务列表（分页筛选）；任务详情（动态路由+接口）
K15-4 表单页（提交/评审） 成果提交、评审打分（表单+接口）
K15-5 用户管理页 管理员页面（CRUD+权限）

四、项目任务或案例任务

本次课任务：完成 CTTS-Frontend 全部核心页面，对接后端 API。

任务清单：

  1. 登录页：表单 + 调 login 接口 + 存 Token + 跳转。
  2. 布局组件：Header（用户名/退出）+ Sidebar（导航）+ Content（router-view）。
  3. 项目列表页：调 getProjects + 分页 + 筛选。
  4. 任务列表/详情页：动态路由 + 调接口。
  5. 成果提交页：表单 + 调提交接口。
  6. 评审页：教师查看提交 + 打分。
  7. 用户管理页：管理员 CRUD 用户。

六、课程思政融入点

项目 内容
融入点 团队协作——前后端各司其职，接口联调是关键

七、课堂练习或随堂测验（5 分钟）

判断题：

  1. 登录后应存 Token 到 store 并持久化。（✓）
  2. 列表页应直接在组件发请求而非通过 api 模块。（✗）
  3. 任务详情页用动态路由传 id。（✓）
  4. 成果提交用 POST 请求。（✓）

详细题目见 题库.md。

八、课后任务

  1. 完成所有核心页面，确保可运行。
  2. 整理一份《联调问题清单》。
  3. 准备项目演示（下次课答辩）。
