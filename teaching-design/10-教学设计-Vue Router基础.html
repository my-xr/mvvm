二、教学目标

知识目标

  1. 理解前端路由（SPA 路由）的概念与作用。
  2. 掌握 Vue Router 4 的安装与配置。
  3. 掌握 <router-view> 与 <router-link> 的使用。
  4. 掌握 useRouter 与 useRoute 组合式 API。
  5. 掌握动态路由（:id）与路由参数。
  6. 掌握嵌套路由（children）。

能力目标

  1. 能安装配置 Vue Router 并定义路由表。
  2. 能用 router-link/router-view 实现多页面导航。
  3. 能用 useRouter 编程式导航、useRoute 获取参数。
  4. 能配置 CTTS-Frontend 全部页面路由（含动态与嵌套）。

素质目标（课程思政）

  1. 培养导航设计意识——良好的路由是用户体验的基础。
  2. 建立 SPA 架构认知——前端路由是单页应用的核心。

三、主要知识点纲要

编号 知识点 要点
K10-1 路由概念与安装 SPA 前端路由；hash/history 模式；npm install vue-router
K10-2 路由配置与组件 routes 配置；<router-view> 出口；<router-link> 导航；createRouter/createWebHistory
K10-3 useRouter 与 useRoute 编程式导航 push/replace；获取参数 route.params/query
K10-4 动态路由与参数 :id；route.params.id；props 传参
K10-5 嵌套路由 children；子 <router-view>；路径拼接

四、项目任务或案例任务

本次课任务：配置 CTTS-Frontend 全部页面路由——登录、项目列表、任务列表、任务详情（动态路由）、用户中心（嵌套子路由）。

五、课堂互动设计

互动 1：API 路径设计投票

项目 内容
互动问题 "前端路由 /projects 与后端 API /api/projects 的对应关系？"
教师点评要点 前端路由是页面路径，后端 API 是数据接口，二者解耦但命名可对应

互动 2：hash vs history

项目 内容
互动问题 "为什么有的网址有 # 有的没有？"
教师点评要点 hash 模式带 # 兼容好；history 模式干净但需服务器配置

  2. <router-view> 是路由出口。（✓）
  3. useRoute 用于编程式导航。（✗）
  4. 动态路由用 :id 定义。（✓）
