二、教学目标

知识目标

  1. 整合全部页面路由与权限守卫。
  2. 整合 Pinia 状态管理与接口联调。
  3. 掌握 vite build 构建与部署。
  4. 了解静态服务器部署（Nginx/预览）。

能力目标

  1. 能整合 CTTS-Frontend 全部功能，形成完整可运行应用。
  2. 能用 vite build 构建生产包并部署到静态服务器。
  3. 能进行项目演示与答辩。

素质目标（课程思政）

  1. 培养完整交付意识——能运行、能演示、能部署才是合格交付。
  2. 建立项目收尾与复盘习惯。

三、主要知识点纲要（实践复盘型）

编号 知识点 要点
K16-1 路由整合与权限守卫 全部路由表；meta 权限；beforeEach 拦截
K16-2 状态管理整合 userStore/projectStore/appStore 接入页面
K16-3 接口联调完善 全部 api 对接；Mock 替换真实接口
K16-4 vite build 构建 npm run build；dist 产物；预览
K16-5 部署与答辩 部署到静态服务器（Nginx/预览）；项目演示答辩

四、项目任务或案例任务

本次课任务：整合 CTTS-Frontend 全部功能，构建部署，完成项目演示与答辩。

任务清单：

  1. 整合路由表（全部页面 + meta 权限 + 守卫 + 404）。
  2. 整合状态管理（三 store 接入各页面）。
  3. 完善接口联调（替换 Mock 为真实接口）。
  4. vite build 构建生产包。
  5. 部署到静态服务器（Nginx 或 vite preview）。
  6. 项目演示与答辩。

六、课程思政融入点

项目 内容

七、课堂练习或随堂测验（5 分钟）

判断题：

  1. npm run build 用于构建生产包。（✓）
  2. 构建产物在 dist 目录。（✓）
  3. history 模式部署后刷新可能 404。（✓）
  4. 项目答辩是交付的重要环节。（✓）

详细题目见 题库.md。

八、课后任务

  1. 完成项目构建与部署，提交部署地址。
  2. 撰写《项目总结报告》（功能清单、技术栈、问题与解决）。
  3. 整理代码到 git 仓库。
