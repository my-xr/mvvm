二、教学目标

知识目标

  1. 理解组件化思想，掌握组件的局部与全局注册。
  2. 掌握 props（定义/类型/默认值/必填/校验）。
  3. 掌握 emits 自定义事件（子传父）。
  4. 掌握父子组件通信（父传子 props、子传父 emits）。
  5. 了解组件 v-model 的基本用法。

能力目标

  1. 能拆分页面为组件并正确注册使用。
  2. 能用 props 接收父组件数据并校验。
  3. 能用 emits 向父组件传递数据。
  4. 能拆分 CTTS-Frontend 登录页为 LoginForm 组件，实现父子通信。

素质目标（课程思政）

  1. 培养组件化思维——分而治之是工程方法论的核心。
  2. 建立接口契约意识——props/emits 是组件间契约，体现协作精神。

三、主要知识点纲要

编号 知识点 要点
K7-1 组件基础与注册 组件定义；局部注册（import + 用）；全局注册（app.component）；命名
K7-2 props defineProps；类型/默认值/必填/校验；单向数据流
K7-3 emits defineEmits；子传父；$emit 触发事件
K7-4 父子通信综合 父传子 props、子传父 emits；通信方案选择
K7-5 组件 v-model defineModel/modelValue + update:modelValue；双向

四、项目任务或案例任务

本次课任务：拆分 CTTS-Frontend 登录页为 LoginForm 组件，父组件 App 传初始值（props），子组件提交时 emit 事件传登录数据给父组件。

五、课堂互动设计

互动 1：接口设计讨论——props 还是 provide/inject

项目 内容
互动问题 "父传子用 props，那跨多层怎么办？什么时候用 provide/inject？"
教师点评要点 父子用 props/emits；跨层用 provide/inject（后续课程）；全局用状态管理（Pinia，第 12 次）

互动 2：props 单向数据流纠错

项目 内容
互动问题 "子组件直接改 props 会怎样？"
教师点评要点 Vue 警告，props 单向流动，子组件不能直接改，应 emit 通知父改

六、课程思政融入点

项目 内容
融入点 组件化思维——分而治之是工程方法论
技术关联 把复杂页面拆成可复用组件，降低复杂度、提升复用
引导问题 "一整页几百行代码 vs 拆成 5 个组件，哪种更好维护？"
预期价值目标 培养组件化与分而治之的工程思维

七、课堂练习或随堂测验（5 分钟）

判断题：

  1. props 是单向数据流，子组件不应直接修改。（✓）
  2. 子组件用 emits 向父组件传数据。（✓）
  3. <script setup> 中 import 的组件需手动注册。（✗）
  4. props 可以设置类型与必填校验。（✓）

详细题目见 题库.md。

八、课后任务

  1. 通读 教学资料.md，掌握组件注册、props、emits、组件 v-model。
  2. 完善 LoginForm 组件：增加"记住我"checkbox，提交时一并 emit。
  3. 思考：props 与 emits 各自的数据流向（200 字）。
