二、教学目标

知识目标

  1. 掌握 Axios 安装与基本使用（get/post）。
  2. 掌握请求封装（baseURL/timeout/headers）。
  3. 掌握请求拦截器（自动加 Token）。
  4. 掌握响应拦截器（统一错误处理）。
  5. 掌握与后端 API 联调与 Vite 代理配置（跨域）。

能力目标

  1. 能封装 Axios 实例与拦截器。
  2. 能用 Axios 调用后端 RESTful API。
  3. 能配置 Vite 代理解决跨域。
  4. 能联调 CTTS 后端的登录、项目列表、任务列表接口。

素质目标（课程思政）

  1. 培养前后端协作意识——接口契约是团队协作的基础。
  2. 建立错误处理意识——统一拦截与用户友好提示。

三、主要知识点纲要

编号 知识点 要点
K14-1 Axios 安装与基本使用 npm install axios；axios.get/post；请求配置
K14-2 请求封装 创建 axios 实例；baseURL/timeout/headers；统一管理
K14-3 请求拦截器 interceptors.request；自动加 Token；统一处理
K14-4 响应拦截器 interceptors.response；统一错误处理；解包数据
K14-5 接口联调与 Vite 代理 与 CTTS 后端联调；vite.config.js 配置 proxy 解决跨域；Mock 兜底

四、项目任务或案例任务

本次课任务：封装 Axios，联调 CTTS 后端的登录、项目列表、任务列表接口（后端未就绪时用 Mock）。

七、课堂练习或随堂测验（5 分钟）

判断题：

  1. Axios 是基于 Promise 的 HTTP 库。（✓）
  2. 请求拦截器可自动添加 Token。（✓）
  3. Vite 代理可解决开发环境跨域。（✓）
  4. 响应拦截器用于统一错误处理。（✓）

详细题目见 题库.md。

八、课后任务

  1. 通读 教学资料.md，掌握 Axios 封装与拦截器。
  2. 完善 CTTS-Frontend：联调任务详情、成果提交接口。
  3. 思考：开发环境与生产环境跨域的解决方式（200 字）。
