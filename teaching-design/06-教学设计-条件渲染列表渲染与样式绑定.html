二、教学目标

知识目标

  1. 深入掌握条件渲染 v-if/v-else/v-else-if/v-show 的区别与场景。
  2. 掌握列表渲染 v-for 遍历数组/对象/数字，理解 :key 的重要性与列表更新检测。
  3. 掌握 :class（对象/数组语法）与 :style（对象/数组语法）绑定。
  4. 理解 Vue 数组变异方法与非变异方法的更新机制。

能力目标

  1. 能根据场景选择 v-if 或 v-show。
  2. 能正确使用 v-for 渲染列表并提供稳定 :key。
  3. 能用 :class/:style 实现动态样式（如状态变色）。
  4. 能实现 CTTS-Frontend 任务列表的条件展示、分页与样式切换。

素质目标（课程思政）

  1. 培养细节意识——合理的列表渲染与样式让界面更专业。
  2. 建立性能意识——:key 与 v-if/v-show 选择影响性能。

三、主要知识点纲要

编号 知识点 要点
K6-1 条件渲染 v-if/v-else-if/v-else（删 DOM）；v-show（切 display）；<template v-if>
K6-2 列表渲染 v-for 遍历数组/对象/数字；:key 唯一稳定；index 用法与局限
K6-3 列表更新检测 变异方法（push/pop/splice 等）触发更新；非变异（filter/map）需替换；Vue 3 Proxy 可监测索引
K6-4 class 绑定 对象语法 {active: bool}；数组语法 [a, b]；与普通 class 共存
K6-5 style 绑定 对象语法 {color: x}；数组语法；驼峰/短横线
