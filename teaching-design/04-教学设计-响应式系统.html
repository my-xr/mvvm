二、教学目标

知识目标

  1. 掌握 ref 与 reactive 的区别与使用场景。
  2. 掌握 computed 计算属性的用法与缓存特性。
  3. 掌握 watch 与 watchEffect 侦听器的区别与用法。
  4. 了解 Vue 3 响应式原理（Proxy）。

能力目标

  1. 能够根据数据类型选择 ref 或 reactive。
  2. 能够使用 computed 实现派生数据，理解其缓存优势。
  3. 能够使用 watch 在数据变化时执行副作用（如异步请求）。
  4. 能实现 CTTS-Frontend 任务列表的搜索过滤（computed）与状态变化响应（watch）。

素质目标（课程思政）

  1. 培养"数据驱动"思维——响应式让开发者关注数据而非 DOM，体会声明式编程的力量。
  2. 建立"缓存与性能"意识——computed 的缓存特性是工程优化的典型范例。

三、主要知识点纲要

编号 知识点 要点
K4-1 ref 基本类型响应式；.value；模板自动解包；也支持对象
K4-2 reactive 对象响应式；直接访问属性无需 .value；解构会丢失响应式（用 toRefs）
K4-3 computed 计算属性；基于依赖缓存；只有依赖变化才重算
K4-4 watch 侦听器；显式指定侦听源；可获新旧值；可侦听多个；deep/immediate
K4-5 watchEffect 立即执行；自动收集依赖；无法获旧值
K4-6 响应式原理 Proxy 代理对象读写；依赖收集与触发更新

五、课堂互动设计

互动 1：面试题导入——ref 和 reactive 的区别

项目 内容
互动问题 "面试常问：ref 和 reactive 有什么区别？什么时候用哪个？"
组织方式 小组讨论 3 分钟后发言
教师点评要点 ref 适合基本类型（用 .value），reactive 适合对象（直接访问）；reactive 解构会丢失响应式

互动 2：computed vs methods

项目 内容
互动问题 "computed 和 methods 都能算结果，为什么有了 methods 还要 computed？"
教师点评要点 computed 有缓存，依赖不变时不重算；methods 每次调用都重算

六、课程思政融入点

项目 内容
融入点 数据驱动思维——响应式让开发者关注数据而非 DOM 操作
技术关联 响应式是 MVVM 的核心，Vue 自动追踪数据变化更新视图
引导问题 "没有响应式之前，你怎么让数据变化时界面更新？"
预期价值目标 体会声明式编程与数据驱动的工程价值

七、课堂练习或随堂测验（5 分钟）

判断题：

  1. reactive 适合包装对象类型。（✓）
  2. reactive 解构后仍保持响应式。（✗）
  3. computed 有缓存特性。（✓）
  4. watchEffect 会立即执行一次。（✓）

详细题目见 题库.md。
