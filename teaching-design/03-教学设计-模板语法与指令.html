二、教学目标

知识目标

  1. 掌握模板语法与文本插值（Mustache {{ }}）。
  2. 掌握属性绑定 v-bind（简写 :）与事件绑定 v-on（简写 @）。
  3. 理解双向绑定 v-model 的基本用法。
  4. 掌握条件渲染 v-if / v-show 的区别与使用场景。
  5. 掌握列表渲染 v-for 与 :key 的重要性。
  6. 了解常用指令修饰符。

能力目标

  1. 能够使用 {{ }}、v-bind、v-on 实现数据与视图的绑定。
  2. 能够使用 v-if/v-show 控制元素显隐，使用 v-for 渲染列表。
  3. 能够用指令实现 CTTS-Frontend 的项目列表展示与搜索筛选。

素质目标（课程思政）

  1. 培养代码规范意识——指令使用要清晰简洁，避免滥用。
  2. 建立"声明式"思维——用指令描述"想要什么"，而非"怎么做"。

三、主要知识点纲要

详细讲解见同文件夹 教学资料.md。

编号 知识点 要点
K3-1 文本插值 Mustache {{ }}，响应式更新；不能用于 HTML 属性
K3-2 属性绑定 v-bind v-bind:attr 简写 :attr；绑定 class/style/动态属性
K3-3 事件绑定 v-on v-on:event 简写 @event；事件对象 $event；方法与内联语句
K3-4 双向绑定 v-model 表单双向绑定（基础）；v-model = :value + @input
K3-5 条件渲染 v-if/v-else/v-else-if/v-show；v-if 删除重建，v-show 切换 display
K3-6 列表渲染 v-for 遍历数组/对象；:key 必须唯一稳定；避免与 v-if 同级
K3-7 指令修饰符 .stop/.prevent/.once/.lazy/.number/.trim 等

本次课任务：用指令实现 CTTS-Frontend 项目列表展示与搜索筛选——展示项目数组、用输入框搜索过滤、用 v-show 切换列表/空状态提示。

五、课堂互动设计

互动 1：代码找错——v-if 与 v-for 混用反例

项目 内容
互动问题 给出 <li v-for="p in list" v-if="p.active">，请学生指出问题
组织方式 全班讨论
预期学生输出 v-if 与 v-for 不应同级；v-if 优先级高导致 list 未定义报错
教师点评要点 Vue 3 中 v-if 优先级高于 v-for，混用会出错；应用 computed 过滤

互动 2：v-if vs v-show 辩论

项目 内容
互动问题 "频繁切换显隐用哪个？只切换一次用哪个？为什么？"
组织方式 两派辩论
教师点评要点 频繁切换用 v-show（不重建 DOM），一次性用 v-if（惰性渲染）

六、课程思政融入点

项目 内容
融入点 指令使用规范——简洁清晰，避免滥用（如 v-if/v-for 混用）

七、课堂练习或随堂测验（5 分钟）

判断题：

  1. {{ }} 可用于 HTML 属性绑定。（✗）
  2. v-bind 可简写为 :。（✓）
  3. v-if 与 v-show 本质相同。（✗）
  4. v-for 必须为每项提供 :key。（✓）

详细题目见 题库.md。
