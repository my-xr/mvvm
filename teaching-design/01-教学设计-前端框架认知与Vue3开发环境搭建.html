二、教学目标

知识目标

  1. 了解前端开发的演进历程：原生 JS → jQuery → MVVM 框架时代，理解”为什么需要前端框架”。
  2. 理解 MVVM 架构思想：Model、View、ViewModel 三者的职责划分与数据双向流动。
  3. 了解 Vue 3 的核心特性（Composition API、<script setup>、性能提升、生态）与作者背景。
  4. 理解 Node.js 与 npm 在前端工程化中的作用：Node.js 是运行时、npm 是包管理工具。
  5. 掌握使用 Vite 脚手架创建 Vue 3 项目的流程，理解项目目录的基本结构。

能力目标

  1. 能够用自己的语言准确描述”什么是 MVVM”“Vue 解决了什么问题”。
  2. 能够独立完成 Node.js 安装与版本验证、npm 镜像配置。
  3. 能够使用 npm create vite@latest 创建一个可运行的 Vue 3 项目并启动开发服务器。
  4. 能够看懂 Vite 创建的 Vue 3 项目目录结构，找到入口文件与根组件。

素质目标（课程思政）

  1. 增强国产技术生态认同——Vue 是华人尤雨溪创建的框架，体现中国技术影响力。
  2. 建立”工具服务于问题”的工程认知——框架不是炫技，而是为解决前端工程化痛点而生。
  3. 培养独立搭建开发环境的动手能力——环境搭建是工程师的第一项基本功。

三、主要知识点纲要

详细讲解内容见同文件夹 教学资料.md，此处为纲要。

编号 知识点 要点
K1-1 前端开发演进 原生 JS（操作 DOM）→ jQuery（封装 DOM）→ MVVM 框架（数据驱动）；演进动力是前端复杂度上升
K1-2 MVVM 架构思想 Model（数据）+ View（界面）+ ViewModel（桥梁）；数据绑定与响应式同步；数据驱动视图；表单交互可用 v-model 回写数据
K1-3 Vue 3 简介与核心特性 尤雨溪创建；Composition API、<script setup>、Proxy 响应式、性能提升、生态（Router/Pinia/Vite）
K1-4 Node.js 与 npm Node.js = JS 运行时（让 JS 脱离浏览器运行）；npm = 包管理工具；前端工程化的基础
K1-5 Vite 创建 Vue3 项目 npm create vite@latest；选 Vue + JavaScript；项目目录结构；npm install 与 npm run dev

四、项目任务或案例任务

贯穿项目导入：校园实训任务管理系统前端（CTTS-Frontend）

本次课任务： 1. 教师介绍贯穿项目 CTTS-Frontend 的业务背景与三角色（管理员/教师/学生）。 2. 学生使用 Vite 脚手架在本地创建 CTTS-Frontend 项目，成功启动开发服务器，看到欢迎页。 3. 将默认欢迎页标题改为”CTTS-Frontend 校园实训任务管理系统”，作为项目的第一个提交。

项目背景概述（详见 教学资料.md 综合示例）： - 项目名称：校园实训任务管理系统前端（CTTS-Frontend） - 三种角色：管理员、教师、学生 - 与 JavaWeb 课程的 CTTS 后端配套，第 14 次课前后端联调 - 课程八阶段增量构建，本课程结束时交付可运行、可演示、可部署的前端 SPA

📌 本节课重点是”认知 + 环境”，代码量少但必须让每个学生把项目跑起来。代码深入从第 2 次课开始。

五、课堂互动设计

互动 1：课前 5 分钟讨论（开场导入）

项目 内容
互动问题 “用原生 JS 写过一个稍微复杂的页面吗？比如一个带搜索、增删改的列表？最大的痛苦是什么？”
组织方式 自由发言，教师板书关键词，不评判对错
预期学生输出 提到”操作 DOM 太繁琐”“状态一多就乱”“代码难维护”“重复逻辑多”等关键词
教师点评要点 肯定真实痛点，引出”框架就是来解决这些问题的”；为 K1-1 演进与 K1-2 MVVM 做铺垫

互动 2：MVVM 角色辨识（讲解 K1-2 后）

项目 内容
互动问题 给出一个”购物车页面”：商品列表、数量加减、总价自动计算。请学生指出其中哪些是 Model、哪些是 View、ViewModel 在做什么
组织方式 全班举手抢答，教师引导
预期学生输出 Model = 商品数据/数量；View = 页面显示；ViewModel = 把数量变化自动同步到总价显示
教师点评要点 强调”ViewModel 是桥梁，开发者只改数据，视图自动更新”，这正是与原生 JS 操作 DOM 的本质区别

互动 3：环境搭建互助（讲解 K1-5 时）

项目 内容
互动任务 全员动手用 Vite 创建项目，2 人一组互助，先跑起来的帮未跑起来的
组织方式 教师演示一遍 → 学生动手 10 分钟 → 同桌互助
预期学生输出 每人本机有一个可运行的 CTTS-Frontend 项目，浏览器显示欢迎页
教师点评要点 收集共性报错（端口占用、Node 版本过低、镜像慢），统一讲解排查方法

六、课程思政融入点

项目 内容
融入点 Vue 是华人尤雨溪（Evan You）独立创建并维护的前端框架，目前是全球三大前端框架之一
技术关联 Vue 3 是本课程主框架；学习 Vue 既是学技术，也是认识中国开发者在开源世界的影响力
引导问题 “你知道 Vue 是谁做的吗？一个华人独立发起的项目如何成为全球主流框架？”
预期价值目标 增强国产技术生态认同与文化自信；激发学生”我也能做出被世界用的东西”的技术抱负

思政自然融入，不空喊口号。通过 Vue 作者的真实故事，让学生体会开源精神与中国技术影响力。

七、课堂练习或随堂测验

随堂练习（5 分钟，讲解结束前进行）

判断题（口头快速作答）： 1. MVVM 中，开发者直接操作 DOM 来更新界面。（✗） 2. Vue 3 推荐使用 Composition API 和 <script setup> 语法。（✓） 3. Node.js 是一个浏览器，用来运行前端代码。（✗） 4. npm create vite@latest 命令用于创建一个新的 Vite 项目。（✓） 5. Vue 是由华人尤雨溪创建的开源前端框架。（✓）

详细题目与解析见 题库.md。此处仅作课堂快速互动，不计分。

八、课后任务

  1. 阅读：通读同文件夹 教学资料.md，重点理解前端演进、MVVM、Vue3 特性、Node.js/npm、Vite 项目结构。
  2. 动手：确保本机 CTTS-Frontend 项目可正常运行（npm run dev），把欢迎页标题改为”CTTS-Frontend 校园实训任务管理系统”，截图下次课抽查。
  3. 思考：用 200 字描述”MVVM 与原生 JS 操作 DOM 的本质区别”，下次课抽查。
  4. 环境准备：安装 VS Code（如未安装）并安装 Vue Official 插件（原 Volar），为第 2 次课编写 SFC 做准备。
  5. 拓展阅读：浏览 Vue 3 官方文档（cn.vuejs.org）首页与”简介”章节（选做）。
