二、教学目标

知识目标

  1. 掌握多 store 管理（userStore/projectStore/appStore）。
  2. 掌握 store 间相互引用。
  3. 掌握状态持久化（localStorage）。
  4. 掌握 $reset/$patch/$subscribe。

能力目标

  1. 能为 CTTS-Frontend 设计完整状态管理方案。
  2. 能实现 userStore（登录）、projectStore（项目数据缓存）、appStore（UI 状态）。
  3. 能实现状态持久化与恢复。

素质目标（课程思政）

  1. 培养架构意识——合理的状态管理让应用更健壮。
  2. 建立"数据分层"思维——不同职责的状态分类管理。

三、主要知识点纲要（实践复盘型）

编号 知识点 要点
K13-1 多 store 管理 userStore/projectStore/appStore 分类；职责单一
K13-2 store 间相互引用 action 中 useXxxStore() 调用其他 store
K13-3 状态持久化 localStorage 存取；初始化从 localStorage 恢复
K13-4 $reset / $patch / $subscribe 重置/批量改/监听变化
K13-5 综合实践组织 状态管理方案设计与实现

四、项目任务或案例任务

本次课任务：完成 CTTS-Frontend 全局状态管理——userStore（登录状态）、projectStore（项目数据缓存）、appStore（侧边栏折叠等 UI 状态），并实现状态持久化。

七、课堂练习或随堂测验（5 分钟）

  3. localStorage 可用于状态持久化。（✓）
  4. $reset 可重置 store 状态到初始值。（✓）
