二、教学目标

知识目标

  1. 掌握 Vite 创建的 Vue 3 项目目录结构与各文件职责。
  2. 理解 SFC（单文件组件）的三段式结构：<template> / <script setup> / <style>。
  3. 掌握 <script setup> 语法的特点与基本用法。
  4. 初步体验响应式：理解 ref 的作用与 .value 的使用规则。
  5. 能够编写并运行一个包含静态数据与响应式交互的 Vue 页面。

能力目标

  1. 能够看懂并描述 Vue 3 项目的文件加载链路（index.html → main.js → App.vue）。
  2. 能够独立编写一个 SFC 组件，正确使用三段式结构。
  3. 能够使用 ref 创建响应式数据并在模板中使用，实现简单的数据驱动交互。
  4. 能够创建 CTTS-Frontend 首页，展示欢迎信息与静态项目列表。

素质目标（课程思政）

  1. 培养工程规范意识——项目结构是团队协作的基础，规范目录与文件命名是工程师的基本素养。
  2. 建立"关注点分离"思维——SFC 三段式把结构、逻辑、样式分离又聚合，体现工程美学。
  3. 体会"数据驱动"的第一印象——通过 ref 体验"改数据、视图自动变"，建立 MVVM 直觉。

三、主要知识点纲要

详细讲解内容见同文件夹 教学资料.md，此处为纲要。

编号 知识点 要点
K2-1 Vue3 项目目录结构 public/src/node_modules、package.json、vite.config.js、index.html 的职责与加载链路
K2-2 SFC 单文件组件 .vue 文件三段式：<template>（结构）/<script setup>（逻辑）/<style>（样式）
K2-3 <script setup> 语法 顶层即 setup；声明的变量/函数自动暴露给模板；无需 return；导入即用
K2-4 响应式初体验 ref ref() 创建响应式数据；JS 中用 .value 访问；模板中自动解包；适合基本类型
K2-5 首个页面开发 创建 CTTS-Frontend 首页：欢迎信息 + 静态项目列表 + 简单交互（点击计数）

四、项目任务或案例任务

贯穿项目任务：CTTS-Frontend 首页

本次课任务：

  1. 在第 1 次课创建的 CTTS-Frontend 项目基础上，理清项目结构与文件加载链路。
  2. 编写 App.vue 作为首页，展示"CTTS-Frontend 校园实训任务管理系统"欢迎信息。
  3. 在首页用静态数据渲染一个项目列表（3~5 个实训项目），并用 ref 实现一个"访问次数"计数器，体会数据驱动。

预期成果：

  • 浏览器显示 CTTS-Frontend 首页，含标题、项目列表、计数器按钮。
  • 点击按钮，访问次数自动 +1（无需手动操作 DOM）。

📌 本节课开始写真正的 Vue 代码，重点是 SFC 结构与 ref 响应式初体验，不引入组件拆分（第 7 次课讲）。

五、课堂互动设计

互动 1：代码阅读——对比 Options API 与 Composition API

项目 内容
互动问题 给出功能相同的两段计数器代码（Options API vs <script setup>），请学生指出哪种更简洁、为什么
组织方式 全班对比阅读，举手发言
预期学生输出 <script setup> 更简洁，不用写 data/methods/return
教师点评要点 引出 <script setup> 是 Composition API 语法糖，减少样板代码；同时强调二者都能用

互动 2：ref 的 .value 之谜

项目 内容
互动问题 "为什么 ref(0) 在 JS 里要写 count.value++，但在模板里直接写 {{ count }} 就行？"
组织方式 提问后给 1 分钟思考，再讲解
预期学生输出 学生可能猜测"模板自动处理了"
教师点评要点 讲清"模板自动解包（unwrap）"机制；JS 中 ref 是对象 {value: x}，必须 .value

六、课程思政融入点

项目 内容
融入点 项目目录与文件命名规范——看似琐碎，实则是团队协作的基石

引导问题 "如果每个人随便命名文件夹和文件，新人接手项目会多痛苦？规范带来什么价值？"
预期价值目标 树立工程规范意识，体会"约定优于配置"的工程哲学

七、课堂练习或随堂测验

随堂练习（5 分钟）

判断题（口头快速作答）：

  1. .vue 文件必须包含 <template>、<script>、<style> 三段，缺一不可。（✗）
  2. <script setup> 中声明的变量可以直接在模板中使用，无需 return。（✓）
  3. ref 创建的数据在 JavaScript 中通过 .value 访问。（✓）
  4. index.html 是 Vue 项目的 JS 入口文件。（✗）

详细题目与解析见 题库.md。此处仅作课堂快速互动，不计分。

八、课后任务
