06-选择-001（★ 知识点：K6-1） v-show 控制显隐的实现方式是？

  • A删除 DOM
  • B切换 display
  • C修改 visibility
  • D修改 opacity

06-选择-002（★ 知识点：K6-1） v-if 条件为假时，元素？

  • A隐藏（display:none）
  • B从 DOM 中删除
  • C变透明
  • D不变

答案：B 解析：v-if 为假时删除元素（不占 DOM）。B 正确。

06-选择-003（★ 知识点：K6-1） 频繁切换显隐，推荐使用？

  • Av-if
  • Bv-else
  • Cv-show
  • Dv-for

答案：C 解析：频繁切换用 v-show（不重建 DOM）。C 正确。

06-选择-004（★ 知识点：K6-1） v-else 必须紧跟在？

  • Dv-show 后

  • D对象

06-选择-008（★ 知识点：K6-2） 下列关于 v-for 与 v-if 同级的说法，正确的是？

06-选择-009（★ 知识点：K6-3） 下列属于变异方法（修改原数组并触发更新）的是？

  • Bmap
  • Cpush
  • Dslice

  • Bsplice

  • Dsort

四、论述 / 简答题（共 4 题）

06-论述-001（★★ 知识点：K6-1，分值：6 分） 题目：比较 v-if 与 v-show，说明区别与适用场景。

要求： （1）实现区别（3 分）。 （2）性能区别（2 分）。 （3）适用场景（1 分）。

参考答案： （1）实现（3 分）：v-if 删除/重建 DOM（假时不占 DOM）；v-show 始终渲染，切 display。 （2）性能（2 分）：v-if 切换开销大（重建）、初始开销小（惰性）；v-show 切换开销小（仅样式）、初始开销大（始终渲染）。 （3）场景（1 分）：频繁切换用 v-show，一次性/少切换用 v-if。

评分标准：共 6 分，按小题给分。

06-论述-002（★★ 知识点：K6-2/K6-3，分值：8 分） 题目：解释 :key 的作用及为何不用 index；说明变异与非变异方法的区别。

要求： （1）:key 作用与不用 index 原因（4 分）。 （2）变异 vs 非变异（4 分）。

参考答案： （1）（4 分）：:key 是节点唯一标识，帮助 Vue 高效复用与更新。不用 index 因列表增删时 index 重排，导致复用错位、状态错乱、性能差；应用唯一稳定 id。 （2）（4 分）：变异方法（push/splice/sort 等）修改原数组直接触发更新；非变异方法（filter/map/slice）返回新数组，需把结果替换回原数组才触发更新。

评分标准：共 8 分，按小题给分。

06-论述-003（★★ 知识点：K6-4，分值：8 分） 题目：说明 :class 的对象语法、数组语法及与普通 class 共存的规则，举例。

要求： （1）对象语法（3 分）。 （2）数组语法（3 分）。 （3）与普通 class 共存（2 分）。

参考答案： （1）对象语法（3 分）：:class="{ active: isActive, 'text-danger': hasError }"，键为类名，值为布尔决定是否生效。 （2）数组语法（3 分）：:class="[baseClass, isActive ? 'active' : '']"，或混合 :class="[base, {active: isActive}]"。 （3）共存（2 分）：普通 class 与 :class 会合并，如 <div class="box" :class="{active: isActive}"> 最终 class 为 box active（当 isActive 为真）。

评分标准：共 8 分，按小题给分。

06-论述-004（★★ 知识点：K6-3/K6-5 综合，分值：8 分） 题目：说明 Vue 3 相比 Vue 2 在数组更新检测上的改进，并说明 :style 的书写规则。

要求： （1）Vue 3 数组更新改进（4 分）。 （2）:style 书写规则（4 分）。

参考答案： （1）改进（4 分）：Vue 3 用 Proxy，能直接监测数组索引修改（list[0]=x）和 length 修改（list.length=0），触发更新；Vue 2 用 defineProperty 不能监测，需 Vue.set/this.$set。Vue 3 也仍支持变异方法触发更新。 （2）:style 规则（4 分）：支持对象语法，属性名用驼峰（fontSize）或引号包裹短横线（'font-size'）；数值需带单位（'16px' 或 16+'px'）；数组语法可合并多个样式对象。

评分标准：共 8 分，按小题给分。

06-程序-001（★★ 知识点：K6 综合，分值：10 分） 题目：找出 3 处错误并改正。

  <div>
    <li v-for="item in list" v-if="item.show" :key="item.id">{{ item.name }}</li>
    <p :class="active: true">文本</p>
    <button @click="list.filter(x => x.show)">筛选</button>
  </div>
</template>
<script setup>
import { ref } from 'vue'
const list = ref([{ id: 1, name: 'A', show: true }])
</script>

要求：指出 3 处错误并改正。（每处 3.33 分，共 10 分）

参考答案：

  1. v-for 与 v-if 同级（3.33 分）：应改用 computed 过滤，<li v-for="item in showList" :key="item.id">，定义 const showList = computed(() => list.value.filter(x => x.show))。
  2. :class="active: true" 语法错误（3.33 分）：应改为对象语法 :class="{ active: true }"。
  3. list.filter(...) 不替换不更新（3.33 分）：应改为 list.value = list.value.filter(x => x.show)（替换）或用变异方法。

评分标准：共 10 分，每处指出并改正得 3.33 分。
