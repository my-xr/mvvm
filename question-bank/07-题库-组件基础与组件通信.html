四、论述 / 简答题（共 4 题）

07-论述-001（★★ 知识点：K7-1，分值：6 分） 题目：比较局部注册与全局注册，说明推荐方式。

要求： （1）两者区别（3 分）。 （2）推荐方式及原因（3 分）。

参考答案： （1）区别（3 分）：局部注册在组件内 import 使用，仅当前可用；全局注册在 main.js 用 app.component，全局任意位置可用。 （2）推荐（3 分）：推荐局部注册。因全局注册无法 Tree-shaking，增大打包体积；局部注册按需引入，更利于维护与优化。

评分标准：共 6 分，按小题给分。

07-论述-002（★★ 知识点：K7-2，分值：8 分） 题目：解释 props 的单向数据流，子组件需要修改 props 数据时怎么办？

要求： （1）单向数据流含义（3 分）。 （2）子组件修改 props 的正确方式（3 分）。 （3）props 校验选项（2 分）。

参考答案： （1）单向流（3 分）：props 只能从父流向子，子组件不能直接修改 props，否则 Vue 警告。这保证数据流向清晰可追踪。 （2）正确方式（3 分）：子组件用 emit 触发事件通知父组件，由父组件修改数据后再通过 props 传回子组件；或用 computed 派生本地数据。 （3）校验选项（2 分）：type（类型）、required（必填）、default（默认值）、validator（自定义校验）。

评分标准：共 8 分，按小题给分。

07-论述-003（★★ 知识点：K7-3/K7-4，分值：8 分） 题目：说明 emits 实现子传父的完整流程，并写出父子组件示例。

要求： （1）流程说明（4 分）。 （2）完整示例（4 分）。

参考答案： （1）流程（4 分）：①子组件用 defineEmits 声明事件名；②子组件在合适时机调用 emit('事件名', 数据) 触发；③父组件用 @事件名 监听，回调接收数据。 （2）示例（4 分）： 子：const emit = defineEmits(['change']); const fn = () => emit('change', 10) 父：<Child @change="onChange" />，const onChange = (val) => { ... }

评分标准：共 8 分，按小题给分。示例须含声明、触发、监听三步。

07-论述-004（★★ 知识点：K7-5，分值：8 分） 题目：解释组件 v-model 的原理，并说明如何实现。

要求： （1）原理（4 分）。 （2）实现方式（Vue 3.4+ 与传统）（4 分）。

参考答案： （1）原理（4 分）：<Child v-model="x" /> 等价于 <Child :modelValue="x" @update:modelValue="x=$event" />，即父传 modelValue（props），子 emit update:modelValue 通知父更新，实现双向。 （2）实现（4 分）：①Vue 3.4+ 用 const model = defineModel()，自动声明 modelValue + update:modelValue；②传统方式：defineProps(['modelValue']) + defineEmits(['update:modelValue'])，手动 emit 更新。支持多 v-model 用 v-model:参数名。

评分标准：共 8 分，按小题给分。
