一、选择题（共 40 题，每题 2 分）

1.1 单项选择题（30 题）

03-选择-001（★ 知识点：K3-1） Vue 模板中用于文本插值的语法是？

  • A{ }
  • B{{ }}
  • C[[ ]]
  • D<% %>

答案：B 解析：Vue 用双花括号 {{ }}（Mustache）做文本插值。B 正确。

03-选择-002（★ 知识点：K3-1） 关于 {{ }}，下列说法正确的是？

  • A可用于 HTML 属性绑定
  • B只能放变量，不能放表达式
  • C可放变量、运算、三元等表达式
  • D会解析 HTML 标签

答案：C 解析：{{ }} 可放任意 JS 表达式。不能用于属性（A 错）；输出纯文本不解析 HTML（D 错）。C 正确。

03-选择-003（★ 知识点：K3-2） v-bind:src 的简写是？

  • A@src
  • B:src
  • C#src
  • D-src

答案：B 解析：v-bind 简写为 :，如 :src。B 正确。

03-选择-004（★ 知识点：K3-2） 下列写法中，绑定 class 正确的是？

  • A<div class="{active: true}">
  • B<div :class="{active: isActive}">
  • C<div v-class="active">
  • D<div {{ active }}>

答案：B 解析：class 绑定用 :class，支持对象语法 {active: isActive}。B 正确。

03-选择-005（★ 知识点：K3-3） v-on:click 的简写是？

  • A:click
  • B@click
  • C#click
  • D*click

答案：B 解析：v-on 简写为 @，如 @click。B 正确。

03-选择-006（★ 知识点：K3-3） 在内联事件语句中访问原生事件对象，应使用？

  • Aevent
  • Be
  • C$event
  • Dthis

答案：C 解析：内联语句用 $event 访问事件对象。C 正确。

03-选择-007（★ 知识点：K3-4） v-model 本质上是哪两者的语法糖？

  • A:value + @input
  • B:value + @change
  • C:model + @update
  • D:data + @input

答案：A 解析：v-model = :value + @input（input 元素）。A 正确。

03-选择-008（★ 知识点：K3-4） v-model 不能用于下列哪个元素？

  • A<input>
  • B<textarea>
  • C<select>
  • D<div>

答案：D 解析：v-model 只能用于表单元素（input/textarea/select），不能用于 div。D 正确。

03-选择-009（★ 知识点：K3-5） 关于 v-if 与 v-show，下列说法正确的是？

  • A两者完全相同
  • Bv-if 删除/重建 DOM，v-show 切换 display
  • Cv-show 删除 DOM，v-if 切换 display
  • D都不支持 v-else

答案：B 解析：v-if 删除重建 DOM，v-show 用 display 切换显隐。B 正确。

03-选择-010（★ 知识点：K3-5） 频繁切换元素显隐，推荐使用？

  • Av-if
  • Bv-else
  • Cv-show
  • Dv-for

答案：C 解析：频繁切换用 v-show（不重建 DOM，开销小）。C 正确。

03-选择-011（★ 知识点：K3-6） v-for 渲染列表时，:key 的值应？

  • A使用数组索引 index
  • B使用随机数
  • C使用唯一且稳定的标识（如 id）
  • D不需要 key

答案：C 解析：key 应唯一稳定，用数据 id；用 index 或随机数会有问题。C 正确。

03-选择-012（★ 知识点：K3-6） 下列关于 v-for 与 v-if 同级使用的说法，正确的是？

  • A推荐同级使用
  • BVue 3 中 v-if 优先级高于 v-for，同级会出错
  • Cv-for 优先级高于 v-if，同级没问题
  • D同级使用性能更好

答案：B 解析：Vue 3 中 v-if 优先级高于 v-for，同级会导致 v-if 取不到 v-for 的变量而出错。应改用 computed 过滤。B 正确。

03-选择-013（★ 知识点：K3-7） 阻止事件冒泡的修饰符是？

  • A.prevent
  • B.stop
  • C.once
  • D.self

答案：B 解析：.stop 阻止冒泡（stopPropagation）；.prevent 阻止默认行为。B 正确。

03-选择-014（★ 知识点：K3-7） 阻止表单默认提交的修饰符是？

  • A.stop
  • B.prevent
  • C.once
  • D.submit

答案：B 解析：.prevent 阻止默认行为（preventDefault），如表单提交、链接跳转。B 正确。

03-选择-015（★ 知识点：K3-7） v-model.lazy 的作用是？

  • A实时同步
  • B失焦时才同步
  • C转为数字
  • D去空格

答案：B 解析：.lazy 使 v-model 在失焦（change）时才同步，而非实时（input）。B 正确。

03-选择-016（★ 知识点：K3-7） v-model.number 的作用是？

  • A失焦同步
  • B将输入值转为数字
  • C去空格
  • D限制只能输数字

答案：B 解析：.number 将输入值转为数字类型。B 正确。

03-选择-017（★ 知识点：K3-2） 绑定 style 的正确写法是？

  • A<div style="color: red">
  • B<div :style="{ color: textColor }">
  • C<div :style="color: textColor">
  • D<div {{ style }}>

答案：B 解析：style 绑定用对象语法 :style="{ color: textColor }"。B 正确。

03-选择-018（★ 知识点：K3-1） 要渲染包含 HTML 标签的字符串，应使用？

  • A{{ }}
  • Bv-text
  • Cv-html
  • Dv-bind

答案：C 解析：{{ }} 输出纯文本；v-html 解析 HTML（注意 XSS 风险）。C 正确。

03-选择-019（★ 知识点：K3-3） @click="handleClick" 中，handleClick 方法接收的第一个参数是？

  • A无参数
  • B原生事件对象
  • C组件实例
  • D数据

答案：B 解析：方法直接作为事件处理时，第一个参数是原生事件对象。B 正确。

03-选择-020（★ 知识点：K3-6） v-for="(item, index) in list" 中，index 表示？

  • A当前项
  • B当前项的索引
  • C列表本身
  • D列表长度

答案：B 解析：index 是当前项的索引（从 0）。B 正确。

03-选择-021（★★ 知识点：K3-2） 关于 class 绑定的对象语法，下列正确的是？

  • A<div :class="active">
  • B<div :class="{ active: isActive }">
  • C<div :class="active: isActive">
  • D<div class=":active">

答案：B 解析：对象语法为 { 类名: 布尔 }。B 正确。

03-选择-022（★★ 知识点：K3-4） 下列代码等价于 v-model 的是？

  • A<input :value="text" @input="text = $event.target.value">
  • B<input :value="text" @click="text = $event">
  • C<input :text="value" @input="text">
  • D<input @value="text">

答案：A 解析：v-model 等价 :value + @input 中把输入值赋回数据。A 正确。

03-选择-023（★★ 知识点：K3-5） v-if、v-else-if、v-else 之间，下列说法正确的是？

  • A中间可以插入其他元素
  • B必须紧邻，中间不能有其他元素
  • C顺序无所谓
  • Dv-else 可以单独使用

答案：B 解析：v-if/v-else-if/v-else 必须紧邻，中间插入元素会使 v-else 失效。B 正确。

03-选择-024（★★ 知识点：K3-6） 用 index 作为 v-for 的 key 会产生的问题是？

  • A编译报错
  • B列表增删时状态错乱、性能差
  • C无法渲染
  • D没有问题

答案：B 解析：用 index 作 key，列表插入/删除时 index 变化，Vue 复用错位节点，导致状态错乱且性能差。B 正确。

03-选择-025（★★ 知识点：K3-5） 下列场景适合用 v-if 的是？

  • A标签页频繁切换
  • B折叠面板频繁展开收起
  • C根据权限只渲染一次的元素
  • D实时显隐的提示

答案：C 解析：一次性/少切换用 v-if（惰性渲染，初始开销低）。频繁切换用 v-show。C 正确。

03-选择-026（★★ 知识点：K3-7） .self 修饰符的作用是？

  • A阻止冒泡
  • B阻止默认行为
  • C仅事件源是元素自身才触发
  • D只触发一次

答案：C 解析：.self 表示仅当事件目标（event.target）是当前元素本身时才触发，冒泡来的不触发。C 正确。

03-选择-027（★★ 知识点：K3-7） v-model.trim 的作用是？

  • A失焦同步
  • B转数字
  • C去除首尾空格
  • D限制长度

答案：C 解析：.trim 去除输入值首尾空格。C 正确。

03-选择-028（★★ 知识点：K3-3） @click="handleClick()" 与 @click="handleClick" 的区别是？

  • A没有区别
  • B前者立即调用，需手动传 $event；后者把方法引用交给事件，自动接收事件对象
  • C前者不执行
  • D后者不执行

答案：B 解析：加括号是立即调用（内联语句），要访问事件对象需手动传 $event；不加括号是方法引用，自动接收事件对象。B 正确。

03-选择-029（★★ 知识点：K3-1/K3-2） 要把数据绑定到 <img> 的 src 属性，正确的是？

  • A<img src="{{ url }}">
  • B<img :src="url">
  • C<img {{ src=url }}>
  • D<img v-src="url">

答案：B 解析：属性绑定用 :src，不能用 {{ }}。B 正确。

03-选择-030（★★ 知识点：K3-6） 遍历对象时，v-for="(value, key) in obj" 中 key 表示？

  • A对象的属性值
  • B对象的属性名
  • C索引
  • D对象本身

答案：B 解析：遍历对象时，value 是属性值，key 是属性名。B 正确。

03-论述-001（★★ 知识点：K3-5，分值：6 分） 题目：比较 v-if 与 v-show 的区别，并说明各自适用场景。

要求： （1）说明实现方式区别。（3 分） （2）说明性能开销区别。（2 分） （3）说明适用场景。（1 分）

参考答案： （1）实现方式（3 分）：v-if 条件为假时删除元素（不占 DOM），为真时重建；v-show 始终渲染元素，通过切换 display: none 控制显隐。 （2）性能开销（2 分）：v-if 切换开销大（重建 DOM），初始开销小（惰性）；v-show 切换开销小（仅样式），初始开销大（始终渲染）。 （3）适用场景（1 分）：频繁切换用 v-show，一次性/少切换用 v-if。

评分标准：共 6 分，按小题给分。意思相近即可。

03-论述-002（★★ 知识点：K3-6，分值：8 分） 题目：解释 v-for 中 :key 的作用，为什么不建议用 index 作 key？

要求： （1）说明 key 的作用。（3 分） （2）说明用 index 作 key 的问题。（3 分） （3）说明正确做法。（2 分）

参考答案： （1）key 作用（3 分）：key 是节点的唯一标识，帮助 Vue 高效识别、复用与更新节点，减少不必要的 DOM 操作。 （2）用 index 的问题（3 分）：列表增删时 index 会重新分配，导致 Vue 复用错位节点，造成状态错乱（如表单输入残留）且性能下降。 （3）正确做法（2 分）：使用数据中唯一且稳定的标识，如 :key="item.id"。

评分标准：共 8 分，按小题给分。

03-论述-003（★★ 知识点：K3-4，分值：8 分） 题目：解释 v-model 的原理，并用代码说明它等价于什么。

要求： （1）说明 v-model 的本质。（3 分） （2）写出等价代码。（3 分） （3）说明双向绑定的两个方向。（2 分）

参考答案： （1）本质（3 分）：v-model 是 :value + @input 的语法糖，实现表单元素的数据双向绑定。 （2）等价代码（3 分）：

<input v-model="text" />
<!-- 等价于 -->
<input :value="text" @input="text = $event.target.value" />

（3）两个方向（2 分）：数据→视图（数据变更新 value）；视图→数据（用户输入通过 input 事件同步回数据）。

评分标准：共 8 分，按小题给分。等价代码须含 :value 和 @input。

03-论述-004（★★ 知识点：K3-5/K3-6 综合，分值：8 分） 题目：为什么 v-if 与 v-for 不应同级使用？应如何解决？

要求： （1）说明同级使用的问题。（4 分） （2）说明正确解决方案。（4 分）

参考答案： （1）问题（4 分）：Vue 3 中 v-if 优先级高于 v-for，同级时 v-if 会先执行，但此时 v-for 的循环变量还未定义，导致取不到变量而报错或行为异常。即使不报错，每次渲染都对全部项判断再过滤，性能差。 （2）解决方案（4 分）：用 computed 计算属性先过滤数据，再 v-for 渲染过滤后的结果：

<li v-for="item in activeList" :key="item.id">{{ item.name }}</li>
const activeList = computed(() => list.value.filter(item => item.active))

评分标准：共 8 分，按小题给分。第（2）题须答出 computed 过滤方案。

03-编程-002（★★★ 知识点：K3 综合，分值：20 分） 题目：编写 CTTS-Frontend 项目列表与搜索筛选页面，要求：

  • 用 ref 包装项目数组（至少 3 项，含 id/title/status）；
  • 输入框 v-model 绑定关键词，实时过滤 title；
  • 下拉框 v-model 绑定状态筛选；
  • v-for 渲染过滤后列表，带 :key；
  • 无匹配时用 v-if/v-else 显示"暂无匹配"；
  • 提供"重置"按钮清空筛选。

要求： （1）完整三段式结构。（3 分） （2）ref 数据 + computed 过滤（关键词+状态）。（7 分） （3）v-for + :key 渲染列表。（4 分） （4）v-if/v-else 空状态 + 重置按钮。（6 分）

参考答案：

<template>
  <div class="projects">
    <h2>项目列表</h2>
    <input v-model="keyword" placeholder="搜索" />
    <select v-model="statusFilter">
      <option value="">全部</option>
      <option value="进行中">进行中</option>
      <option value="未开始">未开始</option>
    </select>
    <ul v-if="filtered.length">
      <li v-for="p in filtered" :key="p.id">{{ p.title }} - {{ p.status }}</li>
    </ul>
    <p v-else>暂无匹配</p>
    <button @click="reset">重置</button>
  </div>
</template>
<script setup>
import { ref, computed } from 'vue'
const keyword = ref('')
const statusFilter = ref('')
const projects = ref([
  { id: 1, title: 'JavaWeb', status: '进行中' },
  { id: 2, title: 'Vue3', status: '进行中' },
  { id: 3, title: '全栈联调', status: '未开始' }
])
const filtered = computed(() =>
  projects.value.filter(p =>
    p.title.includes(keyword.value) &&
    (statusFilter.value === '' || p.status === statusFilter.value)
  )
)
const reset = () => { keyword.value = ''; statusFilter.value = '' }
</script>
<style scoped>
.projects { max-width: 600px; margin: 20px auto; font-family: system-ui; }
ul { list-style: none; padding: 0; }
li { padding: 10px 0; border-bottom: 1px solid #eee; }
</style>

评分：三段式（3 分）；ref+computed 双条件过滤（7 分）；v-for+:key（4 分，缺 :key 扣 1）；v-if/v-else 空状态+重置（6 分）。
