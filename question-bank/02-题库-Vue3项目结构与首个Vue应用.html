02-选择-005（★ 知识点：K2-1） 关于 public/ 与 src/assets/ 的区别，正确的是？

  • Bpublic/ 的资源会被构建处理，assets/ 不会

02-选择-011（★ 知识点：K2-4） ref(0) 返回的对象，访问其真实值的方式是？

02-选择-012（★ 知识点：K2-4） 在模板中显示 ref 数据 count，正确写法是？

02-选择-013（★ 知识点：K2-4） 下列代码中，正确递增 ref 计数器的是？

02-选择-014（★ 知识点：K2-4） 把 ref 计数器重置为 0，正确写法是？

  • Bcount.value = 0
  • Ccount.reset()
  • Dcount = ref(0)

  • Bstyle → template → script
  • Ctemplate → script → style
  • D任意顺序均可，无约定

答案：C 解析：社区约定 template → script → style，官方脚手架与 ESLint 也按此顺序。C 正确。

02-选择-016（★ 知识点：K2-3） 关于 <script setup>，下列说法错误的是？

  • B顶层声明自动暴露给模板
  • C需要 export default
  • D导入的组件可直接在模板用

02-选择-017（★ 知识点：K2-1） vite.config.js 文件的作用是？

  • B循环变量，代表当前项

  • D方法名

02-选择-021（★★ 知识点：K2-1） 关于 Vue 3 项目的文件加载链路，正确的是？

02-选择-022（★★ 知识点：K2-2） 关于 SFC，下列说法正确的是？

02-选择-023（★★ 知识点：K2-3） <script setup> 相比普通 setup() 函数的主要优势是？

02-选择-024（★★ 知识点：K2-4） 关于模板中 ref 的自动解包，下列说法正确的是？

02-选择-025（★★ 知识点：K2-4） 下列代码会导致响应式丢失的是？

02-选择-026（★★ 知识点：K2-2/K2-3） 关于 <style scoped>，下列说法正确的是？

02-选择-029（★★ 知识点：K2-4） ref 适合包装的数据类型是？

02-论述-003（★★ 知识点：K2-4，分值：8 分） 题目：解释 ref 的响应式机制，并说明为什么在 JavaScript 中要用 .value 而模板中不用。

要求： （1）解释 ref 的作用与返回对象结构。（3 分） （2）说明 JS 中为何用 .value。（3 分） （3）说明模板中为何不用 .value。（2 分）

参考答案： （1）ref 作用与结构（3 分）：ref() 把值包装成响应式数据，返回一个 Ref 对象，结构形如 { value: 原始值 }。Vue 通过追踪 .value 的读写实现响应式——修改 .value 时视图自动更新。 （2）JS 中用 .value（3 分）：因为 ref 返回的是对象，真实值存在 .value 属性中，JS 中必须访问 .value 才能读写真实值；直接 count++ 会因 count 是对象而失败，count = 1 会覆盖变量丢失响应式。 （3）模板中不用 .value（2 分）：模板中 Vue 自动对 ref 进行"解包"（unwrap），直接显示 .value 的值，所以写 {{ count }} 即可，写 .value 反而取不到。

评分标准：共 8 分，按小题分值给分。第（2）题需答出"ref 返回对象"这一关键点。

02-论述-004（★★ 知识点：K2-1/K2-5，分值：8 分） 题目：在 CTTS-Frontend 首页中，为什么要用 ref 包装项目列表数据而不用普通数组？请从响应式角度分析，并描述普通数组与 ref 数组在修改后视图表现的差异。

要求： （1）说明用 ref 包装的原因。（4 分） （2）对比普通数组与 ref 数组的视图表现。（4 分）

参考答案： （1）用 ref 的原因（4 分）：Vue 的响应式系统通过 ref/reactive 追踪数据变化。普通数组不是响应式的，修改后 Vue 检测不到变化，视图不会更新。用 ref([...]) 包装后，数组变为响应式，修改 projects.value（或其元素）时 Vue 会自动更新视图，实现数据驱动。 （2）对比（每方面 2 分，共 4 分）：

  • 普通数组：修改后视图不更新，需手动操作 DOM 才能改变显示；
  • ref 数组：修改 .value 或数组元素后，视图自动更新，无需操作 DOM。

评分标准：共 8 分，按小题分值给分。第（1）题需答出"普通数组非响应式、ref 使其响应式"核心点。
