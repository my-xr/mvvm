四、论述 / 简答题（共 4 题）

12-论述-001（★★ 知识点：K12-1，分值：8 分） 题目：比较 Pinia 与 Vuex，说明 Pinia 的优势。

要求： （1）区别（4 分）。 （2）Pinia 优势（4 分）。

参考答案： （1）区别（4 分）：Pinia 无 mutations，直接改 state；Vuex 必须通过 mutations。Pinia store 平级独立；Vuex 用 modules 嵌套。Pinia TS 友好；Vuex 较弱。 （2）优势（4 分）：更简洁（无 mutations）；TS 友好；store 平级易维护；体积更小；学习成本低。

评分标准：共 8 分，按小题给分。

12-论述-002（★★ 知识点：K12-2/K12-3，分值：8 分） 题目：说明 store 的定义与 state 的使用，为何 state 用函数返回。

要求： （1）store 定义（3 分）。 （2）state 使用与修改（3 分）。 （3）函数返回原因（2 分）。

参考答案： （1）定义（3 分）：defineStore('id', { state, getters, actions })，id 唯一。 （2）使用与修改（3 分）：组件 const store = useXxxStore() 读取 store.xxx；修改可直接改、$patch、action。 （3）函数返回（2 分）：保证每个 store 实例的 state 独立，避免引用共享。

评分标准：共 8 分，按小题给分。

12-论述-003（★★ 知识点：K12-4/K12-5，分值：8 分） 题目：说明 getters 与 actions 的作用与注意事项。

要求： （1）getters 作用与注意（4 分）。 （2）actions 作用与注意（4 分）。

参考答案： （1）getters（4 分）：基于 state 的计算状态，有缓存，类似 computed。注意：只读不改；getter 间互访用 this（普通函数，非箭头）。 （2）actions（4 分）：store 的方法，可同步可异步，封装业务逻辑。注意：用 this 访问 state；用普通函数定义（箭头无 this）；异步用 async/await。

评分标准：共 8 分，按小题给分。

12-论述-004（★★ 知识点：K12 综合，分值：6 分） 题目：哪些数据应该放 Pinia，哪些放组件本地？为什么解构 store 状态要用 storeToRefs？

要求： （1）数据放置原则（3 分）。 （2）storeToRefs 原因（3 分）。

参考答案： （1）原则（3 分）：多组件共享的放 Pinia（用户信息/Token/全局 UI 状态）；组件私有的放本地（组件内表单、临时状态）。 （2）storeToRefs（3 分）：直接解构 store 状态会丢失响应式（变成普通值）；storeToRefs 把状态转为 ref，解构后仍保持响应式。

评分标准：共 6 分，按小题给分。
