四、论述 / 简答题（共 4 题）

11-论述-001（★★ 知识点：K11-1/K11-2，分值：8 分） 题目：说明路由守卫的种类与执行顺序。

要求： （1）三类守卫（4 分）。 （2）执行顺序（4 分）。

参考答案： （1）三类（每点 1.33 分，共 4 分）：①全局守卫（beforeEach/afterEach）；②路由独享守卫（beforeEnter）；③组件内守卫（onBeforeRouteLeave/onBeforeRouteUpdate）。 （2）顺序（4 分）：导航触发后依次执行：全局前置（beforeEach）→ 路由独享（beforeEnter）→ 组件内（beforeRouteEnter）→ 全局后置（afterEach）。

评分标准：共 8 分，按小题给分。

11-论述-002（★★ 知识点：K11-1，分值：8 分） 题目：说明 beforeEach 如何通过返回值控制导航，并举例登录拦截。

要求： （1）返回值规则（4 分）。 （2）登录拦截示例（4 分）。

参考答案： （1）返回值规则（4 分）：不返回/返回 true 放行；返回 false 取消导航；返回路径字符串或路由对象重定向。 （2）示例（4 分）：

router.beforeEach((to) => {
  if (to.meta.requireAuth && !localStorage.getItem('token')) {
    return '/login'
  }
})

评分标准：共 8 分，按小题给分。

11-论述-003（★★ 知识点：K11-3，分值：8 分） 题目：说明如何用 meta 实现角色权限控制。

要求： （1）meta 配置（4 分）。 （2）守卫判断（4 分）。

参考答案： （1）meta 配置（4 分）：在路由配置中加 meta: { requireAuth: true, role: 'admin' } 标识所需权限。 （2）守卫判断（4 分）：

router.beforeEach((to) => {
  const token = localStorage.getItem('token')
  const role = localStorage.getItem('role')
  if (to.meta.requireAuth && !token) return '/login'
  if (to.meta.role && to.meta.role !== role) return '/projects'
})

评分标准：共 8 分，按小题给分。

11-编程-001（★★ 知识点：K11-1/K11-3，分值：15 分） 题目：为 CTTS-Frontend 编写全局守卫，实现：未登录访问需认证页面跳转登录页；非 admin 访问 admin 页面跳回项目列表；并设置页面标题。

要求： （1）路由 meta 配置（requireAuth/role/title）。（5 分） （2）beforeEach 登录与角色校验。（7 分） （3）页面标题设置。（3 分）

参考答案：

const routes = [
  { path: '/login', component: Login, meta: { title: '登录' } },
  { path: '/projects', component: Projects, meta: { requireAuth: true, title: '项目列表' } },
  { path: '/admin/users', component: Users, meta: { requireAuth: true, role: 'admin', title: '用户管理' } }
]
const router = createRouter({ history: createWebHistory(), routes })
router.beforeEach((to) => {
  document.title = to.meta.title || 'CTTS'
  const token = localStorage.getItem('token')
  const role = localStorage.getItem('role')
  if (to.meta.requireAuth && !token) return '/login'
  if (to.meta.role && to.meta.role !== role) return '/projects'
})
export default router

评分：meta 配置（5 分）；beforeEach 双校验（7 分）；标题（3 分）。

评分标准：共 15 分，按小题给分。代码须可运行。
