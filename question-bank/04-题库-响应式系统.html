四、论述 / 简答题（共 4 题）

04-论述-001（★★ 知识点：K4-1/K4-2，分值：8 分） 题目：比较 ref 与 reactive 的区别，并说明如何选择。

要求： （1）说明两者区别（4 分）。 （2）说明选择原则（4 分）。

参考答案： （1）区别（每点 1 分，共 4 分）：

  • ref 适合基本类型（也支持对象），reactive 适合对象/数组；
  • ref 返回 Ref 对象，JS 中用 .value 访问；reactive 返回 Proxy，直接访问属性；
  • ref 在模板自动解包，reactive 无需解包；
  • ref 可整体替换（.value = newVal），reactive 整体替换会丢失响应式。 （2）选择原则（4 分）：基本类型用 ref；对象/数组用 reactive；若需整体替换或解构传递，用 ref 包装对象或用 toRefs。实践中可统一用 ref（包括对象）简化心智。

评分标准：共 8 分，按小题给分。

04-论述-002（★★ 知识点：K4-3，分值：8 分） 题目：解释 computed 的缓存机制，并说明 computed 与 methods 的区别。

要求： （1）说明 computed 缓存机制（4 分）。 （2）说明与 methods 区别（4 分）。

参考答案： （1）缓存机制（4 分）：computed 返回只读 Ref，首次访问时计算并缓存结果；当其依赖的响应式数据未变化时，再次访问直接返回缓存不重算；只有依赖变化时才标记为脏、下次访问重算。这避免了重复计算，提升性能。 （2）与 methods 区别（每点 2 分，共 4 分）：

  • computed 有缓存（依赖不变不重算），methods 每次调用都执行；
  • computed 像属性使用（不加括号），methods 像方法（加括号）；computed 适合派生数据，methods 适合事件/动作。

评分标准：共 8 分，按小题给分。

04-论述-003（★★ 知识点：K4-4/K4-5，分值：8 分） 题目：比较 watch 与 watchEffect 的区别，并说明各自适用场景。

要求： （1）说明区别（5 分）。 （2）说明适用场景（3 分）。

参考答案： （1）区别（每点 1.67 分，共 5 分）：

  • 触发时机：watch 依赖变化时触发；watchEffect 立即执行一次 + 依赖变化时触发；
  • 依赖指定：watch 显式指定侦听源；watchEffect 自动收集回调中用到的响应式数据；
  • 获取旧值：watch 能获取新旧值；watchEffect 不能获取旧值；
  • 选项：watch 支持 deep/immediate 等；watchEffect 无需指定源。 （2）适用场景（3 分）：需要旧值、需明确侦听源、需精细控制（如深度/立即）用 watch；只需在数据变化时执行副作用、不需旧值用 watchEffect。

评分标准：共 8 分，按小题给分。

04-论述-004（★★ 知识点：K4-6，分值：6 分） 题目：简述 Vue 3 响应式原理，并说明相比 Vue 2 的优势。

要求： （1）简述 Proxy 响应式原理（3 分）。 （2）说明相比 Vue 2 优势（3 分）。

参考答案： （1）原理（3 分）：Vue 3 用 reactive() 通过 ES6 Proxy 包裹对象，拦截属性的读（get）和写（set）。读取时"收集依赖"（记录谁用了该属性），修改时"触发更新"（通知依赖重新执行/渲染），从而实现响应式。 （2）相比 Vue 2 优势（每点 1 分，共 3 分）：

  • 能监测属性新增/删除（Vue 2 需 Vue.set/Vue.delete）；
  • 能监测数组索引修改（Vue 2 需特殊方法）；
  • 性能更好，代理整个对象而非逐属性拦截。

评分标准：共 6 分，按小题给分。

04-编程-002（★★★ 知识点：K4 综合，分值：20 分） 题目：编写 CTTS-Frontend 任务列表，要求：

  • 用 reactive 存储任务数组（id/title/status）；
  • 用 ref 存储搜索关键词；
  • 用 computed 过滤任务（按 title）；
  • 用 computed 统计已完成数量；
  • 用 watch（深度）监听任务变化，记录日志；
  • 提供"完成第一个"按钮。

要求： （1）reactive + ref 数据。（4 分） （2）computed 过滤 + 统计。（6 分） （3）watch 深度监听记录日志。（5 分） （4）按钮与方法 + 模板渲染。（5 分）

参考答案：

<template>
  <div>
    <input v-model="keyword" placeholder="搜索" />
    <ul>
      <li v-for="t in filtered" :key="t.id">{{ t.title }} - {{ t.status }}</li>
    </ul>
    <p>已完成：{{ doneCount }}</p>
    <button @click="finishFirst">完成第一个</button>
    <p v-if="log">日志：{{ log }}</p>
  </div>
</template>
<script setup>
import { ref, reactive, computed, watch } from 'vue'
const keyword = ref('')
const tasks = reactive([
  { id: 1, title: '任务一', status: '进行中' },
  { id: 2, title: '任务二', status: '未开始' }
])
const filtered = computed(() => tasks.filter(t => t.title.includes(keyword.value)))
const doneCount = computed(() => tasks.filter(t => t.status === '已完成').length)
const log = ref('')
watch(tasks, () => {
  log.value = `任务变化，已完成 ${doneCount.value} 个`
}, { deep: true })
const finishFirst = () => {
  const t = tasks.find(x => x.status !== '已完成')
  if (t) t.status = '已完成'
}
</script>
<style scoped>
ul { list-style: none; padding: 0; }
li { padding: 8px 0; border-bottom: 1px solid #eee; }
</style>

评分：reactive+ref（4 分）；computed 双用（6 分）；watch 深度+日志（5 分）；按钮方法+模板（5 分）。

评分标准：共 20 分，按小题给分。代码须可运行，watch 须带 deep。
