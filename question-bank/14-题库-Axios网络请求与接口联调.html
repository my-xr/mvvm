四、论述 / 简答题（共 4 题）

14-论述-001（★★ 知识点：K14-2/K14-3/K14-4，分值：8 分） 题目：说明 Axios 封装的目的与拦截器的作用。

要求： （1）封装目的（3 分）。 （2）请求拦截器（2 分）。 （3）响应拦截器（3 分）。

参考答案： （1）封装目的（3 分）：用 axios.create 统一配置 baseURL/timeout/headers，便于环境切换与统一管理；接口模块化组织在 src/api/，组件调用 api 函数，解耦请求细节。 （2）请求拦截器（2 分）：在请求发送前统一处理，常自动添加 Token 到 Authorization 头，必须 return config。 （3）响应拦截器（3 分）：在响应到达后统一处理，成功时解包返回业务数据（res.data），失败时统一错误提示；401 清状态跳登录；错误需 reject。

评分标准：共 8 分，按小题给分。

14-论述-002（★★ 知识点：K14-5，分值：8 分） 题目：说明开发与生产环境跨域的解决方案。

要求： （1）为什么跨域（2 分）。 （2）开发方案（3 分）。 （3）生产方案（3 分）。

参考答案： （1）跨域原因（2 分）：浏览器同源策略，前端 5173 与后端 8080 端口不同属跨域，浏览器拦截响应。 （2）开发方案（3 分）：Vite 配置 server.proxy 把 /api 转发到后端地址，changeOrigin 改 Origin，浏览器认为是同源。 （3）生产方案（3 分）：Nginx 反向代理转发，或后端配置 CORS 允许跨域。

评分标准：共 8 分，按小题给分。

14-论述-003（★★ 知识点：K14-3/K14-4，分值：8 分） 题目：说明拦截器中常见错误及避免方法。

要求： （1）请求拦截器错误（4 分）。 （2）响应拦截器错误（4 分）。

参考答案： （1）请求拦截器（4 分）：忘 return config 导致请求不发；在 Pinia 未挂载前用 store 报错。避免：必须 return config；确保 store 在请求时已可用。 （2）响应拦截器（4 分）：忘 reject 导致组件 catch 不到；401 处理不当死循环。避免：错误必须 Promise.reject；401 跳登录时排除登录页避免循环。

评分标准：共 8 分，按小题给分。

14-论述-004（★★ 知识点：K14 综合，分值：6 分） 题目：后端返回统一格式 {code, message, data}，前端如何处理？

要求： （1）格式说明（2 分）。 （2）前端处理（4 分）。

参考答案： （1）格式（2 分）：后端统一返回 {code: 200, message: 'success', data: {}}，code 表示业务状态，data 是实际数据。 （2）处理（4 分）：响应拦截器中判断 res.code，200 时 return res.data 返回业务数据；非 200 时提示 res.message 并 reject；HTTP 错误（401/500）单独处理。组件 await 直接拿到 data。
