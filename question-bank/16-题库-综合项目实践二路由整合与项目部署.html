四、论述 / 简答题（共 4 题）

16-论述-001（★★ 知识点：K16-4/K16-5，分值：8 分） 题目：说明 vite build 构建与部署流程，及 history 模式 404 解决。

要求： （1）构建流程（4 分）。 （2）部署与 404 解决（4 分）。

参考答案： （1）构建（4 分）：npm run build → 代码分割/Tree-shaking/压缩 → 输出到 dist 目录（含 index.html 与 assets）；npm run preview 预览检查。 （2）部署与 404（4 分）：把 dist 部署到 Nginx 静态目录；history 模式刷新 404 因服务器找不到路径，需配置 try_files $uri $uri/ /index.html 回退到 index.html；API 用 Nginx proxy_pass 代理后端。

评分标准：共 8 分，按小题给分。

16-论述-002（★★ 知识点：K16-1/K16-2，分值：8 分） 题目：说明路由与状态管理的整合要点。

要求： （1）路由整合（4 分）。 （2）状态整合（4 分）。

参考答案： （1）路由（4 分）：整合全部页面路由表；用 meta 标识 requireAuth/role；beforeEach 守卫校验登录与角色；404 兜底放最后；懒加载优化。 （2）状态（4 分）：userStore 接入登录页与 Header（存 Token/显示用户/退出）；projectStore 缓存项目数据；appStore 管理侧边栏等 UI 状态；持久化避免刷新丢失。

评分标准：共 8 分，按小题给分。

16-论述-003（★★ 知识点：K16 综合，分值：8 分） 题目：项目答辩应准备哪些内容？完整交付的标准是什么？

要求： （1）答辩准备（4 分）。 （2）交付标准（4 分）。

参考答案： （1）答辩（4 分）：功能演示（核心业务流程）、技术讲解（架构与技术选型）、问题应对（回答提问）、总结反思（亮点/不足/改进）。 （2）交付标准（4 分）：功能完整（页面齐全、流程打通）、组件质量（拆分合理）、代码规范、接口联调完善、可构建可部署可访问、答辩表现良好。

评分标准：共 8 分，按小题给分。

16-论述-004（★★ 知识点：K16 综合，分值：6 分） 题目：开发环境与生产环境在跨域、API 地址、构建上的区别。

要求：每点 2 分。
