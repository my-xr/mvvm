四、论述 / 简答题（共 4 题）

05-论述-001（★★ 知识点：K5-1，分值：6 分） 题目：说明 @click="fn" 与 @click="fn()" 的区别，及如何访问事件对象。

要求： （1）说明两者区别。（3 分） （2）说明如何访问事件对象。（3 分）

参考答案： （1）区别（3 分）：@click="fn" 是方法引用，事件触发时调用，自动接收事件对象；@click="fn()" 是内联语句，渲染时不调用、事件触发时执行，要传参需手动写，事件对象需手动传 $event。 （2）访问事件对象（3 分）：方法引用时第一参数即事件对象；内联语句用 $event 显式传递，如 @click="fn(msg, $event)"。

评分标准：共 6 分，按小题给分。

05-论述-002（★★ 知识点：K5-2，分值：8 分） 题目：列举至少 4 个事件修饰符并说明作用，举例链式用法。

要求： （1）列举 4 个修饰符及作用。（4 分） （2）举例链式用法并说明顺序影响。（4 分）

参考答案： （1）修饰符（每点 1 分，共 4 分）：.stop 阻止冒泡；.prevent 阻止默认行为；.once 只触发一次；.self 仅事件源为自身才触发；.capture 捕获模式。 （2）链式（4 分）：@click.prevent.stop="fn" 表示先 prevent 再 stop，顺序按书写执行，顺序不同行为不同。举例说明即可。

评分标准：共 8 分，按小题给分。

<template>
  <div>
    <input v-model="text" @keyup.enter="add" placeholder="输入后回车" />

    <ul>
      <li v-for="(item, i) in list" :key="i">{{ item }}</li>

import { ref } from 'vue'

}

05-编程-002（★★★ 知识点：K5 综合，分值：20 分） 题目：编写 CTTS-Frontend 登录表单，要求：

  • 用户名/密码 v-model.trim 双向绑定；
  • "记住我" checkbox；
  • 回车或点击登录提交（@submit.prevent）；
  • 非空校验（用户名）、密码长度≥6 校验；
  • 校验失败显示错误信息，通过则提示登录成功。

要求： （1）表单结构 + v-model.trim + checkbox。（5 分） （2）@submit.prevent + 回车提交。（4 分） （3）校验逻辑（非空 + 长度）。（6 分） （4）错误显示 + 成功提示。（5 分）

参考答案：

<template>
  <form @submit.prevent="onSubmit">
    <input v-model.trim="form.username" placeholder="用户名" @keyup.enter="onSubmit" />
    <p v-if="errors.username" class="err">{{ errors.username }}</p>
    <input v-model.trim="form.password" type="password" placeholder="密码" @keyup.enter="onSubmit" />
    <p v-if="errors.password" class="err">{{ errors.password }}</p>
    <label><input type="checkbox" v-model="form.remember" />记住我</label>
    <button type="submit">登录</button>
    <p v-if="msg">{{ msg }}</p>
  </form>
</template>
<script setup>
import { reactive, ref } from 'vue'
const form = reactive({ username: '', password: '', remember: false })
const errors = reactive({ username: '', password: '' })
const msg = ref('')
const validate = () => {
  errors.username = form.username ? '' : '用户名不能为空'
  errors.password = form.password.length >= 6 ? '' : '密码至少6位'
  return !errors.username && !errors.password
}
const onSubmit = () => {
  if (!validate()) return
  msg.value = `登录成功：${form.username}，记住：${form.remember}`
}
</script>
<style scoped>
input { display: block; padding: 8px; margin: 6px 0; }
.err { color: red; font-size: 12px; }
</style>

评分：表单+v-model.trim+checkbox（5 分）；submit.prevent+回车（4 分）；校验非空+长度（6 分）；错误显示+成功提示（5 分）。

评分标准：共 20 分，按小题给分。代码须可运行。
