四、论述 / 简答题（共 4 题）

10-论述-001（★★ 知识点：K10-1，分值：8 分） 题目：比较 hash 与 history 两种路由模式。

要求： （1）两者实现与 URL 区别（4 分）。 （2）各自优缺点与选择（4 分）。

参考答案： （1）区别（4 分）：hash 模式 URL 带 #，靠 hashchange 事件切换，兼容性好，无需服务器配置；history 模式 URL 干净无 #，靠 History API，需服务器配置所有路径回退 index.html 否则刷新 404。 （2）优缺与选择（4 分）：hash 优点是兼容好、部署简单，缺点是 URL 丑、不利于 SEO；history 优点是 URL 美观、利于 SEO，缺点是部署需服务器配置。现代项目优选 history（部署可控），简单场景可用 hash。

评分标准：共 8 分，按小题给分。

10-论述-002（★★ 知识点：K10-3，分值：8 分） 题目：说明 useRouter 与 useRoute 的区别及各自用途，举例。

要求： （1）区别（4 分）。 （2）举例（4 分）。

参考答案： （1）区别（4 分）：useRouter 返回路由实例，用于编程式导航（push/replace/go），是"动作"；useRoute 返回当前路由信息对象，用于获取数据（path/params/query），是"数据"。 （2）举例（4 分）：

const router = useRouter()
const route = useRoute()
router.push('/projects')              // 导航
console.log(route.params.id)          // 获取动态参数
console.log(route.query.keyword)      // 获取查询参数

评分标准：共 8 分，按小题给分。

10-论述-003（★★ 知识点：K10-4，分值：8 分） 题目：说明动态路由的定义与参数获取，及 props:true 的好处。

要求： （1）定义与获取（4 分）。 （2）props:true 好处（4 分）。

参考答案： （1）定义与获取（4 分）：动态路由用 :参数名 定义，如 { path: '/tasks/:id', component: TaskDetail }，匹配 /tasks/5，通过 route.params.id 获取值为 '5'。 （2）props:true 好处（4 分）：配置 props: true 后，路由参数会作为组件 props 传入，组件通过 defineProps(['id']) 接收，无需依赖 $route，使组件与路由解耦，便于复用与测试。

评分标准：共 8 分，按小题给分。

10-论述-004（★★ 知识点：K10-5，分值：6 分） 题目：说明嵌套路由的配置与子 path 拼接规则。

要求： （1）配置方式（3 分）。 （2）path 拼接规则（3 分）。
