## 二、课程定位与设计理念

### 2.1 课程定位

本课程教授 **Vue 3 前端框架**，以 **MVVM 架构思想**为核心，以 **Composition API + `<script setup>`** 为主要开发方式，帮助学生从"会写 HTML/CSS/JS 页面"跃迁到"能开发规范的前端单页应用"。

课程不采用传统的"知识点堆砌"模式，而是以 **PBL 项目化教学**为导向，围绕一个贯穿课程的前端项目，逐步构建一个可运行、可演示、可部署的 Vue 3 前端应用。

**课程主线**：

```
搭建Vue3项目 → 模板与响应式 → 组件化拆分 → 路由导航
            → 状态管理 → 接口联调 → 项目构建与部署
```

### 2.2 六大设计理念

| 序号 | 理念 | 落地方式 |
| --- | --- | --- |
| 1 | PBL 项目化教学导向 | 以"CTTS-Frontend"贯穿全程，知识点服务于项目任务 |
| 2 | 产教融合导向 | 内容贴近前端开发岗位能力要求，体现组件化、路由、状态管理、接口联调等能力 |
| 3 | 理论实践结合 | 每模块配套实践任务、课堂练习或阶段性项目成果 |
| 4 | 能力递进设计 | 入门 → 核心语法 → 组件化 → 路由 → 状态管理 → 接口联调 → 综合项目 → 部署 |
| 5 | 就业能力导向 | 教学与习题结合前端岗位常见工作任务和面试考点 |
| 6 | 课程思政自然融入 | 思政结合真实开发场景（用户体验、数据安全、代码规范、团队协作），不空泛拔高 |

### 2.3 能力递进路径

```
框架认知 → 核心语法 → 组件化开发 → 路由导航
       → 状态管理 → 接口联调 → 综合项目 → 构建部署
```

## 三、课程目标

### 3.1 知识目标

1. 理解 MVVM 架构思想与 Vue 3 的响应式原理。
2. 掌握 Vue 3 Composition API（`ref`/`reactive`/`computed`/`watch`）的使用。
3. 掌握模板语法、指令（`v-bind`/`v-on`/`v-model`/`v-if`/`v-for`）、事件处理与表单绑定。
4. 掌握组件化开发（组件定义、`props`/`emits`、插槽、组件通信）。
5. 掌握 Vue Router 4 路由配置、动态路由、嵌套路由、导航守卫。
6. 掌握 Pinia 状态管理（store 定义、state/getters/actions）。
7. 掌握 Axios 网络请求封装与后端接口联调。
8. 掌握 Vite 项目构建与部署。

### 3.2 能力目标

1. 能够独立搭建 Vue 3 + Vite 项目并开发前端页面。
2. 能够使用 Composition API 编写响应式逻辑。
3. 能够按组件化思想拆分页面，实现组件间通信。
4. 能够使用 Vue Router 实现多页面导航与权限路由控制。
5. 能够使用 Pinia 管理全局状态。
6. 能够使用 Axios 调用后端 RESTful API 并处理响应。
7. 能够完成一个具备完整业务流程的前端单页应用（SPA）。
8. 能够完成项目构建与部署。

### 3.3 素质目标（课程思政）

1. 树立用户体验意识——前端开发的核心是服务用户。
2. 培养组件化与模块化思维——良好架构是可维护性的基础。
3. 培养数据安全意识——前端存储 Token、处理用户数据时注意安全。
4. 培养团队协作意识——前后端分离协作中接口契约的重要性。
5. 增强国产技术生态认同——Vue 是华人尤雨溪创建的框架，体现中国技术影响力。

## 五、贯穿课程项目设计

### 5.1 项目名称

**校园实训任务管理系统前端（CTTS-Frontend）**

### 5.2 项目选型理由

1. **与 JavaWeb 后端课程配套**：JavaWeb 课程的 CTTS 后端提供 RESTful API，本课程的 CTTS-Frontend 调用这些 API，两门课程可前后端联调，体现产教融合。
2. **场景真实**：贴合高校实训管理实际业务，学生易理解、有代入感。
3. **业务完整**：覆盖登录认证、列表展示、表单提交、数据筛选、权限控制等前端典型场景。
4. **组件丰富**：可拆分为登录页、布局组件、列表页、详情页、表单页、统计页等，充分训练组件化能力。
5. **可递进构建**：从单个页面到多页面路由，从静态数据到接口联调，逐步增量构建。

## 七、32 学时课程进度总览（16 次课）

### 模块 1：前端框架认知与 Vue3 入门

#### 第 1 次课（理论）— 前端框架认知与 Vue3 开发环境搭建
- **主题**：前端框架演进；MVVM 思想；Vue3 简介；Node.js 与开发环境；Vite 创建项目
- **知识点**：前端框架演进（jQuery→MVVM）、MVVM（Model-View-ViewModel）、Vue3 特性、Node.js/npm、Vite 项目创建
- **项目任务**：安装 Node.js，使用 Vite 创建 CTTS-Frontend 项目
- **互动**：课前讨论"原生 JS 开发 vs 框架开发的区别"
- **思政**：中国技术影响力——Vue 是华人尤雨溪创建的框架
- **考核点**：MVVM 概念、Vue3 特性、Vite 项目创建

#### 第 2 次课（理论）— Vue3 项目结构与首个 Vue 应用
- **主题**：Vue3 项目结构；SFC 单文件组件；`<script setup>` 语法；首个页面
- **知识点**：项目目录结构、`.vue` 文件三段式（template/script/style）、`<script setup>`、响应式初体验（`ref`）
- **项目任务**：创建 CTTS-Frontend 首页，显示欢迎信息与项目列表（静态数据）
- **互动**：代码阅读——对比 Options API 与 Composition API
- **思政**：工程规范——项目结构是协作的基础
- **考核点**：SFC 结构、`<script setup>`、`ref` 基本使用

### 模块 2：Vue3 核心语法

#### 第 3 次课（理论）— 模板语法与指令
- **主题**：模板语法；文本插值；指令（v-bind/v-on/v-model/v-if/v-for/v-show/v-html）
- **知识点**：Mustache `{{ }}`、`v-bind`（属性绑定）、`v-on`（事件绑定）、`v-model`（双向绑定）、`v-if`/`v-show`（条件渲染）、`v-for`（列表渲染）、指令修饰符
- **项目任务**：用指令实现项目列表展示与搜索筛选
- **互动**：代码找错——`v-if` 与 `v-for` 混用的反例
- **思政**：代码规范——指令使用要清晰简洁
- **考核点**：各指令使用场景与区别

#### 第 4 次课（理论）— 响应式系统
- **主题**：`ref` 与 `reactive`；`computed` 计算属性；`watch` 侦听器
- **知识点**：`ref`（基本类型响应式）、`reactive`（对象响应式）、`computed`（计算属性）、`watch`/`watchEffect`（侦听器）、响应式原理基础
- **项目任务**：实现任务列表的搜索过滤（computed）与状态变化响应（watch）
- **互动**：面试题导入——"ref 和 reactive 的区别"
- **思政**：数据驱动思维——响应式让开发者关注数据而非 DOM 操作
- **考核点**：ref/reactive/computed/watch 使用

#### 第 5 次课（理论）— 事件处理与表单绑定
- **主题**：事件处理（`v-on`）；事件修饰符；表单输入绑定（`v-model`）
- **知识点**：`@click`/`@submit`、事件对象 `$event`、事件修饰符（.stop/.prevent/.once）、按键修饰符、`v-model` 与 input/textarea/select、修饰符（.lazy/.number/.trim）
- **项目任务**：实现登录表单（双向绑定 + 表单验证 + 提交）
- **互动**：编程小测验——表单绑定场景题
- **思政**：用户体验——良好的表单交互让用户少犯错
- **考核点**：事件处理、事件修饰符、v-model 表单绑定

#### 第 6 次课（理论）— 条件渲染、列表渲染与样式绑定
- **主题**：`v-if`/`v-else`/`v-show`；`v-for` 与 key；class 与 style 绑定
- **知识点**：条件渲染场景、`v-for` 遍历数组/对象、`:key` 重要性、`:class`（对象/数组语法）、`:style`（对象语法）、列表更新检测
- **项目任务**：实现任务列表的条件展示（不同状态不同样式）与分页
- **互动**：两人一组讲解 `:key` 的作用
- **思政**：细节决定体验——合理的列表渲染与样式让界面更专业
- **考核点**：v-if/v-show 区别、v-for 与 key、class/style 绑定

### 模块 3：组件化开发

#### 第 7 次课（理论）— 组件基础与组件通信
- **主题**：组件定义；props；emits；父子组件通信
- **知识点**：组件注册（局部/全局）、`props`（定义/类型/默认值/必填）、`emits`（自定义事件）、父传子（props）、子传父（emits）、组件 v-model
- **项目任务**：拆分登录页为 LoginForm 组件，实现父子通信
- **互动**：接口设计讨论——组件通信该用 props 还是 provide/inject
- **思政**：组件化思维——分而治之是工程方法论
- **考核点**：props/emits、父子通信

#### 第 8 次课（理论）— 插槽与组件高级特性
- **主题**：插槽（slot）；具名插槽；作用域插槽；动态组件；异步组件
- **知识点**：默认插槽、具名插槽（`v-slot:name`）、作用域插槽（传数据给插槽）、动态组件（`<component :is>`）、异步组件（`defineAsyncComponent`）
- **项目任务**：封装通用卡片组件 Card（使用插槽）与动态标签页
- **互动**：代码阅读——作用域插槽的使用场景
- **思政**：复用意识——好组件是设计出来的
- **考核点**：插槽类型、动态组件

#### 第 9 次课（实践）— 组件化开发综合实践
- **主题**：综合实践——完成 CTTS-Frontend 核心组件库
- **任务**：拆分并实现布局组件（Header/Sidebar/Content）、列表组件（ProjectList/TaskList）、表单组件（LoginForm/SubmitForm）、通用组件（Pagination/Card/Dialog）
- **互动**：项目任务复盘——组件拆分的经验与教训
- **思政**：工匠精神——组件设计的好坏直接影响项目质量
- **考核点**：组件拆分与通信实现

### 模块 4：Vue Router 路由

#### 第 10 次课（理论）— Vue Router 基础
- **主题**：路由配置；路由跳转；动态路由；嵌套路由
- **知识点**：安装 Vue Router、路由配置（routes）、`<router-view>`/`<router-link>`、`useRouter`/`useRoute`、动态路由（`:id`）、嵌套路由（children）
- **项目任务**：配置 CTTS-Frontend 全部页面路由
- **互动**：API 路径设计投票——前端路由与后端 API 路径的对应关系
- **思政**：导航设计——良好的路由是用户体验的基础
- **考核点**：路由配置、动态路由、嵌套路由

#### 第 11 次课（理论）— 路由进阶与导航守卫
- **主题**：导航守卫；路由元信息；路由懒加载；404 页面
- **知识点**：全局守卫（beforeEach）、路由独享守卫、组件内守卫、`meta` 元信息（如 requireAuth/role）、路由懒加载（`() => import()`）、重定向与 404
- **项目任务**：实现登录权限拦截（未登录跳转登录页）与角色路由控制
- **互动**：面试题快问快答——导航守卫常见考点
- **思政**：安全意识——前端路由守卫是第一道权限防线
- **考核点**：导航守卫、meta 元信息、懒加载

### 模块 5：Pinia 状态管理

#### 第 12 次课（理论）— Pinia 状态管理基础
- **主题**：Pinia 简介；store 定义；state；getters；actions
- **知识点**：Pinia 与 Vuex 对比、`defineStore`、state（定义/读取/修改）、getters（计算状态）、actions（定义方法/异步操作）、`$reset`/`$patch`
- **项目任务**：创建 userStore（管理 Token/用户信息/登录状态）
- **互动**：小组讨论——哪些数据应该放 Pinia，哪些放组件本地
- **思政**：数据管理意识——全局状态是前端架构的核心
- **考核点**：Pinia store 定义与使用

#### 第 13 次课（实践）— Pinia 进阶与状态管理实践
- **主题**：综合实践——完成 CTTS-Frontend 全局状态管理
- **任务**：创建 userStore（登录状态）、projectStore（项目数据缓存）、appStore（侧边栏折叠等 UI 状态），实现状态持久化（localStorage）
- **互动**：项目问题复盘——状态管理踩坑
- **思政**：架构意识——合理的状态管理让应用更健壮
- **考核点**：Pinia 多 store 管理、状态持久化

### 模块 6：网络请求与接口联调

#### 第 14 次课（理论）— Axios 网络请求与接口联调
- **主题**：Axios 封装；请求/响应拦截器；与后端 API 联调；跨域处理
- **知识点**：Axios 安装与基本使用、请求封装（baseURL/timeout/headers）、请求拦截器（自动加 Token）、响应拦截器（统一错误处理）、与 CTTS 后端 API 联调、Vite 代理配置（跨域）
- **项目任务**：封装 Axios，联调 CTTS 后端的登录、项目列表、任务列表接口
- **互动**：接口联调演示——实时展示前端调用后端 API
- **思政**：前后端协作——接口契约是团队协作的基础
- **考核点**：Axios 封装、拦截器、接口联调

### 模块 7：综合项目开发

#### 第 15 次课（实践）— 综合项目实践一：核心页面与组件开发

4. 主观题含评分标准（按要点/分项给分）。
5. 难度分层：基础 50% / 提高 30% / 综合 20%，标注 ★/★★/★★★。
6. 贴近前端开发岗位与就业面试。
7. 题目编号：`次课-题型-序号`，如 `01-选择-001`。

### 15.2 三个文档的关系

- **教学设计**是教师的"教案"，偏组织流程，回答"**这节课怎么教**"。
- **教学资料**是学生的"讲义/复习资料"，偏知识内容，回答"**这节课学了什么**"，包含定义、问题、完整示例代码等学习材料。
- **题库**是测评依据，偏考核评价，回答"**这节课考什么**"。

三者相互独立又彼此呼应：教学设计引用教学资料中的知识点编号，题库题目对应教学资料中的知识点，形成"教—学—考"闭环。

### 16.2 产出方式（教师已确认）

1. **细化节奏**：按"**每次课一个批次**"逐项产出（非按模块批量）。
2. **文档拆分**：每次课输出**三个文档**：
   - `教学设计.md` —— 教师教案（教学组织流程，偏"怎么教"）
   - `教学资料.md` —— 学生复习资料（定义、问题、完整示例代码，便于课后复习）
   - `题库.md` —— 考试题库（78 题，含答案解析与评分标准）
3. **首次输出**：从 `01`（第 1 次课：前端框架认知与 Vue3 开发环境搭建）开始，每次课一次性产出三个文档。
4. **产出顺序**：`01` → `02` → … → `16`，逐次推进。

> 教师将在每次课文档产出后审阅，确认无误后再推进下一次课。如需调整某次课内容，可在对应批次反馈。
